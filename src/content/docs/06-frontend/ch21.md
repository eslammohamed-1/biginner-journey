<small>المرحلة 7 · CSS والـ Rendering و TypeScript</small>

هتلاقي في create-vite نسخة -ts من كل قالب، وأغلب إعلانات الشغل بتطلب TypeScript. الفصل ده مش كورس TypeScript، هو بيجاوب على: هي إيه، وبتحل إيه، وبتشتغل فين في الـ Pipeline (مين بيشيك على الأنواع ومين بيشيلها)، وكل ملف tsconfig بيعمل إيه، و TypeScript 7 الجديدة المكتوبة بـ Go. وامتى تبدأ تتعلمها في رحلتك.

:::note[بعد الفصل ده هتكون عارف]
- تعرف TypeScript بتحل مشكلة إيه بمثال حقيقي
- تقرا Error بتاع tsc وتفهمه
- تفهم إن Vite بيشيل الأنواع ومابيشيكش عليها، وليه build فيه tsc &&
- تقرا tsconfig.json بتاع Vite سطر سطر
- تعرف ملفات قالب react-ts
- تشغّل .ts في Node 24 مباشرة وتعرف حدودها
- تعرف TypeScript 7 وامتى تتعلم TS
:::

<a id="s21-1"></a>

## 21.1 المشكلة

في JavaScript ده كود "سليم":

```js
function formatPrice(p) {
  return `${p.name}: ${p.price.toFixed(2)} EGP`
}
formatPrice({ name: 'Book', price: '120' })   // TypeError at runtime
```

هيضرب `p.price.toFixed is not a function`، بس **لما المستخدم يوصل للسطر ده**. ممكن بعد أسبوع في الإنتاج. لأن `'120'` نص مش رقم (والقيمة جاية غالباً من `input.value` أو JSON، كتاب الـ APIs). TypeScript = JavaScript + **أنواع**، وأداة بتقرا الكود وتلاقي الغلط ده **قبل ما يشتغل**.

<a id="s21-2"></a>

## 21.2 التجربة

قالب `vanilla-ts`، وملف جديد:

```ts title="src/price.ts"
type Product = {
  name: string
  price: number
  onSale?: boolean
}

export function formatPrice(p: Product): string {
  return `${p.name}: ${p.price.toFixed(2)} EGP`
}

const input = document.querySelector<HTMLInputElement>('#qty')
console.log(input?.value)

formatPrice({ name: 'Book', price: '120' })
```

| الأمر | بيعمل إيه |
|---|---|
| `type Product = {…}` | شكل الـ Object: `name` نص، و`price` رقم، و`onSale?` اختياري (الـ `?`). |
| `(p: Product): string` | الـ Parameter لازم يبقى Product، والـ Function بترجّع نص. |
| `<HTMLInputElement>` | "العنصر ده input"، فالمحرر يعرف إن فيه `.value`. و`input?.value` لأن `querySelector` ممكن يرجّع `null`، و TS بيجبرك تفكر في الحالة دي. |

```sh title="Terminal"
$ npm run build

> ts-app@0.0.0 build
> tsc && vite build

src/price.ts(14,29): error TS2322: Type 'string' is not assignable to type 'number'.
$ echo $?
2
```

**تشريح الأمر**

```text
src/price.ts(14,29): error TS2322: Type 'string' is not assignable to type 'number'.
```

1. `src/price.ts`: الملف.
2. `(14,29)`: السطر 14، الحرف 29: عند `price: '120'` بالظبط.
3. `TS2322`: رقم الـ Error. دوّر بيه لو الرسالة مش واضحة.
4. `Type 'string'…`: "اديتني نص في مكان المفروض فيه رقم".

و`tsc` رجع exit code 2، فالـ `&&` (كتاب الـ Terminal) وقّفت `vite build`، والـ Deploy مش هيكمل بكود فيه غلط. وفي VS Code هتشوف خط أحمر تحت `'120'` وانت بتكتب، قبل أي build.

## 21.3 مين بيشيك ومين بيشيل؟

جرّبنا نفس الكود بـ `vite build` لوحده من غير `tsc`:

```sh title="Terminal"
$ npx vite build
✓ built in 79ms
```

**نجح**، والغلط جوه الـ Bundle. Vite (عن طريق Oxc في Vite 8) بيعمل حاجة واحدة مع TS: **يشيل الأنواع** ويطلّع JS. ودوّرنا على كلمة `Product` في الـ JS الناتج: 0 مرة. مابيشيكش على حاجة، علشان يفضل سريع.

## 21.4 tsconfig.json سطر سطر

```dockerfile
"target": "es2023",
"lib": ["ES2023", "DOM"],
"types": ["vite/client"],
"moduleResolution": "bundler",
"allowImportingTsExtensions": true,
"verbatimModuleSyntax": true,
"noEmit": true,
"noUnusedLocals": true,
"noUnusedParameters": true,
"erasableSyntaxOnly": true,
```

1. `"target": "es2023",`: أنهي مميزات JS والمتصفح موجودة. `DOM` هي اللي بتعرّف `document` و`HTMLInputElement`.
2. `"types": ["vite/client"],`: أنواع Vite: علشان `import.meta.env` و`import logo from './x.svg'` مايطلعوش Errors.
3. `"moduleResolution": "bundler",`: "فيه Bundler هو اللي هيحل الـ imports"، فمسموح `import './price.ts'` بالامتداد.
4. `"verbatimModuleSyntax": true,`: لو بتعمل import لنوع بس، اكتب `import type`، علشان الأداة تعرف تشيله.
5. `"noEmit": true,`: `tsc` يفحص بس ومايكتبش ملفات. Vite هو اللي بيطلّع الـ JS.
6. `"noUnusedLocals": true,`: متغير أو Parameter مش مستخدم = Error (شبه ESLint، فصل 23).
7. `"erasableSyntaxOnly": true,`: ممنوع أي TS بيعمل كود حقيقي (زي `enum`). المسموح بس الحاجات اللي "تتمسح" فيفضل JS سليم. تحت هتعرف ليه.

### قالب react-ts

```sh title="Terminal"
$ npm create vite@latest rts -- --template react-ts --no-interactive
$ ls -a rts
.gitignore  .oxlintrc.json  README.md  index.html  package.json  public  src
tsconfig.app.json  tsconfig.json  tsconfig.node.json  vite.config.ts
```

| الأمر | بيعمل إيه |
|---|---|
| `tsconfig.json` | فاضي تقريباً: `"references"` لملفين. |
| `tsconfig.app.json` | لكود `src` (المتصفح، فيه DOM). |
| `tsconfig.node.json` | لـ `vite.config.ts` (بيشتغل في Node، مفيهوش DOM). |
| `"build": "tsc -b && vite build"` | `-b` = Build mode: يفحص المشروعين اللي في الـ references. |
| `@types/react و @types/react-dom و @types/node` | React نفسها مكتوبة JS، فالأنواع بتاعتها في Packages منفصلة `@types/…` (مشروع اسمه DefinitelyTyped). مكتبات تانية (زي Vite) بتيجي بأنواعها جواها. |
| `.tsx` | TypeScript + JSX. `App.tsx` و`main.tsx`. |

## 21.5 TypeScript في Node 24 مباشرة

```sh title="Terminal"
$ cat t.ts
type User = { name: string }
const u: User = { name: "Sara" }
console.log("hi", u.name)
$ node t.ts
hi Sara
$ node e.ts
SyntaxError [ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX]: TypeScript enum is not supported in strip-only mode
```

Node 24 بيشغّل `.ts` على طول بإنه **يمسح** الأنواع (Type stripping)، من غير فحص. وعلشان كده `enum` فشل: مش "نوع" ينفع يتمسح، ده كود. وده سبب `erasableSyntaxOnly` في tsconfig: يخلّي كودك يشتغل في أي أداة بتمسح بس.

## 21.6 TypeScript 7

في 8 يوليو 2026 نزلت **TypeScript 7.0**: نفس اللغة، بس الـ Compiler اتكتب من جديد بلغة **Go** بدل JavaScript، وفريق TypeScript بيقول إنه أسرع حوالي 10 مرات في المشاريع الكبيرة. جرّبناها على نفس المشروع:

```sh title="Terminal"
$ npx -p typescript@7.0.2 tsc --version
Version 7.0.2
$ npx -p typescript@7.0.2 tsc --noEmit -p .
src/price.ts(14,29): error TS2322: Type 'string' is not assignable to type 'number'.
```

نفس الـ Error بالحرف. بس لاحظ إن قوالب create-vite وقت الكتابة لسه كاتبة `"typescript": "~6.0.3"` (الـ `~` مش هتجيب 7 أبداً، فصل 15)، وإن أدوات بتعتمد على API بتاع TypeScript (زي typescript-eslint) محتاجة وقت تلحق. الكلام ده للمعرفة: هتشتغل بالنسخة اللي القالب جايبها.

:::tip[أتعلمها إمتى؟]
مش دلوقتي. خلّص JavaScript مع Jonas، وبعدين Node، وبعدين React. لما تبقى مرتاح في React، ابدأ مشروع بـ `react-ts`. هتلاقي إن 80% من الشغل: `type` للـ Props، وأنواع الـ `useState`، و`?.`. وكل اللي اتعلمته في JS بيفضل زي ما هو، لأن TS = JS + أنواع.
:::

:::tip[ملخص الفصل]
- TypeScript = JS + أنواع، بتلاقي الغلط قبل التشغيل.
- المحرر و`tsc` بيفحصوا، و Vite و Node بيشيلوا الأنواع بس من غير فحص.
- علشان كده `"build": "tsc && vite build"`.
- `noEmit` و`moduleResolution: bundler` و`erasableSyntaxOnly` أهم سطور الـ tsconfig.
- TypeScript 7 (Go) أسرع، والقوالب لسه على 6.0. اتعلم TS بعد React.
:::

### صح ولا غلط؟

1. المتصفح بيفهم TypeScript مباشرة.
2. `npm run dev` في مشروع Vite بيوقف لو فيه Type error.
3. Node 24 بيشغّل ملف `.ts` فيه `enum` عادي.

### أسئلة مراجعة

1. ليه `vite build` لوحده نجح والكود فيه غلط؟
2. اقرا الـ Error: `src/App.tsx(8,5): error TS2322`. هتروح فين؟
3. ليه React محتاجة `@types/react` و Vite لأ؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** اعمل مشروع `vanilla-ts` وغيّر حاجة في `counter.ts` لنوع غلط. شوف الخط الأحمر في VS Code.
2. **[متوسط]** كرر تجربة `price.ts` وشغّل `npm run build` و`npx vite build` وقارن.
