<small>المرحلة 3 · CSS بجد</small>

لو اتعلمت CSS من فيديوهات قديمة، فاتك كتير. في آخر كام سنة CSS بقى فيها متغيرات حقيقية بتتغير وقت التشغيل، و Nesting زي Sass، و :has() اللي الناس كانت بتسميه «الـ Parent selector المستحيل»، و Logical properties بتقلب الصفحة للعربي لوحدها، ودوال زي clamp و color-mix. الفصل ده جولة على أهمهم، ومعاها إزاي تعرف ميزة معينة ينفع تستخدمها ولا لسه (Baseline).

:::note[بعد الفصل ده هتكون عارف]
- الـ Custom properties: var() والـ fallback والـ scope وتغييرها بالـ JS
- الـ Nesting الأصلي في CSS و &
- :has(): تختار الأب حسب ولاده
- الـ Logical properties: inline و block بدل left و right
- min() و max() و clamp()
- الألوان الحديثة: oklch() و color-mix()
- @supports للميزات الجديدة
- Baseline: تعرف الميزة مدعومة ولا لأ
:::

<a id="s10-1"></a>

## 10.1 الـ Custom properties: متغيرات بجد

شفت في قالب Vite: `--text` و`--bg` اتعرّفوا مرة، واتغيروا في Dark mode، وكل حاجة اتغيرت معاهم. ده بالظبط اللي الـ **Custom properties** (الناس بتقول عليها CSS variables) بتعمله:

```css
:root {
  --brand: #1d63ed;
  --space: 1rem;
}

.btn {
  background: var(--brand);
  padding: var(--space) calc(var(--space) * 2);
}

.danger {
  --brand: crimson; /* نفس الزرار، لون تاني جوه .danger بس */
}
```

| الأمر | بيعمل إيه |
|---|---|
| `--brand: #1d63ed` | التعريف. الاسم لازم يبدأ بـ `--`، وحساس للـ Capital والـ Small (`--Brand` غير `--brand`). |
| `:root` | = عنصر `html`. التعريف هنا يبقى متاح للصفحة كلها، لأن المتغيرات **بتتورث** زي `color`. |
| `var(--brand)` | الاستخدام. و`var(--brand, blue)` = "لو مش متعرّف استخدم blue" (الـ Fallback). |
| `calc(var(--space) * 2)` | تقدر تحسب بيها. و`calc` بتخلط وحدات كمان: `calc(100% - 2rem)`. |
| `.danger { --brand: crimson }` | المتغير ليه **Scope**: إعادة تعريفه على عنصر بتأثر عليه وعلى ولاده بس. ودي حاجة متغيرات Sass مبتعملهاش. |

:::tip[الفرق الجوهري عن متغيرات Sass]
متغيرات Sass (`$brand`) بتتحسب **وقت الـ Build** وبتختفي: المتصفح بيستلم `#1d63ed` مكتوبة. أما `--brand` فبتوصل للمتصفح **حية**: تتغير بالـ Media queries، وبالـ Classes، وبالـ JavaScript: `document.documentElement.style.setProperty('--brand', 'green')`. علشان كده Tailwind 4 بنى نظام الألوان كله عليها (`@theme` في فصل 20).
:::

## 10.2 الـ Nesting الأصلي

لسنين كان أهم سبب الناس تستخدم Sass هو إنها تكتب القواعد جوه بعض. دلوقتي CSS نفسها بتعمل كده (في كل المتصفحات الرئيسية من 2023). وقالب Vite بيستخدمها فعلاً:

```css title="vanilla-app/src/style.css"
.counter {
  color: var(--accent);
  border: 2px solid transparent;
  transition: border-color 0.3s;

  &:hover {
    border-color: var(--accent-border);
  }
  &:focus-visible {
    outline: 2px solid var(--accent);
    outline-offset: 2px;
  }
}

h1 {
  font-size: 56px;
  @media (max-width: 1024px) {
    font-size: 36px;
  }
}
```

| الأمر | بيعمل إيه |
|---|---|
| `&:hover` | الـ `&` = "الـ Selector الأب". فدي = `.counter:hover`. |
| `.hero { .base { … } }` | من غير `&` = حفيد: `.hero .base`. (القالب بيعمل كده بالظبط في `.hero`.) |
| `@media جوه القاعدة` | الـ Media query تتكتب جوه العنصر نفسه. فكل حاجة عن `h1` في مكان واحد. |

:::caution[خلي بالك]
متعششش أكتر من 2 أو 3 مستويات. الـ Nesting العميق بيعمل Selectors طويلة بـ Specificity عالية (فصل 6)، وصعب تتغيّر بعدين.
:::

## 10.3 :has(): الأب يعرف ولاده

لعشرين سنة تقريباً، CSS كانت بتختار من فوق لتحت بس: "الـ `img` اللي جوه `.card`". ومكانش فيه طريقة تقول "الـ `.card` **اللي فيه** `img`". `:has()` عملت ده:

```css
/* الكارت اللي فيه صورة: عمودين */
.card:has(img) {
  grid-template-columns: 120px 1fr;
}

/* الـ label اللي بعده خانة غلط */
label:has(+ input:user-invalid) {
  color: crimson;
}

/* الفورم كله لو فيه أي خانة غلط */
form:has(:user-invalid) button[type="submit"] {
  opacity: 0.5;
}
```

حاجات كانت محتاجة JavaScript (تشيك وتزوّد Class) بقت سطر CSS. وخلي بالك إن الـ Specificity بتاعة `:has(…)` = أدق حاجة جواها، زي `:is()`.

## 10.4 الـ Logical properties: هدية للعربي

لو كتبت `margin-left: 1rem` لأيقونة جنب كلمة، وبعدين قلبت الصفحة `dir="rtl"`، الأيقونة هتبقى ملزوقة في الناحية الغلط. الـ **Logical properties** بتتكلم بـ "بداية ونهاية" زي Flexbox:

**Physical ← Logical**

| القديمة (Physical) | الحديثة (Logical) | في الإنجليزي / في العربي |
|---|---|---|
| `margin-left` | `margin-inline-start` | شمال / يمين |
| `padding-right` | `padding-inline-end` | يمين / شمال |
| `margin-left` + `margin-right` | `margin-inline` | الجنبين |
| `margin-top` + `margin-bottom` | `margin-block` | فوق وتحت |
| `width` / `height` | `inline-size` / `block-size` | العرض / الارتفاع |
| `left: 0; right: 0` | `inset-inline: 0` | — |
| `text-align: left` | `text-align: start` | شمال / يمين |
| `border-left` | `border-inline-start` | شمال / يمين |

وقالب Vite بيستخدمها فعلاً: `border-inline: 1px solid var(--border)` على `#app`، و`inset-inline: 0` في `.hero`. والقاعدة: لو بتكتب لموقع ممكن يبقى عربي في أي يوم، اكتب Logical من الأول.

## 10.5 min() و max() و clamp()

| الأمر | بيعمل إيه |
|---|---|
| `width: min(100%, 60rem)` | "خد الأصغر": 100% من الأب، بس متعدّيش 60rem. بديل سطر واحد لـ `width: 100%; max-width: 60rem`. |
| `padding: max(1rem, 3vw)` | "خد الأكبر": مسافة بتكبر مع الشاشة، بس مش أقل من 1rem. |
| `clamp(a, b, c)` | الاتنين مع بعض (فصل 9). |

## 10.6 الألوان الحديثة

```css
:root {
  --brand: oklch(55% 0.2 260);
  --brand-hover: oklch(from var(--brand) calc(l - 10%) c h);
  --brand-soft: color-mix(in oklch, var(--brand) 15%, white);
}
```

| الأمر | بيعمل إيه |
|---|---|
| `oklch(L C H)` | **L** = الإضاءة (0% أسود لـ 100% أبيض)، **C** = التشبّع (Chroma)، **H** = درجة اللون (0 لـ 360). ميزتها إن الـ L "صادقة" للعين: لونين بنفس الـ L باينين بنفس الإضاءة، عكس `hsl()`. و Tailwind 4 كاتب ألوانه الافتراضية كلها بـ `oklch`. |
| `oklch(from var(--brand) …)` | **Relative color syntax**: خد لون موجود وعدّل جزء منه. هنا: نفس اللون أغمق 10% للـ Hover. (ميزة أحدث من الباقي، اتأكد من الـ Baseline تحت.) |
| `color-mix(in oklch, A 15%, B)` | اخلط لونين بنسبة. هنا: 15% من اللون الأساسي على أبيض = خلفية فاتحة من نفس العيلة. |

## 10.7 @supports و Baseline: ينفع أستخدمها؟

كل الميزات دي جديدة نسبياً. فإزاي تعرف إنها هتشتغل عند المستخدمين؟

#### Baseline

مبادرة من المتصفحات الكبيرة (Chrome و Edge و Firefox و Safari) بتدي لكل ميزة حالة: **Newly available** = اشتغلت في الأربعة. و**Widely available** = عدّى عليها 30 شهر من ساعتها، فآمنة لأغلب الناس. هتلاقي علامة Baseline في أول كل صفحة على MDN.

#### @supports

شرط في الـ CSS نفسه: "طبّق ده بس لو المتصفح فاهمه". مثال: `@supports (container-type: inline-size) { … }`. والمتصفح القديم هيتجاهل البلوك كله ويستخدم الشكل الأساسي.

:::tip[الـ Progressive enhancement]
اكتب شكل أساسي يشتغل في كل حتة، وبعدين زوّد الحاجات الجديدة كتحسين. لو المتصفح مش فاهم `:has()`، القاعدة كلها بتتجاهل، والصفحة لسه شغالة بس من غير الحتة الحلوة دي. CSS مصممة إنها متقعش لما متفهمش حاجة: بتتجاهلها وتكمّل.
:::

:::tip[ملخص الفصل]
- الـ Custom properties حية في المتصفح: بتتورث، وليها Scope، وبتتغير بالـ Media والـ JS.
- الـ Nesting بقى في CSS نفسها، و`&` = الأب. متعششش كتير.
- `:has()` بتختار العنصر حسب اللي جواه أو اللي بعده.
- الـ Logical properties (`inline-start` و`block`) بتقلب مع `dir` لوحدها.
- `min()` و`max()` و`clamp()` بيوفّروا Media queries.
- `oklch()` و`color-mix()` لألوان متناسقة.
- Baseline يقولك الميزة آمنة ولا لأ، و`@supports` للتحسين التدريجي.
:::

### صح ولا غلط؟

1. متغيرات CSS (`--x`) بتختفي بعد الـ Build زي متغيرات Sass.
2. `margin-inline-start` في صفحة `dir="rtl"` = `margin-right`.
3. لو المتصفح مش فاهم خاصية CSS، الصفحة كلها بتبوظ.

### أسئلة مراجعة

1. إزاي تغيّر متغير CSS من JavaScript؟ وليه ده مستحيل مع Sass؟
2. اكتب Selector بـ `:has()` يختار أي `li` فيه لينك.
3. حوّل للـ Logical: `padding-left: 1rem; border-right: 1px solid; text-align: left;`
4. إيه الفرق بين Baseline Newly و Widely available؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** اعمل زرار بلونه الأساسي في `--brand`، و3 نسخ بتغيّر المتغير بس: `.danger` و`.success` و`.muted`.
2. **[متوسط]** اعمل زرار Dark/Light بالـ JS يغيّر Attribute على الـ `html` (`data-theme="dark"`)، والـ CSS يغيّر المتغيرات بس جوه `[data-theme="dark"]`.
3. **[صعب]** اعمل Form يقفل زرار الإرسال بالـ CSS بس (`:has()` و`:user-invalid`)، من غير ولا سطر JS، واتأكد من Baseline لكل Selector استخدمته على MDN.
