<small>المرحلة 2 · لغة Python</small>

كل اسكريبت AI في الدنيا بيلف حوالين نوعين بيانات: نصوص (الـ Prompt والرد)، و Dictionaries (الـ JSON). الفصل ده بيعرّفك على كل نوع هتقابله، وإزاي تقرا الأقواس والنقط والـ \[ \] اللي في كل حتة.

:::note[بعد الفصل ده هتكون عارف]
- يعني إيه Variable و = في Python
- الأنواع: str و int و float و bool و None
- الـ List والـ Dict والـ Tuple والـ Set، وإمتى كل واحد
- تقرا d\["key"\] و d.get("key") والفرق بينهم
- الـ Slicing زي text\[:500\]
- الـ f-strings بالتنسيق، والنصوص متعددة السطور """ """
:::

## 4.1 الـ Variable = اسم بيشاور على قيمة

في Python مفيش `let` ولا `const`. أول ما تكتب `x = 5` بيتعمل المتغير. واسمه بيشاور على القيمة، ومفيش نوع ثابت ليه: ممكن تحط فيه رقم دلوقتي ونص بعدين (بس متعملش كده، بيلخبط اللي بيقرا).

```python
model = "gpt-6-luna"      # str  : نص
max_files = 200           # int  : رقم صحيح
price_per_mtok = 0.10     # float: رقم بكسور
dry_run = True            # bool : True أو False
api_key = None            # None : "مفيش قيمة"
```

**الأنواع الأساسية ومقابلها في JavaScript**

| Python | مثال | JavaScript | خد بالك |
|---|---|---|---|
| `str` | `"hi"` أو `'hi'` | string | الاتنين علامات واحد |
| `int` / `float` | `3` / `3.5` | number | في Python نوعين منفصلين |
| `bool` | `True` / `False` | `true` / `false` | بحرف كبير في Python |
| `None` | `None` | `null` | مفيش undefined في Python |
| `list` | `[1, 2]` | Array | نفس الشكل |
| `dict` | `{"a": 1}` | Object | المفتاح لازم بين علامات |

## 4.2 النصوص: أهم نوع في اسكريبتات الـ AI

الـ Prompt نص، والرد نص، ومحتوى الملفات نص. فخلّينا نقرا كل اللي ممكن يتعمل فيه:

```python title="عمليات على النصوص"
text.strip()
text.lower()
text.split("\n")
", ".join(names)
text.replace("\r", "")
"error" in text
len(text)
```

1. `text.strip()`: يشيل المسافات والسطور الفاضية من الأول والآخر. بتلاقيه كتير على رد الموديل.
2. `text.lower()`: كل الحروف small. مفيد للمقارنة: `answer.lower() == "yes"`.
3. `text.split("\n")`: يقطّع النص لـ List عند كل سطر جديد. والـ `\n` رمز "سطر جديد".
4. `", ".join(names)`: العكس: يلزق List نصوص مع بعض، وبينهم `", "`. شكلها غريب بس شائعة جداً.
5. `text.replace("\r", "")`: يبدّل كل ظهور لحاجة بحاجة.
6. `"error" in text`: `in` = "موجود جوه؟". بترجّع True أو False.
7. `len(text)`: عدد الحروف (مش التوكنز، دي حاجة تانية خالص، فصل 14).

### الـ Slicing: \[start:end\]

**تشريح الأمر**

```python
preview = text[:500]
```

1. `text`: النص الأصلي.
2. `[`: بداية "هات حتة".
3. `:`: فاصل بين البداية والنهاية. البداية فاضية = من الأول.
4. `500`: لحد الحرف رقم 500 (من غيره). يعني أول 500 حرف. بتتستخدم كتير علشان تقص نص طويل قبل ما تبعته للموديل.

| الأمر | بيعمل إيه |
|---|---|
| `text[0]` | أول حرف. العدّ بيبدأ من **0** زي JS. |
| `text[-1]` | آخر حرف. السالب بيعدّ من الآخر (مش موجودة في JS بالشكل ده). |
| `text[100:200]` | من 100 لـ 199. |
| `text[-300:]` | آخر 300 حرف. |
| `items[:10]` | نفس الكلام على List: أول 10 عناصر. مفيد علشان تجرّب على 10 ملفات بس قبل الكل. |

### الـ f-strings بالتنسيق

**تشريح الأمر**

```python
print(f"{name:<20} {cost:.4f}$ {tokens:,}")
```

1. `f"`: f-string: اللي بين `{ }` بيتحسب ويتحط.
2. `{name:<20}`: بعد الـ `:` بييجي "التنسيق". و`<20` = خليه 20 خانة متساب على الشمال. بيعمل جداول مترتبة في الـ Terminal.
3. `{cost:.4f}`: `.4f` = رقم عشري بـ 4 أرقام بعد العلامة: `0.0123`. مهم جداً في التكاليف لأنها أرقام صغيرة.
4. `{tokens:,}`: الفاصلة = حط فواصل الآلاف: `1,048,576`.

### النصوص متعددة السطور: بيت الـ Prompts

```python
SYSTEM_PROMPT = """You are an editor.
Rewrite the text in clear, simple English.
Return only the rewritten text."""
```

التلات علامات `"""` بتبدأ نص يكمّل على أكتر من سطر لحد التلات علامات اللي بعدها. هتلاقيها في كل اسكريبت AI تقريباً، لأن الـ Prompts طويلة. ولو لقيتها أول سطر جوه فانكشن، تبقى اسمها **Docstring**: شرح للفانكشن.

:::tip[حاجة مشتركة: Template literals]
في JS بتكتب نفس الكلام بـ backticks: `` `line1\nline2 ${x}` ``. وفي Python لو عايز متعدد السطور ومتغيرات مع بعض: `f"""...{x}..."""`.
:::

**المصادر الرسمية:** [docs.python.org · String methods](https://docs.python.org/3/library/stdtypes.html#string-methods) · [f-strings](https://docs.python.org/3/reference/lexical_analysis.html#f-strings) · [Format spec mini-language](https://docs.python.org/3/library/string.html#formatspec)

## 4.4 الـ Dict: مفتاح وقيمة… شكل JSON بالظبط

الـ Dictionary هو أهم نوع بعد النص، لأن أي JSON بيرجع من API بيتحوّل لـ dict. وأي إعدادات بتتبعت لموديل بتبقى dict.

```python
row = {"file": "a.md", "tokens": 812, "tags": ["ai", "draft"]}
```

```python title="قراية الـ dict"
row["file"]
row.get("lang")
row.get("lang", "en")
row["status"] = "ok"
row["tags"][0]
for key, value in row.items():
"file" in row
```

1. `row["file"]`: هات قيمة المفتاح `"file"`. **ولو المفتاح مش موجود: KeyError** والاسكريبت يقف.
2. `row.get("lang")`: نفس الكلام، بس لو مش موجود بيرجّع `None` من غير خطأ.
3. `row.get("lang", "en")`: لو مش موجود رجّع `"en"` كقيمة افتراضية.
4. `row["status"] = "ok"`: زوّد مفتاح جديد أو غيّر قيمة موجودة.
5. `row["tags"][0]`: متداخل: هات `tags` (List)، ومنها أول عنصر `"ai"`. اقرا من الشمال لليمين، خطوة خطوة.
6. `for key, value in row.items():`: لف على كل مفتاح وقيمته مع بعض. `.items()` بترجّع أزواج.
7. `"file" in row`: هل المفتاح موجود؟

:::caution[data["choices"][0]["message"]["content"]]
هتشوف سلاسل زي دي كتير لما حد بيقرا JSON بإيده من API. اقراها خطوة خطوة: خد `choices` (List)، أول عنصر فيها `[0]` (dict)، منه `message` (dict)، ومنه `content` (نص). ولو أي حلقة في السلسلة مش موجودة، هيطلع `KeyError` أو `IndexError`. والـ SDKs الرسمية بتريّحك من ده بـ Objects ونقط بدل الأقواس (فصل 8).
:::

:::tip[حاجة مشتركة: Object في JS]
`row["file"]` = `row.file` أو `row["file"]` في JS. الفرق المهم: في JS المفتاح الغلط بيرجّع `undefined` بهدوء، وفي Python بيرمي `KeyError`. وأقرب حاجة لـ `row.lang ?? "en"` في Python هي `row.get("lang", "en")`.
:::

## 4.5 Tuple و Set و None و "الصح والغلط"

#### Tuple: (a, b)

زي List بس مبيتغيرش. هتشوفه لما فانكشن ترجّع أكتر من قيمة: `text, tokens = read(path)`. ده اسمه **Unpacking**: كل قيمة تروح في متغير.

#### Set: {a, b}

مجموعة من غير تكرار. مثال: `done = set()` و`done.add(name)` و`if name in done:`. بتستخدم كتير علشان تعرف "خلّصت الملف ده قبل كده؟".

#### None

"مفيش". اختبرها بـ `if x is None:` مش `==`. فانكشن ملهاش `return` بترجّع None.

#### Truthy و Falsy

`if text:` معناها "لو النص مش فاضي". والحاجات اللي بتتحسب False: `""` و`0` و`[]` و`{}` و`None`.

### تحويل من نوع لنوع

| الأمر | بيعمل إيه |
|---|---|
| `int("42")` | نص لرقم. ولو النص مش رقم: `ValueError`. |
| `float("0.75")` | نص لرقم عشري (مفيد لما تقرا أسعار من CSV). |
| `str(812)` | رقم لنص. |
| `type(x)` | يقولك نوع أي حاجة. جرّبه في الـ REPL على أي رد من الـ SDK. |

**المصادر الرسمية:** [docs.python.org · Data Structures](https://docs.python.org/3/tutorial/datastructures.html) · [Built-in Types](https://docs.python.org/3/library/stdtypes.html)

:::tip[ملخص الفصل]
- `x = ...` بتعمل المتغير. الأنواع: str و int و float و bool و None.
- النص: `.strip()` و`.split()` و`"".join()` و`in`، والـ Slicing `text[:500]`.
- الـ f-strings: `{x:.4f}` و`{n:,}`، و`"""` للـ Prompts الطويلة.
- الـ dict = JSON. `d["k"]` بيرمي KeyError، و`d.get("k", default)` مبيرميش.
- اقرا السلاسل `a["x"][0]["y"]` خطوة خطوة.
:::

### صح ولا غلط؟

1. `text[-1]` بترجّع آخر حرف في النص.
2. `{"a": 1}.get("b")` بترمي KeyError.
3. `if []:` الشرط ده بيتحقق.

### أسئلة مراجعة

1. إيه الفرق بين `"5" + "5"` و`5 + 5`؟ جرّبهم في الـ REPL.
2. اشرح `f"{cost:.4f}"` حتة حتة.
3. إمتى تستخدم `d["k"]` وإمتى `d.get("k")`؟
4. اقرا: `resp["data"][0]["embedding"][:5]` خطوة خطوة.
