Screenshots لازم توصفها، و PDF عايز ملخصه، وصورة منتج محتاجة Alt text. الفصل ده بيشرح إزاي تبعت صورة أو ملف للموديل في OpenAI وفي Gemini: يعني إيه Base64، وإمتى تبعت الملف جوه الطلب وإمتى ترفعه الأول، والحدود الرسمية لكل واحد.

:::note[بعد الفصل ده هتكون عارف]
- bytes و Base64 و Data URL: يعني إيه ولازمتهم إيه
- OpenAI: input\_image (image\_url / file\_id) و detail
- OpenAI: input\_file لـ PDF (file\_data / file\_id / file\_url) و files.create(purpose="user\_data")
- Gemini: types.Part.from\_bytes و client.files.upload و حذف الملفات
- الحدود الرسمية: الحجم وعدد الصفحات والصلاحية
- اسكريبت Alt text لفولدر صور
:::

## 23.1 الصورة مش نص… فهنبعتها إزاي في JSON؟

الطلب للـ API هو JSON، والـ JSON نص. والصورة **bytes**: أرقام من 0 لـ 255، كتير منها ملوش شكل كحرف. فالحل القديم والمعروف: **Base64**، وهو إنك تحوّل أي bytes لنص من 64 حرف آمن (A–Z a–z 0–9 + /). والحجم بيكبر حوالي الثلث، بس بقى نص تقدر تحطه في JSON. والحل التاني: **ترفع الملف الأول** وتاخد ID، وتبعت الـ ID بس.

```python
>>> from pathlib import Path
>>> import base64
>>> data = Path("logo.png").read_bytes()
>>> data[:8]
b'\x89PNG\r\n\x1a\n'
>>> b64 = base64.b64encode(data).decode("utf-8")
>>> b64[:12]
'iVBORw0KGgoA'
>>> f"data:image/png;base64,{b64}"[:34]
'data:image/png;base64,iVBORw0KGgoA'
```

| الأمر | بيعمل إيه |
|---|---|
| `Path(...).read_bytes()` | اقرا الملف كـ `bytes` (لاحظ الـ `b'...'`). مش `read_text`، لأن الصورة مش نص. |
| `base64.b64encode(data)` | بيرجّع `bytes` فيها حروف Base64 بس. |
| `.decode("utf-8")` | حوّلها لـ `str` علشان تتحط في JSON. |
| `data:image/png;base64,…` | **Data URL**: "ده مش لينك، ده الملف نفسه، نوعه png ومتشفّر Base64". وده الشكل اللي OpenAI عايزه في `image_url`. |

:::tip[حاجة مشتركة: JS]
في Node: `fs.readFileSync(path, "base64")` بترجّع Base64 على طول. وفي المتصفح: `FileReader.readAsDataURL(file)` بترجّع Data URL، وهي نفس `data:image/png;base64,...` اللي فوق.
:::

## 23.2 OpenAI: الصور

```python
import base64, mimetypes
from pathlib import Path

def image_part(path: Path, detail: str = "auto") -> dict:
    mime = mimetypes.guess_type(path.name)[0] or "image/jpeg"
    b64 = base64.b64encode(path.read_bytes()).decode("utf-8")
    return {"type": "input_image", "image_url": f"data:{mime};base64,{b64}", "detail": detail}

response = client.responses.create(
    model="gpt-6-luna",
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": "Write alt text (max 125 chars)."},
            image_part(Path("hero.jpg")),
        ],
    }],
)
print(response.output_text)
```

```python title="الجديد هنا"
mimetypes.guess_type(path.name)[0]
"content": [ {...input_text...}, {...input_image...} ]
"detail": "auto"
```

1. `mimetypes.guess_type(path.name)[0]`: مكتبة جاهزة بتخمّن النوع من الامتداد: `"hero.jpg"` بتدّي `("image/jpeg", None)`، و`[0]` بياخد الأول. ولو مش عارف، بيرجّع `None`، فالـ `or` بيدّي قيمة افتراضية.
2. `"content": [ {...input_text...}, {...input_image...} ]`: الـ `content` بقى **List أجزاء** بدل نص واحد. تقدر تحط نص وكذا صورة بالترتيب اللي يناسبك.
3. `"detail": "auto"`: بيتحكم في معالجة الصورة: `low` أو `high` أو `original` أو `auto` (حسب الموديل)، والافتراضي `auto`. و`low` = Tokens أقل، كويس للـ Alt text البسيط.

وفي طريقتين تانيين لنفس الـ `input_image`: `"image_url": "https://..."` لصورة على الإنترنت، أو ترفع الصورة بـ `client.files.create(file=open(p, "rb"), purpose="vision")` وتبعت `"file_id": file.id`.

**حدود الصور في OpenAI (الدوكيومنتيشن، أكتوبر 2026)**

| البند | الحد |
|---|---|
| الأنواع | PNG و JPEG و WEBP و GIF غير متحرك |
| حجم الطلب | لحد 512 MB للطلب كله |
| عدد الصور | لحد 1,500 صورة في الطلب |
| ملاحظة | الصورة بتتحسب Tokens، ولازم تدخل في الـ Context مع باقي الطلب |

**المصادر الرسمية:** [OpenAI · Images and vision](https://developers.openai.com/api/docs/guides/images-vision)

## 23.3 OpenAI: PDF وملفات

```python
# (1) جوه الطلب بـ Base64
pdf_b64 = base64.b64encode(Path("report.pdf").read_bytes()).decode("utf-8")
file_part = {"type": "input_file", "filename": "report.pdf",
             "file_data": f"data:application/pdf;base64,{pdf_b64}"}

# (2) أو ارفعه الأول وابعت الـ ID
uploaded = client.files.create(file=open("report.pdf", "rb"), purpose="user_data")
file_part = {"type": "input_file", "file_id": uploaded.id}

response = client.responses.create(
    model="gpt-6-luna",
    input=[{"role": "user", "content": [
        file_part,
        {"type": "input_text", "text": "Summarize in 5 bullet points."},
    ]}],
)
```

- **PDF**: على الموديلات اللي بتشوف، الـ API بيستخرج **النص وصور الصفحات** الاتنين. وفي `detail` لـ `input_file` كمان (`low` أرخص).
- **docx و pptx و txt والكود**: نص بس، والصور والـ Charts اللي جواهم مش بتوصل. فلو الـ Charts مهمة، حوّل لـ PDF.
- **xlsx و csv**: الـ API بيقرا لحد أول 1,000 صف في كل Sheet، ويعمل ملخص. وده مش بديل إنك تقرا الملف بـ pandas بنفسك (فصل 10).
- **Chat Completions** بياخد PDF بس كـ `file`. وأي نوع تاني، استخدم Responses.
- كل ملف أقل من 50 MB، والمجموع في الطلب 50 MB.

**المصادر الرسمية:** [OpenAI · File inputs](https://developers.openai.com/api/docs/guides/file-inputs)

## 23.4 Gemini: from\_bytes و files.upload

```python
from google.genai import types

# (1) جوه الطلب: bytes على طول، من غير Base64 بإيدك
response = client.models.generate_content(
    model="gemini-3.8-flash",
    contents=[
        types.Part.from_bytes(data=Path("hero.jpg").read_bytes(), mime_type="image/jpeg"),
        "Write alt text (max 125 chars).",
    ],
)

# (2) ارفع الأول (للملفات الكبيرة أو اللي هتستخدمها كذا مرة)
doc = client.files.upload(file="report.pdf")
response = client.models.generate_content(
    model="gemini-3.8-flash",
    contents=[doc, "Summarize in 5 bullet points."],
)
client.files.delete(name=doc.name)    # نضّف ورا نفسك
```

**تشريح الأمر**

```python
types.Part.from_bytes(data=..., mime_type="image/jpeg")
```

1. `data=`: الـ `bytes` نفسها. والـ SDK بيعمل الـ Base64 لوحده.
2. `mime_type=`: إجباري هنا، لأن الـ bytes مفيهاش اسم ملف.
3. `contents=[part, "text"]`: List فيها Part ونص عادي مع بعض، والـ SDK بيحوّل النص لـ Part لوحده.

**حدود Gemini (الدوكيومنتيشن، أكتوبر 2026)**

| البند | الحد |
|---|---|
| صور inline | صفحة الصور بتقول: الطلب كله (نص + bytes) أقل من 20MB |
| إمتى Files API إجباري | صفحة الـ Files بتقول: لما الطلب كله أكبر من 100 MB، ولـ PDF الحد 50 MB |
| PDF | لحد 50MB أو 1000 صفحة، والصفحة ≈ 258 Token |
| تخزين Files API | 20 GB للمشروع، و2 GB للملف، **وبيتمسح بعد 48 ساعة** |

:::caution[خلي بالك]
صفحتين في دوكيومنتيشن Google بيدّوا رقمين مختلفين للـ inline (20MB في صفحة الصور، و100 MB في صفحة الـ Files). فالآمن: <strong>أي حاجة فوق كام MB ارفعها بـ `files.upload`</strong>. وكمان: الملفات المرفوعة مبتتنزّلش تاني، وبتتمسح بعد 48 ساعة، فمتعتمدش عليها كمخزن.
:::

**المصادر الرسمية:** [Gemini · Image understanding](https://ai.google.dev/gemini-api/docs/image-understanding) · [Gemini · Document processing](https://ai.google.dev/gemini-api/docs/document-processing) · [Gemini · Files API](https://ai.google.dev/gemini-api/docs/files)

## 23.5 اسكريبت: Alt text لفولدر صور

```python title="alt_text.py"
import csv, mimetypes
from pathlib import Path
from google import genai
from google.genai import types

client = genai.Client()
MODEL = "gemini-3.5-flash-lite"
IMAGES = Path("images")
EXTS = {".png", ".jpg", ".jpeg", ".webp"}
PROMPT = "Write one alt text sentence for this image. Max 125 characters. No 'image of'."

rows = []
for path in sorted(IMAGES.iterdir()):
    if path.suffix.lower() not in EXTS:
        continue
    if path.stat().st_size > 15 * 1024 * 1024:
        print("skip (too big):", path.name)
        continue
    mime = mimetypes.guess_type(path.name)[0] or "image/jpeg"
    response = client.models.generate_content(
        model=MODEL,
        contents=[types.Part.from_bytes(data=path.read_bytes(), mime_type=mime), PROMPT],
    )
    alt = (response.text or "").strip()
    rows.append({"file": path.name, "alt": alt})
    print(path.name, "->", alt)

with open("alt_text.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.DictWriter(f, fieldnames=["file", "alt"])
    writer.writeheader()
    writer.writerows(rows)
```

| الأمر | بيعمل إيه |
|---|---|
| `path.suffix.lower() not in EXTS` | فلتر بالامتداد. و`.lower()` علشان `.JPG` من الموبايل. و`EXTS` هنا **set** (أقواس معقوفة من غير `:`)، والبحث فيه سريع. |
| `path.stat().st_size > 15 * 1024 * 1024` | الحجم بالـ bytes. و`15 * 1024 * 1024` = ‎15 MB. ابعد عن حد الـ 20MB بهامش. |
| `(response.text or "").strip()` | لو `text` طلع `None` (رفض مثلاً)، متقعش في `.strip()`. |
| `encoding="utf-8-sig"` | علشان Excel يفتح الـ CSV صح (فصل 10). |

:::note[على الماك]
صور الـ iPhone غالباً `.HEIC`، ودي مش في قايمة OpenAI. حوّلها بأداة الماك المدمجة: `sips -s format jpeg in.HEIC --out out.jpg`، أو لفولدر كامل: `for f in *.HEIC; do sips -s format jpeg "$f" --out "${f%.HEIC}.jpg"; done`.
:::

:::tip[ملخص الفصل]
- الملفات bytes. و Base64 بيحوّلها لنص يتحط في JSON، و Data URL = `data:mime;base64,...`.
- OpenAI: `input_image` (Data URL أو لينك أو `file_id`)، و`input_file` للـ PDF والمستندات، و`files.create(purpose="user_data")`.
- Gemini: `types.Part.from_bytes` للصغير، و`client.files.upload` للكبير (بيتمسح بعد 48 ساعة).
- اتأكد من النوع والحجم قبل ما تبعت، وخلي `detail` منخفض لو مش محتاج تفاصيل.
:::

### صح ولا غلط؟

1. Base64 بيصغّر حجم الصورة.
2. في Gemini لازم تعمل Base64 بإيدك قبل `Part.from_bytes`.
3. الملفات المرفوعة على Gemini Files API بتفضل لحد ما تمسحها.

### أسئلة مراجعة

1. إيه الفرق بين `read_bytes()` و`read_text()`؟ وإمتى كل واحدة؟
2. عندك PDF فيه Charts مهمة، وملف docx فيه نفس الـ Charts. أنهي تبعته لـ OpenAI؟ وليه؟
3. إمتى ترفع الملف بدل ما تبعته جوه الطلب؟
