<small>المرحلة 6 · على نطاق واسع وبأمان</small>

الفاتورة بتتحسب Token بـ Token، والـ Output أغلى من الـ Input بخمس مرات تقريباً، و Tokens التفكير بتتحسب Output. الفصل ده بيعلّمك تحسب التكلفة بالأرقام الرسمية قبل ما تشغّل، وتعدّ الـ Tokens (تقدير أو بالظبط)، وتقرا usage بعد كل طلب، وبعدين 9 طرق توفّر بيها، من الـ Caching للـ Batch لاختيار الموديل.

:::note[بعد الفصل ده هتكون عارف]
- معادلة التكلفة: input و cached و output لكل مليون
- عدّ الـ Tokens: قاعدة 4 حروف، و responses.input\_tokens.count، و models.count\_tokens
- قراية usage و usage\_metadata بعد الطلب
- Prompt caching: الـ Prefix الثابت في الأول، والحد الأدنى، وسعر الكتابة في GPT-6
- Batch و Flex: نص السعر
- اسكريبت estimate\_cost.py قبل أي تشغيل كبير
:::

<a id="s27-1"></a>

## 27.1 الفاتورة اللي محدش توقعها

الحكاية المعتادة: اسكريبت اشتغل كويس على 5 ملفات، بكام سنت. وبعدين اتشغّل على 3000 ملف بموديل كبير، و Reasoning عالي، و Prompt طويل بيتكرر في كل طلب، وفي الآخر فاتورة بمئات الدولارات. ومفيش حاجة فيه "غلط"، بس محدش حسب. والحل بسيط: **اضرب قبل ما تشغّل**.

## 27.2 المعادلة

:::tip[التكلفة لطلب واحد]
`cost = (fresh_input × سعر_input + cached_input × سعر_cached + output × سعر_output) ÷ 1,000,000`<br>والأسعار في الجداول الرسمية **لكل مليون Token**. و`output` فيه Tokens التفكير كمان: Google بتكتب في جدول الأسعار "Output price (including thinking tokens)"، و OpenAI بتقول في دليل الـ Reasoning إن الـ Reasoning tokens مش بتظهر بس بتتحاسب عليها كـ Output.
:::

**أسعار مختارة (Standard، لكل مليون Token، الدوكيومنتيشن الرسمية، 23 أكتوبر 2026)**

| الموديل | Input | Cached input | Output | ملاحظة |
|---|---|---|---|---|
| `gpt-6-luna` | $0.10 | $0.01 | $0.50 | Batch/Flex: ‏$0.05 / $0.25 |
| `gpt-6.1-sol` | $2.00 | $0.10 | $10.00 |   |

### مثال بالأرقام

2000 مقال، كل واحد ~1000 Token + System prompt بـ 500 Token، والرد ~200 Token:

- Input = 2000 × 1500 = **3,000,000**، و Output = 2000 × 200 = **400,000**.
- `gpt-6-luna`: ‏3 × 0.10 + 0.4 × 0.50 = 0.30 + 0.20 = **$0.50**.
- `gemini-3.8-flash`: ‏3 × 0.75 + 0.4 × 3.75 = 2.25 + 1.50 = **$3.75**.
- `gpt-6-astra`: ‏3 × 10 + 0.4 × 50 = **$50**.
- ولو الموديل بيفكّر و Reasoning بيطلع 2000 Token لكل مقال، الـ Output بقى 4.4 مليون: Luna بقت 0.30 + 2.20 = **$2.50**. يعني التفكير **خمّس** التكلفة.

**المصادر الرسمية:** [OpenAI · Pricing](https://developers.openai.com/api/docs/pricing) · [Gemini · Pricing](https://ai.google.dev/gemini-api/docs/pricing)

## 27.3 عدّ الـ Tokens

**3 طرق، من الأرخص للأدق**

| الطريقة | إزاي | الدقة |
|---|---|---|
| تقدير | `len(text) // 4` (Google: ‏Token ≈ 4 حروف، و100 Token ≈ ‏60–80 كلمة إنجليزي) | تقريبي للإنجليزي. والعربي غالباً Tokens أكتر لنفس الطول، فاعمل هامش وقيس على عينة |
| API للعدّ | OpenAI: `client.responses.input_tokens.count(model=, input=)`. Gemini: `client.models.count_tokens(model=, contents=)` | دقيق، وبيحسب الصور والـ Tools والـ Schema |
| بعد الطلب | OpenAI: `response.usage`. Gemini: `response.usage_metadata` | دي الأرقام اللي هتدفع بيها |

```python
# OpenAI
count = client.responses.input_tokens.count(model="gpt-6-luna", input=text)
print(count.input_tokens)

u = response.usage
print(u.input_tokens, u.input_tokens_details.cached_tokens,
      u.output_tokens, u.output_tokens_details.reasoning_tokens)

# Gemini
print(client.models.count_tokens(model="gemini-3.8-flash", contents=text).total_tokens)

m = response.usage_metadata
print(m.prompt_token_count, m.cached_content_token_count,
      m.candidates_token_count, m.thoughts_token_count)
```

| الأمر | بيعمل إيه |
|---|---|
| `input_tokens_details.cached_tokens` | جزء من الـ Input اتقرا من الـ Cache، بسعر أقل. |
| `output_tokens_details.reasoning_tokens` | Tokens التفكير. **مش بتشوفها** في `output_text`، بس داخلة في `output_tokens` وبتدفعها. |
| `prompt_token_count / candidates_token_count` | Input و Output في Gemini. و`thoughts_token_count` = التفكير، وبيتحسب بسعر الـ Output. |

OpenAI بتقول إن الـ Tokenizers المحلية زي `tiktoken` كويسة للنص بس، ومش بتحسب الصور والملفات والـ Tools والـ Schemas صح، وعلشان كده عملوا الـ Endpoint بتاع العدّ.

**المصادر الرسمية:** [OpenAI · Token counting](https://developers.openai.com/api/docs/guides/token-counting) · [Gemini · Tokens](https://ai.google.dev/gemini-api/docs/tokens)

## 27.4 estimate\_cost.py: شغّله قبل أي حاجة كبيرة

```python title="estimate_cost.py"
import argparse
from pathlib import Path

# USD per 1M tokens, Standard tier, short context. Checked 2026-10-23.
PRICES = {
    "gpt-6-luna": {"input": 0.10, "cached": 0.01, "output": 0.50},
    "gpt-6.1-sol": {"input": 2.00, "cached": 0.10, "output": 10.00},
    "gemini-3.8-flash": {"input": 0.75, "cached": 0.075, "output": 3.75},
    "gemini-3.5-flash-lite": {"input": 0.30, "cached": None, "output": 2.50},
}

def estimate_tokens(text: str) -> int:
    return max(1, len(text) // 4)

def cost(model: str, input_tokens: int, output_tokens: int, cached_tokens: int = 0) -> float:
    p = PRICES[model]
    fresh = input_tokens - cached_tokens
    cached_price = p["cached"] if p["cached"] is not None else p["input"]
    return (fresh * p["input"] + cached_tokens * cached_price + output_tokens * p["output"]) / 1_000_000

def main() -> None:
    parser = argparse.ArgumentParser(description="Estimate API cost before running.")
    parser.add_argument("folder", type=Path)
    parser.add_argument("--system-file", type=Path)
    parser.add_argument("--output-tokens", type=int, default=300)
    parser.add_argument("--glob", default="*.md")
    args = parser.parse_args()

    system = args.system_file.read_text(encoding="utf-8") if args.system_file else ""
    files = sorted(args.folder.glob(args.glob))
    total_in = sum(estimate_tokens(system + f.read_text(encoding="utf-8")) for f in files)
    total_out = args.output_tokens * len(files)
    print(f"{len(files)} files, ~{total_in:,} input tokens, ~{total_out:,} output tokens")
    for model in PRICES:
        standard = cost(model, total_in, total_out)
        print(f"{model:24} ${standard:8.4f}   batch ~${standard / 2:8.4f}")

if __name__ == "__main__":
    main()
```

```python title="الحاجات المهمة"
# USD per 1M tokens, Standard tier, short context. Checked 2026-10-23.
max(1, len(text) // 4)
p["cached"] if p["cached"] is not None else p["input"]
sum(estimate_tokens(...) for f in files)
f"{model:24} ${standard:8.4f}"
```

1. `# USD per 1M tokens, Standard tier, short context. Checked 2026-10-23.`: أهم سطر: من فين الأرقام وإمتى. وبعد 3 شهور هتعرف إنها محتاجة تتحدّث.
2. `max(1, len(text) // 4)`: `//` قسمة صحيحة. و`max(1, …)` علشان ملف فاضي ميبقاش صفر.
3. `p["cached"] if p["cached"] is not None else p["input"]`: لو مفيش سعر Cache معروف، احسب بالسعر العادي (التقدير الأسوأ). و`is not None` مش `if p["cached"]`، علشان سعر `0.0` ميتعاملش كـ "مفيش".
4. `sum(estimate_tokens(...) for f in files)`: Generator expression جوه `sum` من غير List في النص.
5. `f"{model:24} ${standard:8.4f}"`: Format spec: `:24` = عرض 24 حرف (عمود مترتب)، و`:8.4f` = عرض 8 و4 أرقام بعد العلامة، و`:,` = فاصل آلاف.

## 27.5 9 طرق توفّر بيها

1. <strong>اختار الموديل الصغير الأول.</strong> جرّب `gpt-6-luna` أو `gemini-3.5-flash-lite` على 20 عينة، وكبّر بس لو الجودة مش كفاية. والفرق ممكن يبقى 100 ضعف (Luna مقابل Astra).
2. <strong>قلّل التفكير.</strong> `reasoning={"effort": "low"}` أو `"none"` في OpenAI، و`thinking_config` في Gemini (فصل 14). والتلخيص والتصنيف مش محتاجين تفكير عالي.
3. <strong>حط سقف للـ Output.</strong> `max_output_tokens`، واطلب الطول في الـ Prompt ("max 2 sentences"). و Structured output بحقول قصيرة بيقلّل الكلام الزيادة.
4. <strong>قصّ الـ Input.</strong> ابعت اللي محتاجه بس: `text[:20_000]`، شيل الـ HTML والـ Boilerplate، وفي RAG ابعت أحسن 3 Chunks مش الملف كله (فصل 24).
5. <strong>Prompt caching: الثابت في الأول.</strong> الـ System prompt والأمثلة (Few-shot) في **أول** الطلب وبنفس النص بالظبط، والمتغير (الملف) في الآخر. والاتنين بيعملوا Caching تلقائي للـ Prefix المتكرر: <br>· OpenAI (GPT-5.6 وبعده): الحد الأدنى 1,024 Token، والقراية بـ 0.1× سعر الـ Input، **بس الكتابة بـ 1.25×** (‏`"30m"` الافتراضي) أو 2.5× (‏`"12h"`) عن طريق `prompt_cache_options`. يعني الـ Cache بيكسب لو الـ Prefix اتقرا كذا مرة. <br>· Gemini (implicit، شغال لوحده): الحد الأدنى 4,096 Token لـ 3.x و 4 Argon، والـ Cached بـ 0.1× (‏$0.075 لـ 3.8 Flash). وابعت الطلبات اللي ليها نفس الـ Prefix ورا بعض في وقت قصير.
6. **Batch API = نص السعر** لأي حاجة مش مستعجلة (فصل 26).
7. **Flex في OpenAI**: ‏`service_tier="flex"` = سعر الـ Batch تقريباً بس بطلب عادي، أبطأ وممكن يرجّع "مفيش موارد" (Beta، وموديلات محددة). وزوّد الـ Timeout.
8. <strong>متعيدش اللي خلص.</strong> الـ Resume (فصل 26) بيوفّر فلوس مش وقت بس. و Retries على 400 = فلوس على الأرض.
9. <strong>حط حد للصرف.</strong> Budget في OpenAI (و Hard limit بيرجّع 429)، و Spend cap في Gemini حسب الـ Tier، وفي OpenRouter رصيد مسبق (فصل 19).

:::note[خلي الاسكريبت يحسب وهو شغال]
ضيف `input_tokens` و`output_tokens` لكل سطر في `results.jsonl` (زي `run_many.py`)، وفي الآخر: `total = sum(cost(MODEL, r["input_tokens"], r["output_tokens"]) for r in rows)`. وتقدر كمان تحط `--budget 2.0` يوقف الاسكريبت لو المجموع عدّاه. وفي OpenRouter التكلفة جاهزة: `getattr(completion.usage, "cost", None)`.
:::

:::tip[حاجة مشتركة: JS]
الـ `usage` في JS نفس الأسماء: `response.usage.input_tokens` و`output_tokens_details.reasoning_tokens`، وفي Gemini JS: `response.usageMetadata.promptTokenCount` (camelCase). وتنسيق الأرقام: `cost.toFixed(4)` بدل `:.4f`.
:::

**المصادر الرسمية:** [OpenAI · Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching) · [OpenAI · Flex processing](https://developers.openai.com/api/docs/guides/flex-processing) · [Gemini · Caching](https://ai.google.dev/gemini-api/docs/caching)

:::tip[ملخص الفصل]
- التكلفة = (input × سعر + cached × سعر + output × سعر) ÷ مليون، والتفكير داخل في الـ Output.
- قدّر بـ `len // 4`، واعرف بالظبط بـ `input_tokens.count` / `count_tokens`، واقرا `usage` بعد كل طلب.
- حط الأسعار في الكود بتاريخها، وشغّل `estimate_cost.py` قبل أي تشغيل كبير.
- وفّر بـ: موديل أصغر، وتفكير أقل، وسقف Output، وInput أقصر، والثابت في الأول للـ Cache، و Batch/Flex، و Resume، وحد صرف.
:::

### صح ولا غلط؟

1. Tokens التفكير مجانية لأنها مش بتظهر في الرد.
2. في GPT-6 كتابة الـ Cache أغلى من الـ Input العادي.
3. علشان الـ Caching يشتغل، حط اسم الملف المتغير في أول الـ Prompt.

### أسئلة مراجعة

1. احسب تكلفة 10,000 طلب، كل واحد 800 Token Input و150 Output، على `gemini-3.8-flash` (قبل وبعد 1 يناير 2027).
2. ليه `len(text) // 4` ممكن يبقى أقل من الحقيقة مع النص العربي؟ وتتأكد إزاي؟
3. رتّب أجزاء الطلب ده علشان الـ Cache: (المقال، والـ System prompt، و3 أمثلة).
