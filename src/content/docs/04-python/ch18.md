<small>المرحلة 4 · أساسيات الـ AI</small>

دلوقتي انت عارف الـ SDKين. الفصل ده جدول ترجمة: كل مفهوم، واسمه في OpenAI، واسمه في Gemini. وبعدين نفس الاسكريبت مكتوب بالاتنين، وفي الآخر نمط بسيط يخلّي اسكريبتك يشتغل مع الاتنين بتغيير كلمة واحدة.

:::note[بعد الفصل ده هتكون عارف]
- جدول ترجمة كامل بين openai و google-genai
- نفس المهمة مكتوبة بالاتنين سطر قصاد سطر
- الفروق اللي بتوقّع الناس: timeout بالملّي، و text ممكن None، و temperature
- نمط ask(provider, ...) اللي يفصل اسكريبتك عن الشركة
:::

## 18.2 نفس الاسكريبت بالاتنين

المهمة: خد عنوان مقالة، ورجّع 3 عناوين بديلة. بص على الكود سطر قصاد سطر:

#### OpenAI

```python title="titles_openai.py"
from openai import OpenAI

client = OpenAI()
response = client.responses.create(
    model="gpt-6-luna",
    instructions="Give 3 alternative titles, one per line.",
    input="Why tea is popular in Egypt",
    max_output_tokens=200,
    reasoning={"effort": "low"},
)
print(response.output_text)
print(response.usage.input_tokens,
      response.usage.output_tokens)
```

#### Gemini

```python title="titles_gemini.py"
from google import genai
from google.genai import types

client = genai.Client()
response = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="Why tea is popular in Egypt",
    config=types.GenerateContentConfig(
        system_instruction="Give 3 alternative titles, one per line.",
        max_output_tokens=200,
        thinking_config=types.ThinkingConfig(thinking_level="low"),
    ),
)
print(response.text)
u = response.usage_metadata
print(u.prompt_token_count, u.candidates_token_count)
```

<a id="s18-3"></a>

## 18.3 الفروق اللي بتوقّع الناس

#### الـ timeout

`HttpOptions(timeout=60)` في Gemini = **60 ملّي ثانية**! كل Request هيفشل. اكتبها `60_000`.

#### النص الفاضي

`response.text.strip()` في Gemini ممكن تدّي `AttributeError: 'NoneType'`. استخدم `(response.text or "")`.

#### الـ Retries

اسكريبت OpenAI بيعيد لوحده على 429. نفس الاسكريبت لو حوّلته لـ Gemini من غير `retry_options` هيقع من أول 429.

#### توكنز التفكير

في OpenAI جوه `output_tokens`. وفي Gemini منفصلة في `thoughts_token_count`. ولو نسيتها في حساب التكلفة، هتحسب أقل من الحقيقة.

## 18.4 نمط ask(): اسكريبتك ميعرفش الشركة

<strong>المشكلة:</strong> لو الـ `client.responses.create` متفرّق في 10 أماكن في الاسكريبت، تغيير الشركة يبقى 10 تعديلات. <strong>الحل:</strong> فانكشن واحدة بس بتعرف تكلم الشركة، وكل الاسكريبت بيناديها:

```python title="ai_client.py"
import os
from dataclasses import dataclass

PROVIDER = os.getenv("AI_PROVIDER", "openai")      # openai أو gemini

@dataclass
class Reply:
    text: str
    input_tokens: int
    output_tokens: int          # شامل التفكير

def ask(system: str, user: str, max_tokens: int = 800) -> Reply:
    if PROVIDER == "openai":
        from openai import OpenAI
        r = OpenAI().responses.create(
            model=os.getenv("OPENAI_MODEL", "gpt-6-luna"),
            instructions=system, input=user,
            max_output_tokens=max_tokens, reasoning={"effort": "low"},
        )
        return Reply(r.output_text, r.usage.input_tokens, r.usage.output_tokens)

    if PROVIDER == "gemini":
        from google import genai
        from google.genai import types
        r = genai.Client().models.generate_content(
            model=os.getenv("GEMINI_MODEL", "gemini-3.8-flash"),
            contents=user,
            config=types.GenerateContentConfig(
                system_instruction=system, max_output_tokens=max_tokens,
                thinking_config=types.ThinkingConfig(thinking_level="low"),
            ),
        )
        u = r.usage_metadata
        out = (u.candidates_token_count or 0) + (u.thoughts_token_count or 0)
        return Reply(r.text or "", u.prompt_token_count or 0, out)

    raise ValueError(f"unknown AI_PROVIDER: {PROVIDER}")
```

```python title="الحاجات الجديدة في الملف ده"
@dataclass
class Reply:
from openai import OpenAI   (جوه الـ if)
(u.thoughts_token_count or 0)
raise ValueError(...)
```

1. `@dataclass`: شكل موحّد للرد. أياً كانت الشركة، الاسكريبت بيستلم `reply.text` و`reply.input_tokens`. ده اسمه **Adapter**.
2. `from openai import OpenAI   (جوه الـ if)`: import جوه فانكشن: بيتنفّذ بس لو وصلنا هنا. فلو بتستخدم Gemini بس، مش لازم `openai` تبقى متسطّبة.
3. `(u.thoughts_token_count or 0)`: الحقل ممكن يبقى `None` لو مفيش تفكير، و`None + 5` بيدّي TypeError. فـ `or 0` = "لو None خليه صفر".
4. `raise ValueError(...)`: لو حد كتب `AI_PROVIDER=gemni` غلط، يقف برسالة واضحة بدل ما يكمّل.

ودلوقتي الاسكريبت كله بيكتب `reply = ask(SYSTEM, text)`، وتغيير الشركة سطر في `.env`: `AI_PROVIDER=gemini`. ده نفس الملف اللي هتلاقيه في المشروع النهائي (فصل 31).

:::tip[حاجة مشتركة: Adapter في JS]
نفس النمط في أي مشروع Node: `async function ask(system, user) { if (provider === "openai") {...} }` بترجّع Object موحّد `{ text, inputTokens, outputTokens }`. ومكتبات زي Vercel AI SDK مبنية على نفس الفكرة دي بالظبط.
:::

:::tip[ملخص الفصل]
- نفس المفاهيم بأسامي تانية: instructions ↔ system\_instruction، و input ↔ contents، و output\_text ↔ text.
- أخطر 4 فروق: timeout بالملّي في Gemini، و text ممكن None، و Retries مش تلقائية في Gemini، وتوكنز التفكير منفصلة.
- حط الكلام مع الشركة في فانكشن واحدة (`ask`) ترجّع شكل موحّد.
:::

### صح ولا غلط؟

1. `usage.output_tokens` في OpenAI شامل توكنز الـ Reasoning.
2. في Gemini، `candidates_token_count` شامل توكنز التفكير.
3. google-genai بيعيد المحاولة على 429 تلقائياً مع generate\_content من غير إعدادات.

### أسئلة مراجعة

1. حوّل نداء Gemini فيه `system_instruction` و`max_output_tokens` لنداء OpenAI.
2. ليه `ask()` بترجّع Reply بدل ما ترجّع رد الـ SDK نفسه؟
3. إيه اللي هيحصل لو كتبت `HttpOptions(timeout=30)`؟
