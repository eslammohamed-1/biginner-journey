<small>المرحلة 3 · الاسكريبت والدنيا</small>

نص شغل أي اسكريبت AI إنه يلاقي الملفات، ويقراها، ويكتب النتايج من غير ما يمسح حاجة مهمة. الفصل ده بيشرح pathlib (الطريقة الحديثة)، و os.path (اللي هتلاقيها في كود قديم)، وأوضاع open، والـ encoding، وفخاخ الـ Mac.

:::note[بعد الفصل ده هتكون عارف]
- Path والعلامة / وأجزاء المسار: name و stem و suffix و parent
- glob و rglob و iterdir علشان تلاقي ملفات
- read\_text و write\_text و open بأوضاعها r و w و a و x و rb
- ليه encoding="utf-8" مهمة جداً مع العربي
- المسارات النسبية و Path(\_\_file\_\_).parent
- السطور الخطيرة: unlink و rmtree و الكتابة فوق ملف
:::

<a id="s9-1"></a>

## 9.1 قبل كده: مسارات نصوص ملزوقة

زمان كانت المسارات نصوص عادية، وكنت بتلزقها بإيدك: `folder + "/" + name`. وده كان بيبوظ لما الفولدر آخره `/` أو مفيهوش، أو على Windows اللي بيستخدم `\`. فاتعملت `os.path.join`، وبعدين في Python 3.4 جت **pathlib**: المسار بقى Object ليه Methods، ومش نص.

**تشريح الأمر**

```python
out = Path("results") / f"{path.stem}.json"
```

1. `Path("results")`: Object بيمثّل مسار فولدر `results` (لسه مش لازم يكون موجود).
2. `/`: مش قسمة! مع Path، العلامة `/` معناها "ادخل جوه"، وبتلزق المسارات صح على أي نظام.
3. `path.stem`: اسم الملف الأصلي من غير امتداد: `notes/intro.md` هتبقى `intro`.
4. `f"….json"`: اسم الملف الجديد. والنتيجة: `results/intro.json`.

**أجزاء مسار: Path("/Users/you/notes/intro.md")**

| الـ Attribute | النتيجة | القديم (os.path) |
|---|---|---|
| `.name` | `intro.md` | `os.path.basename(p)` |
| `.stem` | `intro` | `os.path.splitext(name)[0]` |
| `.suffix` | `.md` | `os.path.splitext(p)[1]` |
| `.parent` | `/Users/you/notes` | `os.path.dirname(p)` |
| `.with_suffix(".json")` | `…/intro.json` | - |
| `.exists()` | `True` / `False` | `os.path.exists(p)` |
| `.is_file()` / `.is_dir()` | ملف؟ فولدر؟ | `os.path.isfile(p)` |
| `.stat().st_size` | الحجم بالـ Bytes | `os.path.getsize(p)` |

## 9.2 تلاقي الملفات: glob و rglob

| الأمر | بيعمل إيه |
|---|---|
| `folder.glob("*.md")` | كل ملفات `.md` في الفولدر ده بس. والـ `*` = "أي حاجة". |
| `folder.rglob("*.md")` | **r** = Recursive: في الفولدر وكل الفولدرات اللي جواه، لأي عمق. |
| `folder.glob("**/*.txt")` | نفس rglob مكتوبة بشكل تاني: `**` = أي عدد فولدرات. |
| `folder.glob("*.[jp][pn]g")` | `[ ]` = حرف واحد من دول: بيلقط `.jpg` و `.png`. |
| `folder.iterdir()` | كل حاجة مباشرة جوه الفولدر (ملفات وفولدرات) من غير فلتر. |
| `sorted(folder.glob("*"))` | الـ glob مش بيضمن ترتيب. `sorted` بتخلي الترتيب ثابت كل مرة، ودي مهمة جداً لو هتكمّل من مكان ما وقفت. |

:::note[على الـ Mac: .DS_Store و ._ملفات]
Finder بيعمل ملف مستخبي اسمه `.DS_Store` في أي فولدر تفتحه، وأوقات ملفات بتبدأ بـ `._` على الفلاشات. لو الاسكريبت بيعمل `iterdir()` أو `glob("*")` من غير فلتر امتداد، هيحاول يبعتهم للموديل! فلتر دايماً بالامتداد، أو سيب أي حاجة `name.startswith(".")`.
:::

## 9.3 القراية والكتابة

```python
text = path.read_text(encoding="utf-8")          # الملف كله نص
out.write_text(result, encoding="utf-8")          # اكتب نص (وامسح القديم!)
data = img_path.read_bytes()                      # Bytes: صور و PDF
out.parent.mkdir(parents=True, exist_ok=True)     # اعمل الفولدر لو مش موجود
```

**تشريح الأمر**

```python
out.parent.mkdir(parents=True, exist_ok=True)
```

1. `out.parent`: الفولدر اللي الملف هيتحط فيه.
2. `.mkdir()`: اعمل فولدر.
3. `parents=True`: اعمل كمان أي فولدرات ناقصة في السكة (زي `mkdir -p`).
4. `exist_ok=True`: لو الفولدر موجود متطلّعش خطأ. من غيرها: `FileExistsError`.

### open وأوضاعها

**تشريح الأمر**

```python
with open(path, "a", encoding="utf-8", newline="") as f:
```

1. `open(path,`: افتح الملف.
2. `"a"`: الوضع (Mode). و`a` = Append: زوّد في الآخر من غير ما تمسح. شوف الجدول.
3. `encoding="utf-8"`: إزاي الحروف تتحوّل Bytes. ومع العربي لازم utf-8.
4. `newline=""`: مطلوبة مع مكتبة `csv` بالذات، علشان متطلعش سطور فاضية زيادة بين الصفوف.
5. `as f`: الملف المفتوح اسمه `f`، و`with` هتقفله لوحدها.

**أوضاع open: اعرف الوضع قبل ما تشغّل**

<table class="cmp keep">
<tr><th>Mode</th><th>معناه</th><th>لو الملف موجود</th><th>لو مش موجود</th></tr>
<tr><td><code>"r"</code></td><td>قراية (الافتراضي)</td><td>يقرا</td><td>FileNotFoundError</td></tr>
<tr><td><code>"w"</code></td><td>كتابة</td><td><b>يمسحه ويكتب من الأول</b></td><td>يعمله</td></tr>
<tr><td><code>"a"</code></td><td>إضافة</td><td>يكتب في الآخر</td><td>يعمله</td></tr>
<tr><td><code>"x"</code></td><td>إنشاء بس</td><td>FileExistsError (حماية!)</td><td>يعمله</td></tr>
<tr><td><code>"rb"</code> / <code>"wb"</code></td><td>Bytes</td><td colspan="2">نفس اللي فوق، بس للصور والـ PDF ومن غير encoding</td></tr>
</table>

:::caution[أخطر حرف في أي اسكريبت: "w"]
كل `open(..., "w")` و`write_text` و`to_csv` و`to_excel` بتمسح الملف القديم من غير ما تسألك. قبل ما تشغّل اسكريبت، دوّر على السطور دي واسأل: "هل المسار ده ممكن يكون ملف مهم عندي؟". ولو الاسكريبت بيكتب في نفس ملف الـ Input (زي ترجمة Excel وحفظه فوق نفسه)، خد نسخة الأول، أو خليه يكتب في ملف جديد.
:::

:::danger[مشكلة: UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0]
الملف مش utf-8. ممكن يكون UTF-16 (ملفات اتصدّرت من Excel على Windows بتعمل كده)، أو ملف Binary زي صورة، أو PDF بتحاول تقراه كنص.

<strong>الحل:</strong> اتأكد إنه ملف نص أصلاً. ولو CSV من Excel جرّب `encoding="utf-16"` أو `"utf-8-sig"` (الـ `-sig` بتشيل علامة BOM اللي Excel بيحطها في الأول). وآخر حل: `errors="replace"` (بيحط علامة مكان الحرف البايظ بدل ما يقف).
:::

## 9.4 المسار النسبي: نسبي لإيه؟

`Path("notes")` نسبي **للفولدر اللي انت واقف فيه في الـ Terminal**، مش للفولدر اللي فيه الاسكريبت. فلو عملت `cd ~` وشغّلت `python3 ai-scripts/run.py`، هيدوّر على `~/notes` مش `~/ai-scripts/notes`.

```python
HERE = Path(__file__).resolve().parent     # فولدر الاسكريبت نفسه
INPUT_DIR = HERE / "notes"                 # دايماً جنب الاسكريبت
DOWNLOADS = Path.home() / "Downloads"      # ~/Downloads
```

| الأمر | بيعمل إيه |
|---|---|
| `__file__` | متغير خاص: مسار الملف الحالي نفسه. |
| `.resolve()` | حوّله لمسار كامل حقيقي (Absolute). |
| `Path.home()` | فولدر المستخدم `/Users/you`. و`Path("~/x").expanduser()` بتعمل نفس الكلام لنص فيه `~`. |
| `Path.cwd()` | الفولدر اللي انت واقف فيه (Current Working Directory). |

<a id="s9-5"></a>

## 9.5 سطور لازم تقف عندها

| الأمر | بيعمل إيه |
|---|---|
| `path.unlink()` | يمسح ملف. ومفيش Trash: مسح نهائي. |
| `shutil.rmtree(folder)` | يمسح فولدر بكل اللي فيه. أخطر سطر في Python. اتأكد من المتغير ده بيساوي إيه قبل ما يتنفّذ. |
| `path.rename(new) / shutil.move` | نقل أو إعادة تسمية. ولو `new` موجود ممكن يتكتب فوقه. |
| `shutil.copy2(src, dst)` | نسخ آمن (بيحافظ على التواريخ). وده كويس قبل ما تعدّل ملف. |

:::tip[حاجة مشتركة: fs في Node]
`path.read_text()` = `fs.readFileSync(p, "utf8")`. و`Path("a") / "b"` = `path.join("a", "b")`. و`mkdir(parents=True, exist_ok=True)` = `fs.mkdirSync(p, { recursive: true })`. و`__file__` = `__filename`.
:::

**المصادر الرسمية:** [docs.python.org · pathlib](https://docs.python.org/3/library/pathlib.html) · [open()](https://docs.python.org/3/library/functions.html#open) · [shutil](https://docs.python.org/3/library/shutil.html) · [os.path](https://docs.python.org/3/library/os.path.html)

:::tip[ملخص الفصل]
- `Path` Object، و`/` بتلزق المسارات، و`.name .stem .suffix .parent` أجزاؤه.
- `glob` للفولدر بس، و`rglob` لكل اللي جواه، و`sorted` علشان ترتيب ثابت.
- دايماً `encoding="utf-8"`، و`newline=""` مع csv.
- `"w"` بتمسح، و`"a"` بتزوّد، و`"x"` بترفض لو موجود.
- المسار النسبي نسبي للـ Terminal، و`Path(__file__).resolve().parent` نسبي للاسكريبت.
- فلتر `.DS_Store`، واقف عند `unlink` و`rmtree`.
:::

### صح ولا غلط؟

1. `Path("a") / "b.txt"` بتقسم حاجة على حاجة.
2. `open(p, "w")` على ملف موجود بتزوّد في آخره.
3. `glob("*.md")` بتدوّر في الفولدرات الفرعية كمان.

### أسئلة مراجعة

1. اكتب السطر اللي يحوّل `input/a.md` لـ `output/a.json` بـ pathlib.
2. ليه `sorted(folder.glob(...))` أحسن من `folder.glob(...)` لوحدها في اسكريبت بيكمّل من مكان ما وقف؟
3. ليه الاسكريبت لاقى الملفات لما شغّلته من فولدره، ومالقاهاش لما شغّلته من `~`؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** اطبع اسم وحجم كل ملف `.md` في فولدر (والحجم بـ KB بـ `{size/1024:.1f}`).
2. **[متوسط]** اكتب اسكريبت ينسخ كل ملفات `.txt` من `in/` لـ `out/` ويحوّل محتواها upper، من غير ما يلمس `in/`.
3. **[صعب]** نفس اللي فات، بس يسيب أي ملف ليه نسخة في `out/` بالفعل (أساس الـ Resume).
