<small>المرحلة 2 · لغة Python</small>

لما تشوف client.responses.create(model=..., input=..., max\_output\_tokens=...) انت بتنادي فانكشن وبتديها Arguments بالاسم. الفصل ده بيشرح الدوال من الناحيتين: إزاي تقرا تعريف فانكشن في اسكريبتك، وإزاي تقرا توقيع فانكشن في Docs مكتبة، بكل النجوم والأسهم اللي فيه.

:::note[بعد الفصل ده هتكون عارف]
- def و return وإزاي الفانكشن بترجّع قيمة
- Positional و Keyword arguments، والقيم الافتراضية
- \*args و \*\*kwargs ومعناهم في توقيعات الـ SDKs
- الـ Type hints: str و list\[str\] و str
- None و -\>
- Docstrings و lambda
:::

<a id="s6-1"></a>

## 6.1 ليه دوال أصلاً؟

قبل الدوال، لو عايز تعمل نفس الحاجة في 3 أماكن، كنت بتنسخ نفس السطور 3 مرات. ولو لقيت غلطة، لازم تصلّحها في التلاتة، وأكيد هتنسى واحدة. <strong>فاتطور الحل:</strong> تكتب السطور مرة واحدة، وتديها اسم، وتناديها بالاسم.

```python title="تشريح تعريف فانكشن"
def summarize(text: str, max_words: int = 50) -> str:
    """Return a short summary of text."""
    words = text.split()
    return " ".join(words[:max_words])
```

1. `def summarize(text: str, max_words: int = 50) -> str:`: `def` = "عرّف فانكشن"، واسمها `summarize`. وجوه الأقواس الـ **Parameters**: اللي الفانكشن مستنياه. و`: str` و`-> str` هي **Type hints** (تحت).
2. `"""Return a short summary of text."""`: **Docstring**: شرح الفانكشن. ده اللي بيظهر لما تعمل Hover في VS Code.
3. `words = text.split()`: متغير "محلي": موجود جوه الفانكشن بس، وبيختفي أول ما تخلص.
4. `return " ".join(words[:max_words])`: `return` = "رجّع القيمة دي للي ناداني، واخرج". من غيرها الفانكشن بترجّع `None`.

والنداء:

```python
short = summarize(article)                 # max_words هياخد 50
shorter = summarize(article, 20)           # بالترتيب
shorter = summarize(article, max_words=20) # بالاسم: أوضح
```

<a id="s6-2"></a>

## 6.2 الـ Arguments بالترتيب وبالاسم

#### Positional

`summarize(article, 20)`: القيمة بتروح للـ Parameter اللي في نفس الترتيب. سريعة بس مش واضحة: 20 دي إيه؟

#### Keyword

`summarize(article, max_words=20)`: بالاسم، والترتيب ميفرقش. وده الأسلوب اللي الـ SDKs كلها بتستخدمه: `model=` و`input=` و`temperature=`.

:::caution[= جوه النداء مش إسناد]
جوه أقواس النداء `model="gpt-6-luna"` معناها "ادّي الـ Parameter اللي اسمه model القيمة دي". مفيش متغير اسمه `model` بيتعمل. وعرف PEP 8 إنك مبتحطش مسافات حوالين `=` هنا.
:::

<a id="s6-3"></a>

## 6.3 النجوم: \*args و \*\*kwargs و \*

لو فتحت Docs أي SDK أو عملت Cmd+Click على `create`، هتلاقي توقيعات شبه دي. ده توقيع مبسّط علشان نتعلم عليه:

```python
def create(self, *, model: str, input: str | list, temperature: float | None = None, **kwargs) -> Response: ...
```

**تشريح الأمر**

```python
def create(self, *, model, input, **kwargs)
```

1. `self`: أول Parameter في أي Method جوه Class: "الـ Object نفسه". انت مش بتبعته، Python بتبعته لوحدها (فصل 8).
2. `*`: نجمة لوحدها = "كل اللي بعدي لازم يتبعت **بالاسم**". علشان كده `create("gpt-6-luna", "hi")` هيدّي TypeError، ولازم `create(model=..., input=...)`.
3. `**kwargs`: "أي Keyword arguments زيادة، لمّها في dict اسمه kwargs". بيخلي الفانكشن تقبل حاجات مش معرّفة بالاسم.

وده التوقيع الحقيقي لـ `generate_content` في `google-genai` 2.33 (مختصر الأنواع)، طالع من `inspect.signature`:

```python
def generate_content(self, *, model: str, contents: ..., config: GenerateContentConfig | None = None) -> GenerateContentResponse
```

ونفس الكلام في `openai` 3.37: كل Parameters الـ `responses.create` (أكتر من 30 واحد، زي `model` و`input` و`instructions` و`max_output_tokens`) جاية بعد `*`، يعني بالاسم بس. ومن غير `**kwargs`: بدالها في Parameters اسمها `extra_headers` و`extra_body` لأي حاجة زيادة.

| الأمر | بيعمل إيه |
|---|---|
| `*args` | أي عدد Positional arguments، بتتلم في Tuple. |
| `f(*items)` | في النداء: "فك الـ List دي وابعت عناصرها كـ Arguments منفصلة". |
| `f(**config)` | في النداء: "فك الـ dict ده وابعت كل مفتاح كـ Keyword argument". مثال: `client.responses.create(**params)`. شائعة جداً. |

:::tip[حاجة مشتركة: rest و spread]
`*args` = `...args` في JS. و`f(**config)` أقرب حاجة ليها إنك تبعت Object: `f({...config})`. والـ Keyword arguments في Python بتعمل اللي الـ "options object" بيعمله في JS: `openai.responses.create({ model, input })`.
:::

## 6.4 الـ Type hints: كلام للقارئ مش لـ Python

الـ AI بيكتب Type hints كتير، وهي بتساعدك تفهم. لكن خد بالك: <strong>Python مبتتأكدش منها وهي شغّالة.</strong> لو كتبت `x: int = "hi"` هتشتغل عادي. هي للمحرر وللبني آدم، وفي أدوات زي mypy بتفحصها.

**قراية الـ Type hints**

| المكتوب | معناه |
|---|---|
| `name: str` | نص |
| `-> int` | الفانكشن بترجّع رقم صحيح |
| `-> None` | مبترجّعش حاجة |
| `list[str]` | List كل عناصرها نصوص |
| `dict[str, float]` | dict مفاتيحه نصوص وقيمه أرقام عشرية |
| `str \| None` | يا نص يا None (القديم: `Optional[str]`) |
| `Path \| str` | يقبل الاتنين |
| `Any` | أي حاجة (من `typing`) |
| `Literal["low", "high"]` | قيمة من دول بس (هتشوفها في SDKs) |

:::tip[حاجة مشتركة: TypeScript]
دي نفس فكرة TypeScript بالظبط: `function f(text: string): string`. الفرق إن TypeScript بيتفحص قبل التشغيل وبيرفض، و Python بتتجاهل الـ hints وقت التشغيل.
:::

## 6.5 lambda: فانكشن من غير اسم

**تشريح الأمر**

```python
ranked = sorted(scores, key=lambda x: x[1], reverse=True)
```

1. `sorted(scores)`: رجّع نسخة مترتبة من `scores` (List أزواج زي `("a.md", 0.82)`).
2. `key=`: "رتّب على أساس إيه؟". بياخد فانكشن بتتنادى على كل عنصر.
3. `lambda x: x[1]`: فانكشن صغيرة في سطر: بتاخد `x` وترجّع `x[1]` (الرقم التاني في الزوج: درجة التشابه). من غير `def` ولا `return`.
4. `reverse=True`: من الأكبر للأصغر. هتشوف السطر ده بالحرف في الـ RAG (فصل 24).

**المصادر الرسمية:** [docs.python.org · Defining Functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions) · [Keyword / special parameters](https://docs.python.org/3/tutorial/controlflow.html#more-on-defining-functions) · [typing](https://docs.python.org/3/library/typing.html)

:::tip[ملخص الفصل]
- `def name(params) -> type:` بتعرّف، و`return` بترجّع. من غيرها النتيجة None.
- الـ SDKs بتستخدم Keyword arguments: `model=`، والنجمة `*` في التوقيع بتجبرك عليها.
- `**kwargs` بتلم الزيادة، و`f(**d)` بتفك dict لـ Arguments.
- الـ Type hints للقراية مش للتنفيذ: `list[str]` و`str | None`.
- `key=lambda x: x[1]` = رتّب على أساس العنصر التاني.
:::

### صح ولا غلط؟

1. فانكشن مفيهاش `return` بترجّع `None`.
2. لو كتبت `def f(x: int)` وناديت `f("hi")`، Python هترمي خطأ قبل ما تنفّذ.
3. في `def f(*, a, b)` لازم تبعت `a` و`b` بالاسم.

### أسئلة مراجعة

1. اشرح التوقيع: `def count_tokens(text: str, model: str = "gpt-6-luna") -> int:`
2. إيه اللي بيحصل في `client.responses.create(**params)` لو `params = {"model": "x", "input": "hi"}`؟
3. اكتب الـ lambda اللي ترتّب List dicts على مفتاح `"cost"`.
