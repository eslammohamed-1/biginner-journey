<small>المرحلة 2 · لغة Python</small>

أي اسكريبت بيعالج ملفات بيعمل حاجتين بس: يكرر (لكل ملف…) ويقرر (لو الملف فاضي… لو الرد فيه خطأ…). الفصل ده عن الحاجتين دول، وعن الـ Comprehension: السطر الواحد الغريب اللي الـ AI بيحبه جداً.

:::note[بعد الفصل ده هتكون عارف]
- if و elif و else والمقارنات و and/or/not
- for … in، و range و enumerate و zip
- break و continue، و while لما متعرفش هتلف كام مرة
- تقرا List و Dict Comprehension بثقة
- الفرق بين is و ==
:::

<a id="s5-1"></a>

## 5.1 الشروط: if و elif و else

```python
size = path.stat().st_size
if size == 0:
    print("skip: empty")
elif size > 200_000:
    print("too big, will trim")
else:
    print("ok")
```

| الأمر | بيعمل إيه |
|---|---|
| `elif` | اختصار "else if". ممكن يبقى منها كتير، وأول شرط يتحقق بيتنفّذ والباقي بيتساب. |
| `200_000` | الـ `_` جوه الرقم مجرد فاصل للقراية = 200000. Python بتتجاهلها. |
| `== != < > <= >=` | يساوي، لا يساوي، أصغر، أكبر، أصغر أو يساوي، أكبر أو يساوي. مفيش `===` في Python. |
| `and / or / not` | بالكلام بدل `&&` و `\|\|` و `!` بتوع JS. |
| `is None` | `is` = "نفس الحاجة بالظبط في الميموري"، و`==` = "نفس القيمة". مع `None` و`True` و`False` استخدم `is`. |
| `x if cond else y` | شرط في سطر (زي `cond ? x : y` في JS): `model = "big" if long else "small"`. |

<a id="s5-2"></a>

## 5.2 الـ for: لكل حاجة في…

في Python الـ `for` دايماً بتلف **على حاجة**: List أو نص أو ملفات أو سطور. مفيش `for (let i=0; i<n; i++)`.

**تشريح الأمر**

```python
for i, path in enumerate(paths, start=1):
```

1. `for … in`: "لكل عنصر جوه…".
2. `enumerate(paths)`: بيلف على `paths` بس بيدّيك مع كل عنصر رقمه. فبيرجّع أزواج `(0, path)` و`(1, path)`…
3. `start=1`: ابدأ العدّ من 1 بدل 0 (أحلى في الطباعة: "ملف 1 من 50").
4. `i, path`: Unpacking: أول قيمة في الزوج تروح في `i` والتانية في `path`.
5. `:`: وتحته الـ Block بـ 4 مسافات.

| الأمر | بيعمل إيه |
|---|---|
| `range(5)` | الأرقام 0, 1, 2, 3, 4 (من غير 5). و`range(1, 6)` = من 1 لـ 5. |
| `zip(names, texts)` | يمشي على اتنين List مع بعض: أول عنصر مع أول عنصر… مفيد لما تبعت Batch وترجع النتايج بنفس الترتيب. |
| `continue` | سيب اللفة دي، وروح على اللي بعدها. (مثال: الملف فاضي؟ `continue`.) |
| `break` | اقفل الـ Loop خالص واخرج منه. |

```python title="نمط هتشوفه في كل حتة"
for path in paths:
    if path.name.startswith("."):
        continue                 # ملفات مستخبية: سيبها
    if path.with_suffix(".json").exists():
        continue                 # اتعالج قبل كده: سيبه
    process(path)
```

<a id="s5-3"></a>

## 5.3 الـ while: لف لحد ما الشرط يبطل

بتستخدم لما متعرفش هتلف كام مرة. وأشهر مكان هتشوفها فيه في اسكريبتات الـ AI: **محاولات الإعادة** (Retries)، و"استنى لحد ما الـ Batch يخلص".

```python
attempt = 0
while attempt < 3:
    attempt += 1               # زي attempt = attempt + 1
    ok = try_call()
    if ok:
        break
```

:::caution[خد بالك من الـ Loop اللانهائي]
`while True:` بتلف للأبد لحد ما يحصل `break`. لو الشرط بتاع الـ break عمره ما اتحقق، الاسكريبت هيفضل شغّال (وممكن يصرف فلوس API!). علشان توقفه من الـ Terminal: **Ctrl+C**.
:::

<a id="s5-4"></a>

## 5.4 الـ Comprehension: Loop في سطر واحد

دي الحاجة اللي بتخضّ أي حد جديد على Python، والـ AI بيكتبها كتير جداً. بس هي مجرد طريقة مختصرة تعمل بيها List من List:

**تشريح الأمر**

```python
names = [p.stem for p in paths if p.suffix == ".md"]
```

1. `[ … ]`: هيطلع List جديدة.
2. `p.stem`: "إيه اللي يتحط في الـ List": اسم الملف من غير الامتداد. اقراه **آخر حاجة**.
3. `for p in paths`: "لف على `paths` وسمّي كل واحد `p`". اقراه **الأول**.
4. `if p.suffix == ".md"`: فلتر (اختياري): خد بس اللي امتداده `.md`. اقراه **تاني**.

نفس السطر ده لو مكتوب بالطريقة الطويلة:

```python
names = []
for p in paths:
    if p.suffix == ".md":
        names.append(p.stem)
```

| الأمر | بيعمل إيه |
|---|---|
| `{k: v for k, v in pairs}` | Dict Comprehension: بيعمل dict. مثال: `{p.name: p.stat().st_size for p in paths}`. |
| `sum(x.tokens for x in rows)` | من غير أقواس مربعة = "Generator": بيحسب واحدة واحدة من غير ما يعمل List. شائعة مع `sum` و`any` و`all`. |
| `any(...) / all(...)` | "فيه واحد على الأقل True؟" / "كلهم True؟". |

:::tip[حاجة مشتركة: map و filter]
`[p.stem for p in paths if p.suffix == ".md"]` هي في JS: `paths.filter(p => p.suffix === ".md").map(p => p.stem)`. نفس الفكرة: فلتر وبعدين حوّل.
:::

**المصادر الرسمية:** [docs.python.org · More Control Flow Tools](https://docs.python.org/3/tutorial/controlflow.html) · [List Comprehensions](https://docs.python.org/3/tutorial/datastructures.html#list-comprehensions) · [enumerate / zip](https://docs.python.org/3/library/functions.html#enumerate)

:::tip[ملخص الفصل]
- `if/elif/else` مع `and/or/not`، و`is None` بدل `== None`.
- `for x in things:` بتلف على حاجة. و`enumerate` للرقم، و`zip` لاتنين مع بعض.
- `continue` = سيب الدور ده، `break` = اخرج خالص.
- `while` للتكرار لحد شرط، زي محاولات الإعادة، و Ctrl+C يوقف أي Loop.
- الـ Comprehension اقراه: الـ `for` الأول، بعدين الـ `if`، بعدين اللي في الأول.
:::

### صح ولا غلط؟

1. `range(3)` بيدّي 1, 2, 3.
2. `continue` بتخرج من الـ Loop خالص.
3. `[x * 2 for x in [1, 2, 3]]` نتيجتها `[2, 4, 6]`.

### أسئلة مراجعة

1. حوّل `[r["id"] for r in rows if r["ok"]]` لـ Loop عادية.
2. إيه فايدة `enumerate(paths, start=1)` في اسكريبت بيعالج ملفات؟
3. ليه `while True` خطر في اسكريبت بيكلم API مدفوع؟
