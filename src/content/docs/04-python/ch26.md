## 26.1 الوقت رايح فين؟

طلب API واحد بياخد مثلاً 3 ثواني. الاسكريبت بتاعك في الـ 3 ثواني دول **مش بيعمل حاجة**: بيستنى الرد من السيرفر. فـ 2000 ملف ورا بعض = 6000 ثانية = ساعة و40 دقيقة، أغلبها انتظار. والحل: **تستنى كذا رد في نفس الوقت**. وده اسمه Concurrency، وفي Python ليه طريقتين: Threads و asyncio. والحل التالت: **متستناش خالص**، ابعت الشغل كله مرة واحدة كـ Batch وتعالى خد النتايج بعدين.

**الأربع طرق**

| الطريقة | إمتى | السعر | الصعوبة |
|---|---|---|---|
| for + tqdm | أقل من ~100 ملف، أو بتجرب | عادي | سهل |
| ThreadPoolExecutor | مئات لآلاف، ومحتاج النتيجة النهارده | عادي | متوسط |
| asyncio | نفس اللي فوق، أو جوه برنامج async أصلاً | عادي | متوسط/صعب |
| Batch API | آلاف، ومش مستعجل (لحد 24 ساعة) | **نص السعر** | متوسط |

## 26.2 tqdm: شوف انت فين

```python
from tqdm import tqdm

for path in tqdm(paths, desc="notes"):
    process(path)
```

```sh title="Terminal"
notes:  38%|███▊      | 3/8 [00:01<00:01,  3.00it/s]
```

`tqdm(iterable)` بيلف على نفس الحاجة ويرسم شريط: النسبة، وعدد اللي خلص من الكل، و`[اللي فات<الباقي]`، والسرعة (`it/s` = عناصر في الثانية). و`desc` الاسم اللي على الشمال. ولو اللي بتلف عليه ملوش طول (Generator)، ابعت `total=`.

## 26.4 ThreadPoolExecutor: 4 عمال بدل واحد

```python title="run_many.py"
import argparse
import json
import logging
from concurrent.futures import ThreadPoolExecutor, as_completed
from pathlib import Path

from openai import OpenAI
from tqdm import tqdm

log = logging.getLogger("run_many")
client = OpenAI(max_retries=4, timeout=60.0)
MODEL = "gpt-6-luna"
SYSTEM = "Summarize the note in 2 sentences."

def load_done(results: Path) -> set[str]:
    done = set()
    if results.exists():
        for line in results.read_text(encoding="utf-8").splitlines():
            if line.strip():
                done.add(json.loads(line)["file"])
    return done

def process(path: Path) -> dict:
    text = path.read_text(encoding="utf-8")
    response = client.responses.create(model=MODEL, instructions=SYSTEM, input=text[:20_000])
    return {
        "file": path.name,
        "summary": response.output_text,
        "input_tokens": response.usage.input_tokens,
        "output_tokens": response.usage.output_tokens,
    }

def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("folder", type=Path)
    parser.add_argument("--out", type=Path, default=Path("results.jsonl"))
    parser.add_argument("--workers", type=int, default=4)
    parser.add_argument("--limit", type=int, default=None)
    args = parser.parse_args()
    logging.basicConfig(level=logging.WARNING, format="%(levelname)s %(message)s")
    log.setLevel(logging.INFO)

    done = load_done(args.out)
    todo = [p for p in sorted(args.folder.glob("*.md")) if p.name not in done]
    todo = todo[: args.limit]
    log.info("done=%d todo=%d", len(done), len(todo))

    failed = 0
    with open(args.out, "a", encoding="utf-8") as out, ThreadPoolExecutor(args.workers) as pool:
        futures = {pool.submit(process, p): p for p in todo}
        for future in tqdm(as_completed(futures), total=len(futures), desc="notes"):
            path = futures[future]
            try:
                row = future.result()
            except Exception as exc:
                failed += 1
                log.error("%s failed: %s", path.name, exc)
                continue
            out.write(json.dumps(row, ensure_ascii=False) + "\n")
            out.flush()
    log.info("finished, failed=%d", failed)

if __name__ == "__main__":
    main()
```

بص بقى هنمشي فيه حتة حتة، لأن فيه حاجات كتير جديدة:

```python title="run_many.py مشرّح"
done = set()  …  done.add(json.loads(line)["file"])
if line.strip():
todo = todo[: args.limit]
open(args.out, "a", ...)
with A as out, B as pool:
ThreadPoolExecutor(args.workers)
{pool.submit(process, p): p for p in todo}
as_completed(futures)
future.result()
out.write(...); out.flush()
OpenAI(max_retries=4, timeout=60.0)
```

1. `done = set()  …  done.add(json.loads(line)["file"])`: **set** فيها أسامي الملفات اللي خلصت. وسؤال `p.name not in done` في set سريع جداً حتى لو فيها 100 ألف.
2. `if line.strip():`: اتخطى السطور الفاضية. ولو الاسكريبت وقع وهو بيكتب، ممكن يبقى آخر سطر ناقص. ولو حصل كده، `json.loads` هيقع. احذف السطر ده بإيدك، أو اعمل `try/except json.JSONDecodeError` حواليه.
3. `todo = todo[: args.limit]`: Slice بـ `None` = لحد الآخر. فـ `--limit 5` تجرّب على 5 بس قبل ما تصرف على 2000. ودي من أهم عادات الأمان (فصل 28).
4. `open(args.out, "a", ...)`: `"a"` = append: ضيف في الآخر، **ومتمسحش القديم**. ولو كتبت `"w"` هنا، كل تشغيل هيمسح النتايج اللي فاتت. وده أشهر Bug في الاسكريبتات دي.
5. `with A as out, B as pool:`: اتنين `with` في سطر واحد. والاتنين هيتقفلوا صح في الآخر حتى لو حصل Error.
6. `ThreadPoolExecutor(args.workers)`: "مجموعة عمال" عددهم `workers`. كل عامل Thread بياخد مهمة وينفّذها، ولما يخلص ياخد اللي بعدها.
7. `{pool.submit(process, p): p for p in todo}`: Dict comprehension. `submit(func, arg)` بيدّي المهمة لعامل ويرجّع على طول **Future**: "إيصال" بنتيجة هتيجي بعدين. والـ dict بيربط كل إيصال بالملف بتاعه.
8. `as_completed(futures)`: بيرجّع الإيصالات **بترتيب ما خلصت** مش بترتيب ما اتبعتت. يعني الأسرع الأول، والـ Progress bar بيتحرك على طول.
9. `future.result()`: هات النتيجة. ولو `process` رمت Exception جوه الـ Thread، **بيترمي هنا**. فالـ `try/except` لازم يبقى حوالين السطر ده.
10. `out.write(...); out.flush()`: الكتابة كلها بتحصل في الـ Thread الرئيسي بس (مش جوه `process`)، فمفيش اتنين بيكتبوا في نفس الوقت. و`flush()` = ابعت للديسك دلوقتي، متستناش. ولو الاسكريبت اتقفل، اللي اتكتب مش هيضيع.
11. `OpenAI(max_retries=4, timeout=60.0)`: Client واحد بتستخدمه كل الـ Threads، وده آمن. والـ Retries من الـ SDK (فصل 25).

:::note[جربناه على سيرفر تجريبي (كل رد بياخد 0.3 ثانية)]
`--limit 8 --workers 1`: ‏8 ملفات في 2.6 ثانية تقريباً (3.1 ملف في الثانية). وبعدين `--workers 4` على نفس الفولدر: قال `done=8 todo=12` (يعني الـ Resume اشتغل)، وخلّص الـ 12 في حوالي ثانية (11 ملف في الثانية). وتشغيل تالت: `todo=0`، ومبعتش ولا طلب. والنتيجة `results.jsonl` فيه 20 سطر بالظبط، من غير تكرار.
:::

:::caution[كام Worker؟]
ابدأ بـ 4. وكل Worker زيادة = طلبات أكتر في الدقيقة = أقرب للـ Rate limit (فصل 25). ولو شفت 429 كتير، قلّل. و Gemini SDK **مبيعيدش** افتراضياً، فمع Threads فعّل `HttpRetryOptions`.
:::

:::note[مش لازم process ترجع بنفس الترتيب]
`as_completed` بيلخبط الترتيب، فالـ JSONL مش مترتب. ولو محتاجه مترتب في الـ CSV النهائي: `sorted(rows, key=lambda r: r["file"])` في الآخر.
:::

## 26.5 asyncio: نفس الفكرة بطريقة JS

:::note[الـ Event loop والـ async من غير ما تكون عارف JS]
لو لسه موصلتش لـ async/await في كورس JavaScript، خد الفكرة كده: تخيل كاشير واحد في كافيه. بدل ما ياخد طلب ويقف مستني القهوة تخلص، بياخد الطلب ويقول للباريستا، وياخد طلب الزبون اللي بعده، ولما أي قهوة تجهز ينادي على صاحبها. الكاشير ده هو الـ **Event loop**: حاجة واحدة بتلف على كل المهام، وكل مهمة لما توصل لحتة "استنى الشبكة" (`await`) بتسيب الدور لغيرها. فـ 20 طلب للـ API بيستنوا مع بعض بدل ما يستنوا ورا بعض. `async def` = دالة ينفع جواها `await`، و `asyncio.run(main())` = شغّل الكاشير وابدأ بـ main. وشرح الـ Promise و async/await في JavaScript موجود في كتاب الإنترنت (فصل 7).
:::

لو انت جاي من JS، asyncio هتبقى مألوفة: `async def` = `async function`، و`await` = `await`، و`asyncio.gather` = `Promise.all`. والفرق إن Python محتاجة حد "يشغّل" الـ Event loop: `asyncio.run(main())`.

```python title="run_async.py"
import asyncio
import json
from pathlib import Path

from openai import AsyncOpenAI

client = AsyncOpenAI(max_retries=4, timeout=60.0)
MODEL = "gpt-6-luna"
LIMIT = asyncio.Semaphore(8)

async def summarize(path: Path) -> dict:
    async with LIMIT:
        response = await client.responses.create(
            model=MODEL, instructions="Summarize in 2 sentences.", input=path.read_text(encoding="utf-8"),
        )
    return {"file": path.name, "summary": response.output_text}

async def main() -> None:
    paths = sorted(Path("notes").glob("*.md"))
    results = await asyncio.gather(*(summarize(p) for p in paths), return_exceptions=True)
    with open("results_async.jsonl", "w", encoding="utf-8") as out:
        for path, result in zip(paths, results):
            if isinstance(result, Exception):
                print("failed:", path.name, result)
                continue
            out.write(json.dumps(result, ensure_ascii=False) + "\n")
    print("ok:", sum(not isinstance(r, Exception) for r in results), "of", len(paths))

if __name__ == "__main__":
    asyncio.run(main())
```

| الأمر | بيعمل إيه |
|---|---|
| `AsyncOpenAI(...)` | نسخة async من الـ Client: كل الفانكشنز بتترجع حاجة لازم تعمل لها `await`. وفي Gemini: `client.aio.models.generate_content(...)` على نفس الـ Client. |
| `asyncio.Semaphore(8)` | "8 تصاريح بس". وكل `async with LIMIT` بياخد تصريح، والتاسع بيستنى لحد ما واحد يخلص. من غيره، `gather` هيبعت الـ 2000 طلب **مرة واحدة**، وتخبط في الـ Rate limit على طول. |
| `asyncio.gather(*(...), return_exceptions=True)` | شغّلهم كلهم واستنى الكل. و`*` بتفرد الـ Generator لـ Arguments. والنتايج **بنفس ترتيب** الإدخال (عكس `as_completed`). و`return_exceptions=True` = الـ Error يرجع كقيمة في الـ List بدل ما يوقّع الكل. وزي `Promise.allSettled`. |
| `isinstance(result, Exception)` | علشان كده بنفرز: ده نجح ولا Error. |
| `asyncio.run(main())` | شغّل الـ Event loop وابدأ بـ `main()`. ومرة واحدة في البرنامج. |

جربناه على نفس السيرفر التجريبي: 20 ملف في حوالي ثانية ونص (مع وقت تحميل Python). والنسخة دي بتكتب في الآخر بس، فمفيش Resume. ولو عايزه، اكتب كل نتيجة أول ما تيجي زي `run_many.py`.

:::tip[حاجة مشتركة: JS]
`await Promise.all(paths.map(p => summarize(p)))` هي `asyncio.gather`. ومفيش Semaphore جاهز في JS، فالناس بتستخدم مكتبة زي `p-limit`: `const limit = pLimit(8); paths.map(p => limit(() => summarize(p)))`. وفي JS مش محتاج `asyncio.run`، لأن الـ Event loop شغال دايماً.
:::

:::note[Threads ولا asyncio؟]
للاسكريبتات بتاعتنا، **Threads أسهل**: `process()` فانكشن عادية، ومفيش `async` في كل حتة. وasyncio أحسن لو آلاف الطلبات في نفس الوقت، أو لو الكود كله async أصلاً.
:::

## 26.6 Batch API: ابعت وتعالى بعدين بنص السعر

لو الشغل مش محتاجه دلوقتي حالاً (تلخيص أرشيف، أو ترجمة 5000 صف)، الاتنين عندهم **Batch API**: تبعت كل الطلبات في ملف JSONL واحد، وهما يخلّصوه في خلال 24 ساعة (وغالباً أسرع بكتير)، **بخصم 50%** وبحدود Rate منفصلة.

```python title="OpenAI Batch"
import json
from pathlib import Path

with open("batch_input.jsonl", "w", encoding="utf-8") as f:
    for path in sorted(Path("notes").glob("*.md")):
        f.write(json.dumps({
            "custom_id": path.name,
            "method": "POST",
            "url": "/v1/responses",
            "body": {"model": "gpt-6-luna", "instructions": SYSTEM,
                     "input": path.read_text(encoding="utf-8")},
        }) + "\n")

batch_file = client.files.create(file=open("batch_input.jsonl", "rb"), purpose="batch")
batch = client.batches.create(input_file_id=batch_file.id,
                              endpoint="/v1/responses", completion_window="24h")
print(batch.id, batch.status)          # validating

# بعدين (نفس الاسكريبت أو اسكريبت تاني):
batch = client.batches.retrieve(batch.id)
if batch.status == "completed":
    for line in client.files.content(batch.output_file_id).text.splitlines():
        row = json.loads(line)
        print(row["custom_id"], row["response"]["status_code"])
```

| الأمر | بيعمل إيه |
|---|---|
| `"custom_id": path.name` | ID فريد لكل سطر. ولازم، لأن OpenAI بتقول صراحة: **ترتيب سطور النتيجة ممكن ميطابقش ترتيب الإدخال**. فاربط بالـ `custom_id` مش بالترتيب. |
| `"url": "/v1/responses"` | الـ Endpoint. والـ `body` هو نفس الـ Parameters اللي بتديها لـ `responses.create`. |
| `purpose="batch"` | نوع الملف المرفوع. |
| `completion_window="24h"` | القيمة الوحيدة المتاحة حالياً. |
| `batch.status` | `validating` ثم `in_progress` ثم `finalizing` ثم `completed`. أو `failed` (الملف نفسه غلط)، أو `expired` (عدّى 24 ساعة، والنتايج اللي خلصت بتوصلك). |
| `output_file_id / error_file_id` | النتايج الناجحة في ملف، والطلبات الفاشلة في ملف تاني. |

حدود OpenAI Batch: لحد 50,000 طلب في الـ Batch، والملف لحد 200 MB.

```python title="Gemini Batch (inline)"
inline_requests = [
    {"contents": [{"role": "user", "parts": [{"text": p.read_text(encoding="utf-8")}]}]}
    for p in paths
]
job = client.batches.create(
    model="gemini-3.8-flash",
    src=inline_requests,
    config={"display_name": "notes-summaries"},
)
# بعدين:
job = client.batches.get(name=job.name)
if job.state.name == "JOB_STATE_SUCCEEDED":
    for path, item in zip(paths, job.dest.inlined_responses):
        print(path.name, item.response.text if item.response else item.error)
```

- **Inline** (List في الطلب) للطلبات الصغيرة، والمجموع أقل من 20MB. وللكبير: JSONL فيه `{"key": "...", "request": {...}}` في كل سطر، ترفعه بـ `client.files.upload(file=..., config=types.UploadFileConfig(mime_type="jsonl"))` وتبعت `src=uploaded.name`، والنتيجة ملف تنزّله بـ `client.files.download(file=job.dest.file_name)`.
- الحالات: `JOB_STATE_SUCCEEDED` أو `FAILED` أو `CANCELLED` أو `EXPIRED`. وبتعمل Poll كل 30 ثانية مثلاً.
- والـ Embeddings ليها `client.batches.create_embeddings(...)`، ودي الطريقة المقترحة لـ `gemini-embedding-2` مع Chunks كتير (فصل 24).
- والـ Batch مش متاح لسه في Interactions API، فاستخدمه مع `generate_content` (فصل 17).

**المصادر الرسمية:** [OpenAI · Batch API](https://developers.openai.com/api/docs/guides/batch) · [Gemini · Batch API](https://ai.google.dev/gemini-api/docs/batch-api)

## 26.7 قواعد الاسكريبت اللي بيلف على ملفات كتير

1. **Resume**: اكتب النتيجة أول بأول (append + flush)، واتخطى اللي خلص.
2. <strong>`--limit`</strong>: جرّب على 5 الأول دايماً.
3. **متكتبش فوق الأصل**: النتايج في فولدر أو ملف جديد (فصل 28).
4. **Error في ملف ≠ وقوع الاسكريبت**: سجّل وكمّل، وفي الآخر اطبع عدد الفاشل.
5. **Idempotent**: تشغيله مرتين يدّي نفس النتيجة، من غير تكرار ولا دفع مرتين.
6. **احسب التكلفة قبل** ما تشغّل على الكل (الفصل الجاي).

:::tip[ملخص الفصل]
- الوقت رايح في الانتظار، فاستنى كذا رد مع بعض، أو استخدم Batch.
- `tqdm` للـ Progress، و Resume بـ JSONL + set + `"a"` + `flush`.
- `ThreadPoolExecutor` + `submit` + `as_completed` + `future.result()` جوه try، والكتابة من الـ Thread الرئيسي.
- asyncio: `AsyncOpenAI` أو `client.aio`، و`Semaphore`، و`gather(return_exceptions=True)`.
- Batch: JSONL و `custom_id` (أو `key`)، ولحد 24 ساعة، ونص السعر، والترتيب مش مضمون.
:::

### صح ولا غلط؟

1. `as_completed` بيرجّع النتايج بنفس ترتيب الـ `submit`.
2. فتح ملف النتايج بـ `"w"` مناسب للـ Resume.
3. في OpenAI Batch، تقدر تعتمد إن السطر رقم 5 في النتيجة هو الطلب رقم 5.

### أسئلة مراجعة

1. إيه الـ Future؟ وفين بيظهر الـ Exception اللي حصل جوه الـ Thread؟
2. من غير الـ Semaphore في `run_async.py`، إيه اللي هيحصل مع 2000 ملف؟
3. إمتى تختار Batch بدل Threads؟ اذكر عيبين للـ Batch.
