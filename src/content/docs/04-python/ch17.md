<small>المرحلة 4 · أساسيات الـ AI</small>

مكتبة google-genai هي الـ SDK الرسمي لـ Gemini. هندخل جواها زي ما عملنا مع openai: الـ Client، و generate\_content وكل حقل في GenerateContentConfig، وشكل الرد بالـ candidates والـ parts والـ usage\_metadata، والـ Streaming والـ Chats. وفي الآخر الـ Interactions API الجديد اللي Google بتنصح بيه للمشاريع الجديدة، وإمتى تستخدم أنهي واحد.

:::note[بعد الفصل ده هتكون عارف]
- pip install google-genai و genai.Client() ومين بيكسب GEMINI\_API\_KEY ولا GOOGLE\_API\_KEY
- client.models.generate\_content: model و contents و config
- GenerateContentConfig: system\_instruction و max\_output\_tokens و thinking\_config وغيرهم
- تشريح الرد: text و candidates و parts و finish\_reason و usage\_metadata
- generate\_content\_stream و client.chats
- client.interactions.create (Beta) والفرق بينه وبين generate\_content
:::

:::note[generateContent ولا Interactions؟ (من الدوكيومنتيشن)]
Google بتقدّم دلوقتي طريقتين. **Interactions API** اسمه "المعيار الجديد، وبننصح بيه لكل المشاريع الجديدة"، بس هو **Beta** والدوكيومنتيشن بتقول إن ممكن يحصل فيه **Breaking changes** (وحصل فعلاً في مايو 2026). وفي نفس الصفحة: "للإنتاج كمّلوا على **generateContent**، ده الطريق الموصى بيه للاستقرار". وكمان في حاجات لسه مش في Interactions، زي الـ **Batch API**. علشان كده الكتاب ماشي على `generate_content` كطريق أساسي، وهنشوف Interactions في آخر الفصل. (الكود متجرّب على `google-genai` 2.33.0.)
:::

## 17.1 الـ Client

```sh title="Terminal"
(.venv) $ pip install google-genai
```

```python
from google import genai
from google.genai import types

client = genai.Client()                                  # بيقرا الـ Key من البيئة
client = genai.Client(
    api_key=os.environ["GEMINI_API_KEY"],
    http_options=types.HttpOptions(timeout=60_000),      # ملّي ثانية!
)
```

```python title="سطر سطر"
from google import genai
from google.genai import types
genai.Client()
types.HttpOptions(timeout=60_000)
```

1. `from google import genai`: الـ Package اسمها `google.genai`، واحنا بنجيب الـ Module `genai` منها. (مش `google.generativeai` القديمة.)
2. `from google.genai import types`: كل الـ Classes بتاعة الإعدادات والمحتوى: `types.GenerateContentConfig` و`types.Part` و`types.ThinkingConfig`… وهتشوفها في كل سطر تقريباً.
3. `genai.Client()`: بيدوّر على `GEMINI_API_KEY` أو `GOOGLE_API_KEY`. **ولو الاتنين موجودين، `GOOGLE_API_KEY` هي اللي بتتاخد**. ودي بتعمل مشاكل لو عندك Key قديم في `GOOGLE_API_KEY` من مشروع تاني.
4. `types.HttpOptions(timeout=60_000)`: إعدادات الـ HTTP. و**الـ timeout هنا بالملّي ثانية** (60,000 = 60 ثانية)، مش بالثواني زي openai. وفيها كمان `retry_options` (فصل 25) و`base_url`.

**المصادر الرسمية:** [Gemini · Quickstart](https://ai.google.dev/gemini-api/docs/quickstart) · [google-genai · Python SDK reference](https://googleapis.github.io/python-genai/) · [Gemini · Libraries](https://ai.google.dev/gemini-api/docs/libraries)

## 17.2 generate\_content

```python title="نداء كامل"
response = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="Rewrite: 'we was going to the office yesterday'",
    config=types.GenerateContentConfig(
        system_instruction="You are a careful editor. Answer in English.",
        max_output_tokens=300,
        thinking_config=types.ThinkingConfig(thinking_level="low"),
    ),
)
print(response.text)
```

**تشريح الأمر**

```python
client.models.generate_content(model=..., contents=..., config=...)
```

1. `client.models`: مجموعة الدوال الخاصة بالموديلات (زي `client.responses` في OpenAI). وجنبها `client.files` و`client.batches` و`client.chats` و`client.caches`.
2. `generate_content`: "ولّد محتوى". والتوقيع: كل الـ Parameters بالاسم بس (`*`)، وهم تلاتة بس.
3. `model=`: اسم الموديل.
4. `contents=`: اللي بتبعته: نص، أو List فيها نص وصور وملفات (`types.Part`)، أو محادثة كاملة (`types.Content` بـ roles `"user"` و`"model"`).
5. `config=`: كل الإعدادات في Object واحد. ممكن تكتبه `types.GenerateContentConfig(...)` أو dict عادي بنفس الأسامي.

**أهم حقول GenerateContentConfig**

| الحقل | معناه |
|---|---|
| `system_instruction` | تعليمات الـ system (زي `instructions` في OpenAI). |
| `max_output_tokens` | سقف الرد. |
| `thinking_config` | `types.ThinkingConfig(thinking_level="low" \| "medium" \| "high")` في موديلات 3.8 و 4. |
| `response_mime_type` + `response_json_schema` | اطلب JSON بشكل محدد (فصل 21). |
| `tools` | دوال الموديل يقدر يطلبها، أو أدوات جاهزة زي Google Search (فصل 22). |
| `stop_sequences` | List نصوص: لو الموديل كتب واحدة منها، يقف. |
| `safety_settings` | درجات فلترة المحتوى. |
| `cached_content` | اسم Cache عملته قبل كده (فصل 27). |
| `temperature` / `top_p` / `top_k` | **متحطهمش** مع Gemini 4 و 3.6+: بيتجاهلوا وهيبقوا خطأ 400 قريب (فصل 14). |

## 17.3 تشريح الرد

```json title="response.model_dump_json(indent=2, exclude_none=True) — مختصر"
{
  "candidates": [
    {
      "content": { "role": "model", "parts": [ { "text": "We were going to the office yesterday." } ] },
      "finish_reason": "STOP"
    }
  ],
  "usage_metadata": {
    "prompt_token_count": 24,
    "candidates_token_count": 9,
    "thoughts_token_count": 40,
    "total_token_count": 73
  },
  "model_version": "gemini-3.8-flash"
}
```

```python title="توصل لكل حاجة إزاي"
response.text
response.candidates[0]
.content.parts
.finish_reason
response.usage_metadata
response.function_calls
```

1. `response.text`: النص كله ملزوق من الـ parts. <strong>بس ممكن يرجع `None`</strong>: لو الرد كان Function call بس، أو اتمنع (Blocked). فمتعملش `response.text.strip()` على طول.
2. `response.candidates[0]`: "المرشّح" الأول. ممكن تطلب أكتر من رد في نفس الـ Request (`candidate_count`)، بس عادة واحد.
3. `.content.parts`: List أجزاء: نص، أو `function_call`، أو صورة… زي `output` في OpenAI.
4. `.finish_reason`: ليه وقف: `STOP` (خلّص طبيعي)، `MAX_TOKENS` (اتقطع)، `SAFETY` (اتمنع)… وهو Enum، فقارنه بـ `types.FinishReason.MAX_TOKENS`.
5. `response.usage_metadata`: `prompt_token_count` = Input، و`candidates_token_count` = الـ Output الظاهر، و`thoughts_token_count` = توكنز التفكير (**بتتحسب بسعر الـ Output برضه**)، و`cached_content_token_count` = اللي اتحسب Cache.
6. `response.function_calls`: Property جاهزة: List بالـ Function calls لو فيه (فصل 22).

```python title="قراية آمنة"
text = response.text or ""
cand = response.candidates[0] if response.candidates else None
if cand and cand.finish_reason == types.FinishReason.MAX_TOKENS:
    log.warning("cut off")
if not text.strip():
    raise RuntimeError("empty or blocked reply")
```

## 17.4 Streaming و Chats

```python
for chunk in client.models.generate_content_stream(
    model="gemini-3.8-flash", contents="Write a haiku about Cairo."
):
    print(chunk.text or "", end="", flush=True)
```

في Gemini الـ Streaming Method منفصلة اسمها `generate_content_stream` (مش Parameter زي OpenAI)، وكل `chunk` فيه `.text` بالحتة الجديدة.

```python
chat = client.chats.create(model="gemini-3.8-flash")
r1 = chat.send_message("Suggest 3 titles for an article about tea.")
r2 = chat.send_message("Make the second one shorter.")   # فاكر اللي فات
print(r2.text)
```

`client.chats` مجرد مساعد: بيشيل المحادثة في الذاكرة، وبيبعتها كلها مع كل `send_message`. يعني الموديل لسه مبيفتكرش، الـ SDK هو اللي بيفتكر بدالك.

## 17.5 الـ Interactions API (Beta)

```python
interaction = client.interactions.create(
    model="gemini-3.8-flash",
    input="Rewrite: 'we was late'",
    system_instruction="You are a careful editor.",
    generation_config={"thinking_level": "low"},
)
print(interaction.output_text)

follow = client.interactions.create(
    model="gemini-3.8-flash",
    input="Now make it formal.",
    previous_interaction_id=interaction.id,       # السيرفر فاكر
)
```

**generate\_content و Interactions جنب بعض**

|   | generate\_content | interactions.create |
|---|---|---|
| الحالة | Stable، موصى بيه للإنتاج | Beta، موصى بيه للمشاريع الجديدة، وممكن يتغيّر |
| البيانات | `contents=` | `input=` |
| الإعدادات | `config=types.GenerateContentConfig(...)` | Parameters مباشرة + `generation_config={...}` |
| النص | `response.text` | `interaction.output_text` |
| المحادثة | تبعت التاريخ (أو `client.chats`) | `previous_interaction_id` على السيرفر |
| Streaming | `generate_content_stream` | `stream=True` وevents نوعها `"step.delta"` |
| Batch API و Explicit caching | مدعومين | لسه مش مدعومين (حسب الدوكيومنتيشن) |

:::caution[خلي بالك]
لو لقيت اسكريبت فيه `interaction.outputs`، ده الشكل القديم قبل تغيير مايو 2026. الشكل الجديد فيه `steps` بدلها. ودي بالظبط مخاطرة الـ Beta: الكود ممكن يبوظ مع تحديث المكتبة. فثبّت نسخة `google-genai` في requirements.txt لو بتستخدمه.
:::

**المصادر الرسمية:** [Gemini · Interactions API](https://ai.google.dev/gemini-api/docs/interactions) · [Interactions · Text generation](https://ai.google.dev/gemini-api/docs/interactions/text-generation) · [Breaking changes (May 2026)](https://ai.google.dev/gemini-api/docs/interactions-breaking-changes-may-2026)

:::tip[حاجة مشتركة: @google/genai في JS]
نفس الـ SDK في npm: `import { GoogleGenAI } from "@google/genai"; const ai = new GoogleGenAI({});` و`const r = await ai.models.generateContent({ model, contents, config: { systemInstruction, maxOutputTokens } });` و`r.text`. نفس الشكل بالظبط، بس camelCase و await.
:::

:::tip[ملخص الفصل]
- `from google import genai` و`from google.genai import types`، و`genai.Client()` (و`GOOGLE_API_KEY` بتكسب).
- `client.models.generate_content(model, contents, config=types.GenerateContentConfig(...))`.
- `response.text` ممكن يبقى None. و`candidates[0].finish_reason` و`usage_metadata` (التفكير في `thoughts_token_count`).
- الـ timeout في `HttpOptions` بالملّي ثانية.
- Streaming: `generate_content_stream`. محادثة: `client.chats`.
- Interactions (Beta): `input` و`output_text` و`previous_interaction_id`.
:::

### صح ولا غلط؟

1. `HttpOptions(timeout=30)` معناها 30 ثانية.
2. `response.text` دايماً نص.
3. الـ Batch API شغّال مع Interactions API النهارده.

### أسئلة مراجعة

1. عندك `GEMINI_API_KEY` جديد وبتاخد 403. إيه احتمال إن `GOOGLE_API_KEY` هو السبب؟
2. من الـ JSON في الفصل: كام توكن هتدفعهم بسعر الـ Output؟
3. إمتى تختار generate\_content وإمتى Interactions؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** شغّل نداء generate\_content واطبع `response.usage_metadata`.
2. **[متوسط]** جرّب `max_output_tokens=10` واطبع `finish_reason`.
3. **[صعب]** اعمل نفس المحادثة (دورين) مرة بـ `client.chats` ومرة بـ Interactions و`previous_interaction_id`.
