<small>المرحلة 3 · قوة الـ Shell</small>

تخيل إنك خلصت مشروع React فيه 300 ملف، وقبل ما ترفعه افتكرت إنك سايب console.log في حتت كتير. هتفتح الملفات واحد واحد؟ أو عندك Log فيه نص مليون سطر، وعايز تعرف أكتر 10 IPs عملوا طلبات فاشلة. في Excel ده ساعة، وفي الـ Terminal سطر واحد. الفصل ده بيشرح عُدّة معالجة النصوص: grep و sed و awk و cut و sort و uniq و wc و tr و tee و xargs، وبعدين find و mdfind (Spotlight) للبحث عن الملفات، وفي الآخر بنركبهم في Pipelines حقيقية. وهنا بالذات هتقابل فروقات الماك عن Linux كتير، فخلي عينك على صناديق "على Linux".

:::note[بعد الفصل ده هتكون عارف]
- grep للبحث جوه الملفات بكل الـ Flags المهمة
- أساسيات الـ Regex المشتركة بين grep و sed و awk
- sed للاستبدال و awk للأعمدة
- cut و sort و uniq و wc و tr
- tee و xargs وإزاي يكملوا الـ Pipes
- find و mdfind (Spotlight) و locate والفرق بينهم وبين grep
- فروقات BSD المهمة: sed -i '' و grep -P و xargs
- Pipelines لتحليل لوجات حقيقية
:::

طول الفصل هنشتغل على ملف لوج بسيط بالشكل ده (اسمه `access.log`، زي لوجات nginx):

```text title="access.log"
192.168.1.10 - - [22/Oct/2026:09:14:02 +0300] "GET /index.html HTTP/1.1" 200 5120
10.0.0.7 - - [22/Oct/2026:09:14:05 +0300] "GET /admin HTTP/1.1" 403 210
192.168.1.10 - - [22/Oct/2026:09:15:11 +0300] "POST /login HTTP/1.1" 401 98
172.16.0.3 - - [22/Oct/2026:09:16:40 +0300] "GET /img/logo.png HTTP/1.1" 404 0
```

كل سطر أعمدة مفصولة بمسافات: **$1** الـ IP، و **$4** الوقت، و **$6** الـ Method، و **$7** المسار، و **$9** الـ Status code، و **$10** الحجم.

:::note[يعني إيه Method و Status code هنا؟]
السطر ده بيسجّل كل زيارة للموقع. الـ **Method** هي نوع الطلب: `GET` = "هاتلي الصفحة"، و `POST` = "خد البيانات دي". والـ **Status code** رقم السيرفر رد بيه: `200` تمام، `404` الصفحة مش موجودة، `403` ممنوع، و `5xx` مشكلة في السيرفر. الشرح الكامل في كتاب الإنترنت (فصل 7 و 8)، بس ده كفاية علشان تفلتر الـ Log دلوقتي.
:::

## 8.1 grep: دوّر على سطور

فاكر <kbd>Cmd+F</kbd> اللي بتدور بيه في أي صفحة؟ `grep` هو نفس الفكرة، بس بيدوّر في ملف واحد أو في ألف ملف مرة واحدة، وبيطبعلك كل سطر فيه الكلمة ومكانه بالظبط. خلينا نرجع لمشكلة الـ `console.log` اللي في أول الفصل، بس المرة دي هندوّر على كلمة `todo` اللي بنسيبها لنفسنا في الكود:

**تشريح الأمر**

```sh
grep -rniw --include="*.py" "todo" ~/project
```

1. `grep`: Global Regular Expression Print: اطبع كل سطر فيه النمط.
2. `-rniw`: أربعة مدموجين: `-r` (Recursive: دوّر في المجلد وكل اللي جواه، نفس معنى -r في cp و rm)، `-n` (اطبع رقم السطر)، `-i` (Ignore case: TODO = todo)، `-w` (Word: كلمة كاملة، فـ `todos` متتحسبش).
3. `--include="*.py"`: دوّر في ملفات Python بس. الـ Quotes مهمة عشان الـ Shell ميوسعش النجمة قبل grep ([↩ 7.4](../ch07/#s7-4 "الـ Globbing: النجمة وأخواتها")).
4. `"todo"`: النمط (Pattern). بيتعامل معاه كـ Regex.
5. `~/project`: فين يدوّر. لو مفيش مسار ومفيش -r، grep بيقرا من stdin (يعني بيشتغل في Pipe).

**أهم Flags بتاعة grep**

| Flag | المعنى |
|---|---|
| `-i` | تجاهل حالة الحروف |
| `-v` | Invert: اعكس، السطور اللي **مفيهاش** النمط (`-v` هنا مش Verbose!) |
| `-c` | Count: عدد السطور المطابقة بس |
| `-n` | رقم السطر |
| `-l` | أسماء الملفات اللي فيها تطابق بس |
| `-r` / `-R` | Recursive (على Linux `-R` بيتبع الـ Symlinks، وعلى الماك الاتنين واحد تقريباً) |
| `-w` / `-x` | كلمة كاملة / السطر كله بالظبط |
| `-E` | Extended Regex: `\| + ? ()` من غير `\` (= `egrep` القديم) |
| `-F` | Fixed: النمط نص عادي مش Regex (أسرع، و `.` بتبقى نقطة) |
| `-o` | Only: اطبع الجزء المطابق بس مش السطر كله |
| `-A 3` / `-B 3` / `-C 3` | After / Before / Context: سطور بعد/قبل/حوالين التطابق |
| `-q` | Quiet: متطبعش حاجة، استخدم الـ Exit code بس (للـ Scripts، [↩ 7.7](../ch07/#s7-7 "الـ Exit Codes و && و \|\| و ;")) |
| `-P` | Perl Regex (زي `\d` والـ Lookahead). **مش موجود في grep بتاع الماك**: استخدم `-E`، أو `brew install grep` واستخدم `ggrep -P`، أو `rg` |

:::tip[-v بتختلف من أمر للتاني]
في معظم الأوامر `-v` = Verbose (`cp -v`، `mkdir -v`، `tar -v`)، لكن في `grep` = Invert، وفي `sort -V` (كبيرة) = Version sort. ودي من أشهر المفاجآت. شوف جدول الـ Flags المشتركة ([↩ 2.5](../ch02/#s2-5 "الـ Flags المشتركة: القاموس الكبير"))، ولما تشك: `--help`.
:::

### Regex في دقيقتين

**أساسيات الـ Regular Expressions**

| الرمز | المعنى | مثال |
|---|---|---|
| `.` | أي حرف واحد | `h.t` = hat, hot |
| `*` | اللي قبلها 0 مرة أو أكتر (مش زي الـ Glob!) | `ab*c` = ac, abbc |
| `+` | مرة أو أكتر (ERE) | `[0-9]+` |
| `?` | اختياري (ERE) | `colou?r` |
| `^` / `$` | بداية / نهاية السطر | `^#` سطور كومنت |
| `[abc]` و `[^abc]` | حرف من دول / مش من دول | `[0-9]` |
| `a\|b` | دي أو دي (ERE) | `error\|fail` |
| `(...)` | جروب (ERE) | `(ab)+` |
| `{n,m}` | عدد مرات (ERE) | `[0-9]{1,3}` |
| `\` | الغي معنى الرمز | `\.` نقطة حقيقية |

:::tip[Regex مشترك بين grep و sed و awk]
نفس الرموز دي بتشتغل في الـ 3 أوامر (وفي `find -regex` و `less` بـ `/` و vim وبايثون). BRE (الافتراضي في grep و sed) محتاج `\+ \| \(\)`، و ERE (`grep -E` و `sed -E` و awk دايماً) من غير Backslash. ابدأ بـ `-E` على طول وريّح دماغك. وخلي بالك: `*` في الـ Regex غير `*` في الـ Glob؛ والنمط حطه في Single quotes عشان الـ Shell ميلمسوش.
:::

**تشريح الأمر**

```sh
grep -Eo '^[0-9]{1,3}(\.[0-9]{1,3}){3}' access.log
```

1. `grep`: دوّر.
2. `-Eo`: `-E` Regex موسّع، و `-o` اطبع الجزء المطابق بس (الـ IP مش السطر).
3. `'`: Single quote: متخليش الـ Shell يلمس الرموز ([↩ 7.5](../ch07/#s7-5 "الـ Quoting: إمتى الـ Shell يفهم الرموز وإمتى لأ")).
4. `^`: من أول السطر.
5. `[0-9]{1,3}`: رقم من 1 لـ 3 خانات.
6. `(\.[0-9]{1,3}){3}`: نقطة حقيقية (`\.`) ورقم، والجروب ده يتكرر 3 مرات.
7. `access.log`: الملف.

## 8.2 sed: عدّل النص وهو ماشي

الموقع بتاعك اتنقل لـ HTTPS، وعندك ملف إعدادات فيه 40 لينك لسه بادئين بـ `http://`. في VS Code هتعمل Find & Replace، تمام. بس لو الملف على سيرفر، أو عايز تعمل ده في 50 ملف مرة واحدة، أو جوه Script بيشتغل لوحده؟ هنا بييجي دور `sed`: "Find & Replace" بالأوامر. وخلي بالك، ده من أكتر الأوامر اللي بتختلف بين الماك و Linux، فركز معايا في الـ `-i`:

**تشريح الأمر**

```sh
sed -i.bak -E 's/http:\/\//https:\/\//g' config.txt
```

1. `sed`: Stream EDitor: بيعدّل كل سطر وهو بيعدي.
2. `-i.bak`: In-place: عدّل الملف نفسه بدل ما تطبع، و `.bak` لازقة فيها = احتفظ بنسخة قديمة `config.txt.bak`. على الماك الـ `-i` **لازم** ياخد امتداد للنسخة، ولو مش عايز نسخة خالص تكتب `-i ''` (علامتين تنصيص فاضيين). والشكل `-i.bak` اللازق ده بيشتغل على الماك و Linux الاتنين، فهو الأضمن في الـ Scripts.
3. `-E`: Extended Regex (نفس grep).
4. `s`: Substitute: أمر الاستبدال. الشكل `s/القديم/الجديد/flags`.
5. `/http:\/\//`: النمط القديم. الـ `/` هي الفاصل، فأي `/` جوه النص لازم تتكتب `\/`.
6. `https:\/\//`: النص الجديد.
7. `g`: Global: كل التطابقات في السطر، مش أول واحد بس.
8. `config.txt`: الملف.

**sed -i على الماك مقابل Linux**

<table class="cmp keep">
<tr><th>عايز</th><th>الماك (BSD)</th><th>Linux (GNU)</th></tr>
<tr><td>عدّل من غير نسخة</td><td><code>sed -i '' 's/a/b/' f</code></td><td><code>sed -i 's/a/b/' f</code></td></tr>
<tr><td>عدّل واحتفظ بنسخة</td><td><code>sed -i .bak 's/a/b/' f</code> أو <code>-i.bak</code></td><td><code>sed -i.bak 's/a/b/' f</code></td></tr>
<tr><td>يشتغل على الاتنين</td><td colspan="2"><code>sed -i.bak 's/a/b/' f &amp;&amp; rm f.bak</code>، أو <code>gsed -i</code> من <code>brew install gnu-sed</code></td></tr>
</table>

:::tip[غيّر الفاصل وارتاح]
الفاصل ممكن يبقى أي حرف: `sed 's|http://|https://|g'` أوضح بكتير من غابة الـ `\/`. وجرّب دايماً من غير `-i` الأول عشان تشوف النتيجة.
:::

| الأمر | بيعمل إيه |
|---|---|
| `sed -n '10,20p' f` | `-n` متطبعش تلقائي، و `p` اطبع السطور من 10 لـ 20 بس. |
| `sed '/^#/d' f` | `d` = Delete: امسح السطور اللي بتبدأ بـ `#`. |
| `sed '/^$/d' f` | امسح السطور الفاضية (`^$` = بداية ونهاية من غير حاجة بينهم). |
| `sed 's/a/b/2' f` | استبدل التطابق التاني بس في كل سطر. |
| `sed -E 's/([[:alnum:]]+) ([[:alnum:]]+)/\2 \1/' f` | `\1 \2` = اللي اتمسك في الجروب الأول والتاني: بيبدّل كلمتين. و `[[:alnum:]]` = حرف أو رقم، وده شغال في كل نسخ sed (أما `\w` فمش مضمون على الماك). |

## 8.3 awk: لغة الأعمدة

لو `grep` هو <kbd>Cmd+F</kbd>، فـ `awk` هو Excel مصغّر جوه الـ Terminal. اسمه جاي من أسامي التلات علماء اللي عملوه سنة 1977 (Aho و Weinberger و Kernighan)، وهو في الحقيقة لغة برمجة صغيرة كاملة. بس إحنا هنستخدم أهم حاجة فيه: إنه بيشوف كل سطر كأنه صف في جدول. `awk` بيقسم كل سطر لأعمدة (`$1`، `$2`… و `$0` = السطر كله) وبيخليك تكتب شروط وحسابات.

خلينا نجرّبه على ملف `/etc/passwd` اللي اتكلمنا عنه في [↩ 6.5](../ch06/#s6-5 "المستخدمين والجروبات"). على الماك الملف ده فيه مستخدمين النظام بس، وكل سطر شكله `_www:*:70:70:World Wide Web Server:/Library/WebServer:/usr/bin/false`، وفي أوله سطور تعليقات بتبدأ بـ `#`. عايزين نعرف مين من المستخدمين دول ليه Shell حقيقي يقدر يدخل بيه:

**تشريح الأمر**

```sh
awk -F: '!/^#/ && $7 != "/usr/bin/false" { print $1, $7 }' /etc/passwd
```

1. `awk`: اقرا سطر سطر، ونفّذ البرنامج اللي بين الـ Quotes على كل سطر.
2. `-F:`: Field separator: الأعمدة مفصولة بـ `:` بدل المسافات.
3. `'`: Single quotes: عشان `$7` هنا تبع awk مش متغير Shell.
4. `!/^#/`: شرط أول: `/^#/` = Regex "السطر بيبدأ بـ #"، و `!` قبله = "مش". يعني سيب التعليقات.
5. `&&`: و (AND): الشرطين لازم يتحققوا.
6. `$7 != "/usr/bin/false"`: شرط تاني: العمود السابع (الـ Shell) مش `/usr/bin/false` (ده "Shell" وهمي بيقفل على طول، بيتحط للمستخدمين اللي مش مفروض يدخلوا).
7. `{ print $1, $7 }`: الـ Action: اطبع الاسم والـ Shell. الـ `,` بتحط مسافة بينهم.
8. `/etc/passwd`: الملف.

:::note[على Linux]
على السيرفر الملف ده فيه كل المستخدمين، والمثال المشهور هو `awk -F: '$3 >= 1000 { print $1, $7 }' /etc/passwd`: العمود التالت (الـ UID) أكبر من أو يساوي 1000 = مستخدمين حقيقيين.
:::

| الأمر | بيعمل إيه |
|---|---|
| `awk '{print $NF}' f` | `NF` = Number of Fields، فـ `$NF` = آخر عمود. |
| `awk 'NR>1' data.csv` | `NR` = Number of Record (رقم السطر): كله ماعدا الهيدر. |
| `awk '{s+=$10} END {print s}' access.log` | اجمع العمود العاشر، و `END` = بعد آخر سطر اطبع المجموع. |
| `awk '$9==404 {print $7}' access.log` | المسارات اللي رجعت 404. |

## 8.4 cut: قص الأعمدة

أحياناً مش محتاج كل قوة awk. عندك ملف CSV صدّرته من Google Sheets، وعايز العمود الأول والتالت بس. هنا `cut` هو المقص البسيط:

**تشريح الأمر**

```sh
cut -d',' -f1,3 users.csv
```

1. `cut`: قص أجزاء من كل سطر.
2. `-d','`: Delimiter: الفاصل فاصلة. (الافتراضي Tab، و cut مبيفهمش "مسافات كتير" كفاصل واحد، ساعتها استخدم awk).
3. `-f1,3`: Fields: العمود الأول والتالت. وممكن Range: `-f2-4`. و `-c1-10` = أول 10 حروف.
4. `users.csv`: الملف.

## 8.5 tr: بدّل الحروف

زميلك بعتلك ملف معمول على Windows، وأول ما فتحته في الـ Terminal لقيت في آخر كل سطر `^M` غريبة، والـ Script بتاعك بيبوظ بسببها. أو عايز تحوّل نص كله لحروف كبيرة. `tr` هو أداة "بدّل الحرف ده بالحرف ده" أو "امسح الحرف ده خالص":

**تشريح الأمر**

```sh
echo "Hello World" | tr 'a-z' 'A-Z'
```

1. `echo "Hello World"`: النص.
2. `|`: ودّيه لـ tr، لأن tr بيقرا من stdin **بس**، مبياخدش اسم ملف (استخدم `< file`، [↩ 7.2](../ch07/#s7-2 "الـ Redirection: وجّه الـ Streams")).
3. `tr`: TRanslate: بدّل حروف بحروف.
4. `'a-z'`: المجموعة الأولى: الحروف الصغيرة.
5. `'A-Z'`: المجموعة التانية: كل حرف يقابل اللي في نفس مكانه. النتيجة `HELLO WORLD`.

| الأمر | بيعمل إيه |
|---|---|
| `tr -d '\r' < win.txt > unix.txt` | `-d` = Delete: شيل الـ Carriage return بتاع ملفات Windows. |
| `tr -s ' '` | `-s` = Squeeze: المسافات المتكررة تبقى واحدة (مفيد قبل cut). |
| `tr ':' '\n' <<< "$PATH"` | اعرض الـ PATH كل مجلد في سطر ([↩ 13.5](../ch13/#s13-5 "الـ PATH: ضيف مجلد صح")). |

## 8.6 sort و uniq: رتّب وشيل المكرر

الاتنين دول زي الأخين اللي مبيمشوش غير مع بعض. `sort` بيرتب، و `uniq` بيشيل المكرر. ولما تجمعهم بتقدر تجاوب على أسئلة زي "مين أكتر واحد بعت طلبات؟" و "أنهي صفحة أكتر صفحة بتفشل؟":

**تشريح الأمر**

```sh
sort -t',' -k3,3nr users.csv
```

1. `sort`: رتّب السطور.
2. `-t','`: الفاصل فاصلة (في cut اسمه `-d`، وفي sort اسمه `-t`، وفي awk `-F`. نفس الفكرة 3 أسماء!).
3. `-k3,3`: Key: رتّب بالعمود التالت لحد التالت (من غيرها `-k3` = من التالت لآخر السطر).
4. `nr`: لازقين في الـ Key: `n` Numeric (عشان 10 تيجي بعد 9 مش بعد 1) و `r` Reverse (الأكبر الأول).
5. `users.csv`: الملف.

**Flags بتاعة sort و uniq**

| الأمر | Flag | المعنى |
|---|---|---|
| sort | `-n` / `-h` | أرقام / أحجام Human (2K قبل 1M) |
| sort | `-r` | اعكس الترتيب |
| sort | `-u` | Unique: شيل المكرر |
| sort | `-o file` | اكتب الناتج في ملف (حتى لو نفس ملف الدخل) |
| uniq | (من غير) | شيل السطور المكررة **المتجاورة** بس |
| uniq | `-c` | Count: حط عدد التكرار قبل كل سطر |
| uniq | `-d` / `-u` | المكرر بس / اللي ملوش تكرار بس |

:::caution[uniq محتاج sort قبله]
`uniq` بيقارن كل سطر باللي قبله بس، فلو التكرارات متفرقة مش هيشوفها. عشان كده هتشوف دايماً `sort | uniq -c` مع بعض.
:::

<a id="s8-7"></a>

## 8.7 wc: عِد السطور والكلمات

**تشريح الأمر**

```sh
wc -lwc notes.txt
```

1. `wc`: Word Count: عِد.
2. `-lwc`: `-l` سطور، و `-w` كلمات، و `-c` Bytes (و `-m` حروف، مهمة للعربي لأن الحرف العربي 2 Bytes في UTF-8).
3. `notes.txt`: الملف. ولو من stdin (`ls | wc -l`) مش هيطبع اسم ملف.

```sh title="Terminal"
$ wc -l notes.txt
      42 notes.txt
$ wc -l < notes.txt
      42
```

<small>على الماك `wc` بيحط مسافات قبل الرقم. لو هتستخدم الرقم في Script وعايزه نضيف: `wc -l < notes.txt | tr -d ' '`.</small>

<a id="s8-8"></a>

## 8.8 tee: شوف واحفظ في نفس الوقت

**تشريح الأمر**

```sh
./build.sh 2>&1 | tee -a build.log
```

1. `./build.sh 2>&1`: شغّل الـ Script وخلي الأخطاء تمشي مع الناتج ([↩ 7.2](../ch07/#s7-2 "الـ Redirection: وجّه الـ Streams")).
2. `|`: Pipe.
3. `tee`: زي حرف T في السباكة: بيكتب الداخل على الشاشة **وفي ملف** في نفس الوقت.
4. `-a`: Append: ضيف على الملف بدل ما تمسحه (زي `>>`).
5. `build.log`: الملف. وعشان tee برنامج مستقل، ينفع تشغله بـ sudo: `| sudo tee /etc/x` ([↩ 6.6](../ch06/#s6-6 "sudo و su")).

## 8.9 xargs: من سطور لـ Arguments

هنا مشكلة غريبة شوية: `find` طلعلك لستة بـ 50 ملف `.tmp`، وعايز تمسحهم. فكتبت `find . -name "*.tmp" | rm` ومحصلش حاجة. ليه؟ بعض الأوامر مبتقراش من stdin، بتاخد Arguments بس (`rm` و `mkdir` و `echo`). `xargs` بيحوّل السطور اللي داخلاله لـ Arguments.

**تشريح الأمر**

```sh
find . -name "*.tmp" -print0 | xargs -0 rm -v
```

1. `find . -name "*.tmp"`: هات كل ملفات tmp (تحت).
2. `-print0`: افصل الأسماء بـ Null character (`\0`) بدل سطر جديد، عشان الأسماء اللي فيها مسافات ومعاها سطور جديدة متتقطعش.
3. `|`: Pipe.
4. `xargs`: خد اللي جاي من stdin وحطه Arguments للأمر اللي بعده.
5. `-0`: الأسماء مفصولة بـ Null (لازم يمشي مع `-print0`).
6. `rm -v`: الأمر اللي هيتنفذ: `rm -v ./a.tmp ./b.tmp …`.

:::note[على Linux]
على Linux، `xargs` بيشغّل الأمر مرة واحدة حتى لو مفيش ولا اسم داخل، فبتلاقي الناس كاتبة `xargs -0 -r rm -v`: الـ `-r` = No-run-if-empty. الـ xargs بتاع الماك أصلاً مبيشغّلش الأمر لو مفيش مدخلات، فالـ `-r` ملهاش لازمة عندك، ومتعتمدش عليها في Script هيشتغل على الماك لأن نسخ كتير منه بترفضها بـ `illegal option`. لو محتاج سطر يشتغل في الاتنين، استخدم لوب `while read` ([↩ 12.4](../ch12/#s12-4 "اللوبات: for و while")) أو `find ... -delete`.
:::

| الأمر | بيعمل إيه |
|---|---|
| `xargs -n 1` | Argument واحد لكل مرة تشغيل. |
| `xargs -I{} cp {} /backup/` | `-I{}`: حط كل سطر مكان `{}` (بيشغل مرة لكل سطر). |
| `xargs -P 4` | Parallel: شغّل 4 في نفس الوقت. |

## 8.10 find و mdfind: دوّر على ملفات

فاكر لما كنت عايز تلاقي كل ملفات الـ Log الكبيرة اللي واكلة المساحة؟ أو كل مجلدات `node_modules` المنسية في مشاريع قديمة؟ الـ Finder بيدوّر بالاسم وخلاص، لكن `find` بيدوّر بأي حاجة: الاسم، والحجم، والتاريخ، والنوع، والصلاحيات، وكمان بيعمل حاجة على كل ملف بيلاقيه:

**تشريح الأمر**

```sh
find ~/projects -type f -name "*.log" -size +10M -mtime -7 -exec ls -lh {} \;
```

1. `find`: دوّر على ملفات بخصائصها (الاسم، الحجم، التاريخ...) بالمشي في المجلدات فعلاً.
2. `~/projects`: نقطة البداية (لازم تيجي الأول، و `.` = هنا). على الماك المسار ده **إجباري**: `find -name x` من غير مسار هتطلعلك Error (على Linux بتشتغل وتعتبره `.`).
3. `-type f`: ملفات عادية بس (`d` مجلدات، `l` Links). في find الشروط كلمة كاملة بشَرطة واحدة.
4. `-name "*.log"`: الاسم بيطابق الـ Glob ده، والـ Quotes إجبارية عشان find هو اللي يفهم النجمة مش الـ Shell. و `-iname` من غير حالة الحروف.
5. `-size +10M`: أكبر من 10 ميجا (`+` أكبر، و `-` أصغر، ومن غيرهم = بالظبط).
6. `-mtime -7`: Modified time: اتعدّل في آخر 7 أيام (`-mmin -30` = آخر 30 دقيقة).
7. `-exec ls -lh {}`: نفّذ أمر على كل ملف لقيته، و `{}` = مكان اسم الملف.
8. `\;`: نهاية الـ `-exec`. الـ `\` عشان الـ Shell ميفهمش `;` إنها فاصل أوامر. ولو كتبت `+` بدلها، find هيجمّع الملفات كلها في أمر واحد (أسرع).

**أهم شروط find**

| الشرط | المعنى |
|---|---|
| `-name` / `-iname` / `-path` | بالاسم / بالاسم من غير حالة / بالمسار كله |
| `-type f\|d\|l` | النوع |
| `-size +1G` | الحجم (`k M G`) |
| `-mtime` / `-mmin` / `-newer f` | وقت التعديل |
| `-user ahmed` / `-perm 777` | المالك / الصلاحيات ([↩ 6.2](../ch06/#s6-2 "chmod: تغيير الصلاحيات")) |
| `-maxdepth 2` | متنزلش أكتر من مستويين (حطها بدري) |
| `-empty` | ملفات أو مجلدات فاضية |
| `! -name x` / `-o` | NOT / OR (و AND هو الافتراضي) |
| `-delete` | امسح اللي لقيته (خطر: جرّب من غيرها الأول) |
| `-print0` | للاستخدام مع `xargs -0` |

### mdfind: الـ Spotlight من الـ Terminal

الماك عنده ميزة مش موجودة على Linux: الـ **Spotlight** (اللي بتفتحه بـ <kbd>Cmd+Space</kbd>) طول الوقت شغال في الخلفية وعامل فهرس بكل ملفاتك، وكمان بمحتواها. والأمر `mdfind` بيخليك تسأل الفهرس ده من الـ Terminal، فالنتيجة بتطلع لحظياً:

**تشريح الأمر**

```sh
mdfind -onlyin ~/projects -name package.json
```

1. `mdfind`: Metadata find: دوّر في فهرس الـ Spotlight.
2. `-onlyin ~/projects`: دوّر جوه المجلد ده بس (من غيرها بيدوّر في الجهاز كله).
3. `-name package.json`: بالاسم. ومن غير `-name` بيدوّر في **المحتوى** كمان: `mdfind "API_KEY"` هيجيبلك كل ملف فيه الكلمة دي.

وفيه أخوه `mdls file.pdf` اللي بيعرض كل الـ Metadata بتاعة ملف (عدد الصفحات، أبعاد الصورة، اتنزل منين)، و `mdutil -s /` بيقولك الفهرسة شغالة ولا لأ.

**find مقابل grep مقابل mdfind**

|   | `find` | `grep -r` | `mdfind` |
|---|---|---|---|
| بيدوّر على | ملفات بخصائصها | **محتوى** جوه الملفات | بالاسم أو المحتوى أو الـ Metadata |
| بيقرا | شجرة الملفات حالاً | محتوى كل ملف | فهرس Spotlight الجاهز |
| السرعة | متوسطة | أبطأ (بيقرا كل حاجة) | لحظي |
| محدّث؟ | دايماً | دايماً | تقريباً لحظي، بس مبيفهرسش كل حاجة (زي المجلدات المخفية وبعض مجلدات النظام) |
| استخدمه لما | "الملفات الكبيرة اللي اتعدلت امبارح" | "فين السطر اللي فيه API\_KEY في المشروع" | "فين ملف package.json بتاع المشروع القديم" |

:::note[على Linux: locate]
**تشريح الأمر**

```sh
locate -i nginx.conf
```

1. `locate`: دوّر في **قاعدة بيانات** فيها أسماء كل الملفات (سريع جداً لأنه مبيمشيش في القرص). على التوزيعات الحديثة الحزمة اسمها `plocate`.
2. `-i`: من غير حالة الحروف.
3. `nginx.conf`: جزء من الاسم أو المسار. القاعدة بتتحدّث يومياً، فالملفات الجديدة أوي مش هتظهر غير بعد `sudo updatedb`.

الماك عنده `locate` برضه، بس قاعدة البيانات بتاعته مش متفعّلة افتراضياً، و `mdfind` أحسن منه في كل حاجة تقريباً.
:::

:::note[بدائل حديثة]
`rg` (ripgrep) بديل أسرع لـ `grep -r` وبيتجاهل اللي في `.gitignore` وبيفهم Regex زي `\d`، و `fd` بديل أبسط لـ find. سطّبهم بـ `brew install ripgrep fd` ([↩ 11.1](../ch11/#s11-1 "الفكرة: المخزن والحزمة والاعتماديات")). وعلى Ubuntu الحزمة اسمها `fd-find` والأمر `fdfind`.
:::

## 8.11 Pipelines حقيقية لتحليل اللوجات

دلوقتي جه وقت نجمع كل اللي اتعلمناه. تخيل إن موقعك بقى بطيء فجأة، ومديرك بيسألك: "مين اللي بيضرب السيرفر بالطلبات دي؟". الإجابة سطر واحد، بس كل حتة فيه أمر من الأوامر اللي فاتت. اقراه من الشمال لليمين كأنه قصة:

**تشريح الأمر**

```sh
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
```

1. `awk '{print $1}' access.log`: طلّع العمود الأول (الـ IP) من كل سطر.
2. `| sort`: رتّبهم عشان المتشابه يبقى جنب بعض.
3. `| uniq -c`: اجمع المتكرر وحط عدده قدامه: ` 58 192.168.1.10`.
4. `| sort -rn`: رتّب بالرقم، الأكبر الأول.
5. `| head -10`: أول 10 بس ([↩ 5.5](../ch05/#s5-5 "قراية الملفات: cat و less و head و tail")). النتيجة: أكتر 10 IPs بيبعتوا طلبات.

| الأمر | بيعمل إيه |
|---|---|
| `awk '{print $9}' access.log \| sort \| uniq -c \| sort -rn` | توزيع الـ Status codes (كام 200 وكام 404...). |
| `awk '$9 ~ /^5/' access.log \| wc -l` | عدد أخطاء السيرفر (أي كود بيبدأ بـ 5). الـ `~` = يطابق Regex. |
| `awk '$9==404 {print $7}' access.log \| sort \| uniq -c \| sort -rn \| head` | أكتر صفحات مش موجودة الناس بتطلبها. |
| `grep "22/Oct/2026:09" access.log \| wc -l` | عدد الطلبات في الساعة 9. |
| `tail -f access.log \| grep --line-buffered " 500 "` | راقب الأخطاء لايف. `--line-buffered` عشان grep يطبع كل سطر فوراً وهو في Pipe. |
| `log show --last 1h --style compact \| grep -i error` | نفس الفكرة على Logs النظام في الماك (على Linux: `journalctl --since today`، [↩ 9.5](../ch09/#s9-5 "الخدمات على الماك: launchd و launchctl و brew services")). |

## 8.12 مشاكل شائعة

:::danger[مشكلة: grep بيطلع سطور مش عايزها لما أدور على 1.2.3.4]
النقطة في الـ Regex = أي حرف، فـ `1.2.3.4` هتطابق `1a2b3c4` كمان.

<strong>الحل:</strong> `grep -F "1.2.3.4"` (نص ثابت) أو هرّب النقط `'1\.2\.3\.4'`.
:::

:::danger[مشكلة: sed: 1: "config.txt": invalid command code c]
نسخت من شرح Linux `sed -i 's/a/b/' config.txt` وطلعلك الرسالة الغريبة دي. اللي حصل إن `sed` بتاع الماك افتكر إن `'s/a/b/'` هو امتداد النسخة (قيمة الـ `-i`)، وإن `config.txt` هو الأمر اللي هينفذه، فأول حرف فيه `c` اتقرا كأمر sed!

<strong>الحل:</strong> `sed -i '' 's/a/b/' config.txt` على الماك، أو `sed -i.bak ...` اللي بيشتغل في الاتنين ([↩ 2.6](../ch02/#s2-6 "ليه أوامر من النت مبتشتغلش على الماك؟ BSD ضد GNU")).
:::

:::danger[مشكلة: grep: invalid option -- P]
نسخت `grep -oP '\d+'` من Stack Overflow. الـ `-P` مش موجود في grep بتاع الماك.

<strong>الحل:</strong> `grep -oE '[0-9]+'`، أو `brew install grep` واستخدم `ggrep -oP`، أو `rg -o '\d+'`.
:::

:::danger[مشكلة: find: paths must precede expression]
كتبت `find . -name *.txt` وفي المجلد ملفين txt، فالـ Shell وسّع النجمة وبقى الأمر `find . -name a.txt b.txt`.

<strong>الحل:</strong> Quotes دايماً حوالين النمط: `-name "*.txt"` ([↩ 7.4](../ch07/#s7-4 "الـ Globbing: النجمة وأخواتها")).
:::

:::tip[ملخص الفصل]
- `grep` سطور، و `sed` استبدال، و `awk` أعمدة وحسابات، و `cut` قص سريع.
- الـ Regex مشترك بينهم، واستخدم `-E` والـ Single quotes.
- `sort | uniq -c | sort -rn | head` = "الأكتر تكراراً"، أشهر Pipeline في الدنيا.
- `tee` شاشة + ملف، و `xargs` سطور ← Arguments.
- `find` بالخصائص وحالاً (والمسار إجباري على الماك)، و `mdfind` من فهرس Spotlight لحظياً، و `grep -r` بالمحتوى.
- على الماك: `sed -i ''` (أو `-i.bak` للاتنين)، ومفيش `grep -P`، و `xargs` مش محتاج `-r`.
:::

### صح ولا غلط؟

1. `grep -v` معناها Verbose.
2. `uniq` لوحده بيشيل كل التكرارات في الملف حتى لو متفرقة.
3. على الماك، `sed -i 's/a/b/' f` هتشتغل زي Linux بالظبط.
4. في awk، `$NF` هو آخر عمود.

### أسئلة مراجعة

1. اكتب أمر يطلع عدد السطور اللي فيها "error" (بأي حالة) في كل ملفات `.log` في مجلد.
2. استبدل كل `localhost` بـ `127.0.0.1` في ملف مع الاحتفاظ بنسخة.
3. إيه الفرق بين `-d` في cut و `-t` في sort و `-F` في awk؟
4. ليه بنستخدم `-print0` مع `xargs -0`؟
5. إمتى تستخدم find وإمتى mdfind وإمتى grep؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** اطبع أسماء كل المستخدمين في `/etc/passwd` مترتبين أبجدياً (من غير سطور التعليقات).
2. **[متوسط]** من `access.log`: أكتر 5 مسارات طلبتها IPs رجعلها 403 أو 401.
3. **[صعب]** لاقي أكبر 10 ملفات في الـ home بتاعك، واعرض حجمهم بشكل مقروء، من غير ما تشوف أي Permission denied.
