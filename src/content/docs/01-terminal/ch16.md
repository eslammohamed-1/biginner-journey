<small>المرحلة 6 · الاحتراف بأمان</small>

افتكر أول يوم فتحت فيه الـ Terminal: شاشة سودا، ومؤشر بيرمش، وإنت مش عارف تكتب إيه. دلوقتي إنت عارف تتنقل في الماك كله، وتدوّر جوه آلاف الملفات، وتسطّب بـ brew، وتدخل سيرفر بـ ssh، وتكتب Scripts. وقت تجمع كل ده في حاجة واحدة بتاعتك. هنبني أداة Terminal حقيقية اسمها opskit: بتطلع تقرير عن صحة الماك (أو السيرفر)، وتحلل لوج سيرفر ويب، وتعمل Backup بتاريخ وتمسح القديم، وتنشر موقع على سيرفر بـ rsync، وتشتغل أوتوماتيك كل يوم بـ launchd. ومكتوبة بحيث تشتغل على الماك بـ bash 3.2 اللي جاي معاه، وعلى Linux من غير تعديل. كل سطر فيها هيرجعك لفصل اتعلمت فيه الحاجة دي.

:::note[بعد الفصل ده هتكون عارف]
- تخطيط أداة CLI بـ Subcommands
- كتابة Script يشتغل على الماك و Linux (uname و bash 3.2 والأدوات الـ BSD)
- تجميع Pipes و awk و sort في تقارير
- Backup آمن بـ tar و Rotation
- Deploy بـ rsync و ssh config
- التثبيت في PATH و Alias و Completion في zsh
- الجدولة بـ LaunchAgent (و cron على السيرفر)
:::

## 16.1 الخطة

قبل ما نكتب سطر كود، خلينا نعمل زي أي مطوّر محترم: نخطط. إحنا عايزين أداة واحدة، اسمها `opskit`، وتحتها أوامر فرعية زي `git commit` و `brew install` بالظبط ([↩ 2.1](../ch02/#s2-1 "الشكل العام لأي أمر")). كل أمر فرعي بيحل مشكلة حقيقية هتقابلك:

**الأوامر الفرعية في opskit**

<table class="cmp keep">
<tr><th>الأمر</th><th>بيعمل</th><th>على الماك</th><th>على Linux</th></tr>
<tr><td><code>opskit health</code></td><td>الحمل والرامات والقرص وأكتر 5 عمليات والبورتات المفتوحة</td><td>sysctl و vm_stat و df و ps و lsof</td><td>/proc و free و df و ps و ss</td></tr>
<tr><td><code>opskit logs FILE</code></td><td>أكتر IPs، وتوزيع الـ Status codes، وأكتر صفحات 404</td><td colspan="2">awk و sort و uniq و head (نفس الكود)</td></tr>
<tr><td><code>opskit backup DIR</code></td><td>أرشيف بتاريخ ويحتفظ بآخر 7</td><td colspan="2">tar و ls -t و while read (نفس الكود)</td></tr>
<tr><td><code>opskit deploy</code></td><td>ينشر مجلد على السيرفر (مع Dry run)</td><td colspan="2">rsync و ssh (نفس الكود)</td></tr>
</table>

1. <strong>الهيكل:</strong> Script واحد فيه دالة لكل أمر فرعي، و `case` بيوزّع ([↩ 12.3](../ch12/#s12-3 "الشروط: test و [ ] و [[ ]]")).
2. <strong>نظامين في ملف واحد:</strong> `uname -s` بيرجع `Darwin` على الماك و `Linux` على Linux، وبنختار الأوامر على أساسه. والأجزاء المشتركة مكتوبة بالأدوات اللي شكلها واحد في الاتنين ([↩ 2.6](../ch02/#s2-6 "ليه أوامر من النت مبتشتغلش على الماك؟ BSD ضد GNU")).
3. <strong>bash 3.2:</strong> مفيش `declare -A` ولا `mapfile` ولا `${var,,}`، والـ Array الفاضية محمية من `set -u` ([↩ 3.4](../ch03/#s3-4 "ليه الماك ساب bash وراح لـ zsh؟")).
4. <strong>الأمان:</strong> `set -euo pipefail` و Quotes و `${var:?}` ([↩ 12.7](../ch12/#s12-7 "الوضع الصارم: set -euo pipefail و trap")).
5. <strong>الرسايل:</strong> دالة `log` بتكتب على stderr، والنتايج على stdout عشان ينفع تعمل لها Pipe ([↩ 7.1](../ch07/#s7-1 "الـ Streams التلاتة")).
6. <strong>الإعدادات:</strong> من متغيرات بيئة بقيم افتراضية `${OPSKIT_DEST:-...}` ([↩ 13.4](../ch13/#s13-4 "متغيرات البيئة و export")).
7. <strong>التثبيت:</strong> في `~/.local/bin` اللي ضفناه للـ PATH في `~/.zprofile` ([↩ 13.5](../ch13/#s13-5 "الـ PATH: ضيف مجلد صح")).

## 16.2 الكود كامل

ده الكود كله، حوالي 100 سطر. متخافش من طوله: اقراه دالة دالة، وهتلاقي كل سطر فيه حاجة إنت عارفها. وبعده هنشرّح أصعب السطور.

```sh title="~/.local/bin/opskit (الجزء 1)"
#!/usr/bin/env bash
# opskit: health / logs / backup / deploy  (macOS first, Linux too, bash 3.2+)
set -euo pipefail

VERSION="1.0"
DEST="${OPSKIT_DEST:-$HOME/backups}"
KEEP="${OPSKIT_KEEP:-7}"
REMOTE="${OPSKIT_REMOTE:-prod:/var/www/site/}"
OS="$(uname -s)"                       # Darwin = macOS, Linux = Linux

log()  { printf '\033[1;34m[opskit]\033[0m %s\n' "$*" >&2; }
die()  { printf '\033[1;31m[error]\033[0m %s\n' "$*" >&2; exit 1; }
need() { command -v "$1" >/dev/null || die "missing: $1"; }

usage() {
    cat <<USAGE
opskit $VERSION
usage: opskit <command> [args]
  health            system report
  logs FILE         analyze an access log
  backup DIR        archive DIR into $DEST (keep $KEEP)
  deploy [-n] DIR   rsync DIR to $REMOTE (-n = dry run)
USAGE
}

mem_mac() {
    local total; total=$(sysctl -n hw.memsize)
    vm_stat | awk -v total="$total" '
        /page size of/          { ps = $8 }
        /Pages active/          { a = $3 }
        /Pages wired down/      { w = $4 }
        /occupied by compressor/{ c = $5 }
        END { used = (a + w + c) * ps
              printf "used %.1fG of %.1fG\n", used/2^30, total/2^30 }'
}

cmd_health() {
    echo "== $(hostname) · $(date '+%F %T') · $OS"
    if [[ "$OS" == Darwin ]]; then
        local load; load=$(sysctl -n vm.loadavg | awk '{print $2, $3, $4}')
        echo "-- load:   $load (cores: $(sysctl -n hw.ncpu))"
        echo "-- memory: $(mem_mac)"
        echo "-- disk:";  df -h -l \
            | { IFS= read -r hdr; echo "$hdr"; sort -k5 -rn; } | head -6
        echo "-- top cpu:"; ps -Ao pid,user,%cpu,%mem,comm -r | head -6
        echo "-- listening:"
        lsof -nP -iTCP -sTCP:LISTEN 2>/dev/null | awk 'NR > 1 {print $1, $9}' | sort -u
    else
        echo "-- load:   $(cut -d' ' -f1-3 /proc/loadavg) (cores: $(nproc))"
        echo "-- memory:"; free -h | awk 'NR<=2'
        echo "-- disk:";   df -h -x tmpfs -x devtmpfs \
            | { IFS= read -r hdr; echo "$hdr"; sort -k5 -rn; } | head -6
        echo "-- top cpu:"; ps -eo pid,user,%cpu,%mem,comm --sort=-%cpu | head -6
        echo "-- listening:"
        ss -tlnH | awk '{print $4}' | sort -u
    fi
}
```

```sh title="~/.local/bin/opskit (الجزء 2)"
cmd_logs() {
    local f="${1:?usage: opskit logs FILE}"
    [[ -r "$f" ]] || die "cannot read: $f"
    echo "== requests: $(wc -l < "$f" | tr -d ' ')"
    echo "-- top IPs:"
    awk '{print $1}' "$f" | sort | uniq -c | sort -rn | head -5
    echo "-- status codes:"
    awk '{print $9}' "$f" | sort | uniq -c | sort -rn
    echo "-- top 404:"
    awk '$9 == 404 {print $7}' "$f" | sort | uniq -c | sort -rn | head -5
}

cmd_backup() {
    local src="${1:?usage: opskit backup DIR}"
    [[ -d "$src" ]] || die "not a directory: $src"
    need tar
    mkdir -p -- "$DEST"
    local base; base="$(basename "$src")"
    local name; name="${base}_$(date +%F_%H%M%S).tar.gz"
    COPYFILE_DISABLE=1 tar -czf "$DEST/$name" --exclude='.DS_Store' \
        -C "$(dirname "$src")" "$base"
    log "saved $DEST/$name ($(du -h "$DEST/$name" | cut -f1))"
    # names are generated by us (no newlines), so ls -t is safe here
    # shellcheck disable=SC2012
    ls -1t "$DEST"/"$base"_*.tar.gz | tail -n +$((KEEP + 1)) \
        | while IFS= read -r old; do rm -v -- "$old"; done
}

cmd_deploy() {
    local dry=()
    [[ "${1:-}" == "-n" ]] && { dry=(--dry-run); shift; }
    local src="${1:?usage: opskit deploy [-n] DIR}"
    need rsync
    log "deploying ${src%/}/ -> $REMOTE ${dry[*]:-}"
    rsync -az --delete --exclude='.git' --exclude='.DS_Store' \
        ${dry[@]+"${dry[@]}"} "${src%/}/" "$REMOTE"
}

case "${1:-}" in
    health) shift; cmd_health "$@" ;;
    logs)   shift; cmd_logs "$@" ;;
    backup) shift; cmd_backup "$@" ;;
    deploy) shift; cmd_deploy "$@" ;;
    -v|--version) echo "$VERSION" ;;
    ""|-h|--help) usage ;;
    *) usage >&2; exit 2 ;;
esac
```

:::note[اتجرّب فين؟]
الكود ده اتجرّب على Linux بـ bash 5.2 وكمان بـ bash 3.2.57 (نفس نسخة الماك) عشان نتأكد إنه مفيهوش أي ميزة أحدث، وعدّى من `shellcheck` من غير ولا تحذير. والجزء الخاص بالماك في `health` اتجرّب بنسخ "تمثيلية" من `sysctl` و `vm_stat` و `lsof` بنفس شكل ناتجهم على الماك، مش على ماك حقيقي. فلو شغلته على الماك بتاعك ولقيت رقم شكله غريب، ده تمرين ممتاز: قارن بـ Activity Monitor وصلّحه.
:::

## 16.3 تشريح أصعب السطور

أغلب الكود واضح لو مشيت معاه. بس فيه 4 سطور كل واحد فيهم بيلخّص فصل كامل، فخلينا نفتحهم:

**تشريح الأمر**

```sh
case "$(uname -s)" in Darwin) ... ;; *) ... ;; esac
```

1. `uname -s`: اسم الـ Kernel: `Darwin` (الماك، [↩ 2.6](../ch02/#s2-6 "ليه أوامر من النت مبتشتغلش على الماك؟ BSD ضد GNU")) أو `Linux`. في الكود حفظناه في `OS` مرة واحدة فوق، وبنسأل عليه بـ `[[ "$OS" == Darwin ]]`.
2. `Darwin)`: فرع الماك: `sysctl -n hw.ncpu` بدل `nproc`، و `vm.loadavg` بدل `/proc/loadavg` (الماك معندوش `/proc`، [↩ 4.2](../ch04/#s4-2 "خريطة المجلدات على الماك"))، و `lsof` بدل `ss` ([↩ 10.9](../ch10/#s10-9 "البورتات و lsof"))، و `ps -A ... -r` بدل `--sort` ([↩ 9.1](../ch09/#s9-1 "ps: صورة للعمليات دلوقتي")).
3. `*)`: أي حاجة تانية = Linux.

**تشريح الأمر**

```sh
vm_stat | awk -v total="$total" '/page size of/ { ps = $8 } ... END { printf ... }'
```

1. `vm_stat`: أداة الماك اللي بتعرض الذاكرة بعدد "الصفحات" (Pages)، مش بالجيجا. وأول سطر فيها: `(page size of 16384 bytes)` على Apple Silicon.
2. `-v total="$total"`: ابعت متغير من bash لجوه awk (الرامات الكلية بالبايت من `sysctl -n hw.memsize`).
3. `/page size of/ { ps = $8 }`: لما تلاقي السطر ده، خد الكلمة التامنة (الرقم) ([↩ 8.3](../ch08/#s8-3 "awk: لغة الأعمدة")). وبنفس الطريقة بناخد Pages active و wired و occupied by compressor. والـ awk بيتجاهل النقطة اللي في آخر كل رقم لوحده لما يحوّله لرقم.
4. `END { ... }`: بعد ما السطور تخلص: المستخدم = (active + wired + compressed) × حجم الصفحة، وقسّمه على `2^30` عشان يبقى جيجا. ده تقريب قريب من رقم "Memory Used" في Activity Monitor.

**تشريح الأمر**

```sh
ls -1t "$DEST"/"$base"_*.tar.gz | tail -n +$((KEEP + 1)) | while IFS= read -r old; do rm -v -- "$old"; done
```

1. `ls -1t "$DEST"/"$base"_*.tar.gz`: أرشيفات المجلد ده بس، واحد في كل سطر (`-1`)، الأحدث الأول (`-t`). الـ Glob بره الـ Quotes عشان يتوسع، والمتغيرات جوه الـ Quotes عشان المسافات ([↩ 7.4](../ch07/#s7-4 "الـ Globbing: النجمة وأخواتها")).
2. `| tail -n +$((KEEP + 1))`: من السطر رقم KEEP+1 للآخر = كل حاجة بعد أحدث 7 ([↩ 5.5](../ch05/#s5-5 "قراية الملفات: cat و less و head و tail")).
3. `| while IFS= read -r old`: اقرا كل اسم كامل، حتى لو فيه مسافات ([↩ 12.4](../ch12/#s12-4 "اللوبات: for و while")).
4. `do rm -v -- "$old"; done`: امسحه واطبع اسمه، و `--` نهاية الـ Options. ولو مفيش ولا ملف قديم، اللوب مبيلفّش ولا مرة. ليه مش `xargs -r rm`؟ لأن `-r` مش مضمونة على الماك ([↩ 8.9](../ch08/#s8-9 "xargs: من سطور لـ Arguments")).

:::note[على Linux بس: find -printf]
لو الأداة هتشتغل على Linux بس، فيه طريقة أقوى مع الأسامي الغريبة:

```sh title="Terminal"
find "$DEST" -maxdepth 1 -name "x_*.tar.gz" -printf '%T@ %p\n' \
  | sort -rn | tail -n +8 | cut -d' ' -f2- | xargs -r rm -v --
```

الـ `-printf '%T@ %p\n'` بتطبع وقت التعديل كرقم ثواني ثم المسار، و `cut -d' ' -f2-` بتشيل الرقم. بس `-printf` ميزة GNU find ومش موجودة في find بتاع الماك (المقابل هناك `stat -f '%m %N'`)، وعشان كده opskit استخدم `ls -t`.
:::

**تشريح الأمر**

```sh
rsync -az --delete --exclude='.git' ${dry[@]+"${dry[@]}"} "${src%/}/" "$REMOTE"
```

1. `rsync -az`: Archive + ضغط ([↩ 10.7](../ch10/#s10-7 "rsync: المزامنة الذكية")). شغال مع openrsync بتاع الماك، ومع rsync الأصلي من brew أو على Linux.
2. `--delete`: مرآة: امسح من السيرفر اللي اتمسح عندك.
3. `--exclude='.git'`: متنشرش مجلد git (ولا `.DS_Store`، [↩ 4.3](../ch04/#s4-3 "المسارات: المطلق والنسبي")).
4. `${dry[@]+"${dry[@]}"}`: Array: يا فاضية (ولا Argument خالص) يا فيها `--dry-run`. الشكل الغريب ده عشان bash 3.2: `"${dry[@]}"` لوحدها مع `set -u` وهي فاضية بتوقع الـ Script بـ `unbound variable`. و `${x+y}` معناها "لو x متعرّفة حط y" ([↩ 12.2](../ch12/#s12-2 "المتغيرات والحساب")). ولو استخدمنا متغير نصي فاضي `"$dry"` كان هيبقى Argument فاضي `''` و rsync يشتكي.
5. `"${src%/}/"`: شيل أي `/` في الآخر وحط واحدة: نضمن "المحتويات" مهما المستخدم كتب.
6. `"$REMOTE"`: الوجهة من الإعدادات (`prod` من ssh config، [↩ 10.5](../ch10/#s10-5 "ملف ~/.ssh/config: اختصر كل ده")).

## 16.4 التثبيت والتشغيل اليومي

الأداة جاهزة. خلينا نحطها في مكانها ونخليها جزء من يومك:

```sh title="Terminal"
$ mkdir -p ~/.local/bin
$ code ~/.local/bin/opskit          # paste the code, save
$ chmod +x ~/.local/bin/opskit
$ brew install shellcheck && shellcheck ~/.local/bin/opskit
$ opskit health
$ opskit logs /opt/homebrew/var/log/nginx/access.log | tee report.txt
$ opskit deploy -n ./site           # dry run first
$ opskit deploy ./site
```

```sh title="~/.zshrc"
export OPSKIT_DEST="$HOME/backups" OPSKIT_KEEP=10
alias ok='opskit'
_opskit() { compadd health logs backup deploy --help --version; }
compdef _opskit opskit
```

`compadd` و `compdef` من نظام الـ Completion بتاع zsh: "لما تضغط Tab بعد opskit، اقترح الكلمات دي" ([↩ 14.5](../ch14/#s14-5 "الـ Tab Completion")). لازم ييجوا بعد سطر `compinit` في الملف. والـ Alias من [↩ 13.2](../ch13/#s13-2 "الـ Aliases: اختصارات"). (وفي bash: `complete -W "health logs backup deploy --help --version" opskit`).

وعشان الـ Backup يشتغل لوحده كل يوم الساعة 2:30 الفجر، LaunchAgent ([↩ 9.5](../ch09/#s9-5 "الخدمات على الماك: launchd و launchctl و brew services")):

```text title="~/Library/LaunchAgents/com.ahmed.opskit.backup.plist"
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>  <string>com.ahmed.opskit.backup</string>
  <key>ProgramArguments</key>
  <array>
    <string>/Users/ahmed/.local/bin/opskit</string>
    <string>backup</string>
    <string>/Users/ahmed/projects</string>
  </array>
  <key>EnvironmentVariables</key>
  <dict>
    <key>PATH</key>  <string>/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin</string>
    <key>OPSKIT_KEEP</key> <string>10</string>
  </dict>
  <key>StartCalendarInterval</key>
  <dict><key>Hour</key><integer>2</integer><key>Minute</key><integer>30</integer></dict>
  <key>StandardErrorPath</key> <string>/Users/ahmed/opskit.log</string>
</dict>
</plist>
```

```sh title="Terminal"
$ plutil -lint ~/Library/LaunchAgents/com.ahmed.opskit.backup.plist
/Users/ahmed/Library/LaunchAgents/com.ahmed.opskit.backup.plist: OK
$ launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.ahmed.opskit.backup.plist
$ launchctl kickstart gui/$(id -u)/com.ahmed.opskit.backup    # test it now
$ tail ~/opskit.log
```

لاحظ الـ `PATH` جوه الـ plist: launchd مش بيقرا `~/.zprofile`، فمن غيره opskit مش هيلاقي أدوات brew. واللوج في `StandardErrorPath` لأن `log` بتاعتنا بتكتب على stderr. ولو الماك كان نايم الساعة 2:30، launchd هيشغّلها أول ما يصحى. وعايز تقرير صحة كل يوم اتنين؟ نفس الملف باسم تاني، و `health` بدل `backup`، و `<key>Weekday</key><integer>1</integer>` في الـ `StartCalendarInterval`.

:::note[على السيرفر: cron و tmux]
```text title="crontab -e"
30 2 * * * $HOME/.local/bin/opskit backup $HOME/docs >> $HOME/opskit.log 2>&1
0  8 * * 1 $HOME/.local/bin/opskit health > $HOME/health-weekly.txt 2>&1
```

Backup كل يوم 2:30 الفجر، وتقرير صحة كل يوم اتنين الساعة 8. و cron بيفهم `$HOME` لأنه بيشغّل السطر بـ sh ([↩ 12.8](../ch12/#s12-8 "Scripts عملية كاملة")). ولو شغّال على سيرفر بعيد، افتح `tmux new -s ops` وشغّل `watch -n 60 opskit health` في Pane، و `tail -f` على اللوج في Pane تاني ([↩ 14.6](../ch14/#s14-6 "tmux: شغلك ميضيعش")). (و `watch` مش جاي مع الماك: `brew install watch`).
:::

:::tip[كل الكتاب في أداة واحدة]
اتفرج: `|` و `>>` و `2>&1` (الفصل 7)، و awk و sort و uniq و ls و while (الفصلين 8 و 12)، و ps و lsof و launchd (الفصل 9)، و tar و rsync و ssh (الفصل 10)، و brew و shellcheck (الفصل 11)، و set و case والدوال والـ Arrays و bash 3.2 (الفصل 12)، و PATH و alias و export و zsh completion (الفصلين 13 و 14)، و `--` والـ Dry run والـ Quotes (الفصل 15)، والفروق بين BSD و GNU (الفصل 2). مفيش سطر مش فاهمه.
:::

## 16.5 طوّرها بنفسك

1. ضيف `opskit clean` يمسح ملفات `/tmp` بتاعتك الأقدم من 7 أيام (مع `-n` للتجربة).
2. خلي `health` يطلع Exit code 1 لو أي قرص أكتر من 90%، عشان تستخدمه في المراقبة.
3. ضيف خيار `--json` لـ `logs` يطلع النتيجة JSON (تلميح: `awk` أو `jq` من brew).
4. ابعت لنفسك تنبيه لو `health` فشل: على الماك Notification بـ `osascript` أو `say` ([↩ 14.3](../ch14/#s14-3 "أدوات الماك اللي مش في أي حتة تانية"))، وعلى السيرفر curl لـ Webhook ([↩ 10.2](../ch10/#s10-2 "curl و wget: كلّم السيرفرات")).
5. ضيف `opskit battery` للماك بس، بيستخدم `pmset -g batt`، ويطبع رسالة واضحة لو اتشغّل على Linux.

:::tip[ملخص الفصل]
- Script واحد بـ Subcommands عن طريق `case` ودوال، ونظامين بـ `uname -s`.
- stdout للنتايج و stderr للرسايل، والإعدادات من متغيرات بيئة بقيم افتراضية.
- اكتب لـ bash 3.2: `${arr[@]+"${arr[@]}"}` مع `set -u`، ومفيش `xargs -r` ولا `find -printf` على الماك.
- Arrays لـ Arguments اختيارية، و `--` قبل الأسماء، و Dry run قبل أي مسح أو نشر.
- التثبيت في `~/.local/bin` + alias + compdef + LaunchAgent (أو cron على السيرفر).
:::

### صح ولا غلط؟

1. رسايل `log` في opskit بتظهر في `report.txt` لما تعمل `| tee report.txt`.
2. `${dry[@]+"${dry[@]}"}` وهي فاضية مبتضيفش أي Argument.
3. الـ LaunchAgent بيقرا `~/.zprofile` فبيلاقي `/opt/homebrew/bin` في الـ PATH لوحده.

### أسئلة مراجعة

1. ليه `log` و `die` بيكتبوا على stderr؟
2. اشرح الـ Pipeline بتاع مسح الـ Backups القديمة خطوة خطوة، وليه مستخدمناش `find -printf`.
3. ليه بنستخدم Array لـ `dry` بدل متغير عادي؟ وليه الشكل `${dry[@]+...}`؟
4. إزاي opskit بيعرف هو شغال على الماك ولا Linux، وإيه الأوامر اللي بتختلف؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** سطّب opskit وشغّل `opskit health` و `opskit --version`، وقارن رقم الرامات بـ Activity Monitor.
2. **[متوسط]** ضيف `opskit clean` بالمواصفات اللي في "طوّرها بنفسك" (تلميح: `find /tmp -user "$USER" -mtime +7`).
3. **[صعب]** خلّي `health` يرجع Exit code 1 لو أي قرص فوق 90%، واعمل LaunchAgent بيشغّله كل ساعة ويعمل Notification بس لما يفشل (تلميح: `||` و `osascript`).
