<small>المرحلة 3 · تتكلم مع API</small>

عرفت curl في كتاب الإنترنت كأداة تشوف بيها HTTP. هنا هنستخدمه كأداة شغل مع الـ APIs: تبعت JSON صح، وتضيف Auth، وتركّب Query parameters بأمان، وتفشل بصوت عالي. وبعدين HTTPie اللي معمول للـ APIs مخصوص، وبرامج زي Bruno و Postman و Insomnia، وإزاي تاخد أي طلب من تابة Network وتعيده في الـ Terminal.

:::note[بعد الفصل ده هتكون عارف]
- curl: -X و -H و -d و --json و -G و --data-urlencode و -u و -f و -w
- الغلطة الأشهر: -d من غير Content-Type
- HTTPie: = و := و == و : و -a و --offline
- Bruno و Postman و Insomnia: الفرق وإمتى كل واحد
- تابة Network: فلتر Fetch/XHR و Copy as cURL و Copy as fetch
- جدول يختار لك الأداة
:::

## 8.1 curl للـ APIs: الـ Flags اللي هتعيش بيها

في كتاب الإنترنت (فصل 10) استخدمنا curl علشان **نتفرج**: `-v` و `-I` و `-o`. مع الـ APIs هنحتاج **نبعت**: Methods و JSON و Tokens. وأول حاجة لازم تعرفها:

:::danger[مشكلة: السيرفر مش شايف الـ JSON اللي بعته (json: null)]
**العَرَض**: بعت `curl -d '{"a":1}' https://httpbin.org/post` والسيرفر رد كإنه مستلمش حاجة، أو رجّع 400 أو 415.

**السبب**: `-d` لوحدها بتبعت `Content-Type: application/x-www-form-urlencoded` (شكل الـ HTML forms القديم). فالسيرفر بيحاول يقرا الـ Body كـ `a=1&b=2`. وده الرد الحقيقي من httpbin:

```json
{"json":null,"form":{"{\"a\":1}":""},"ct":"application/x-www-form-urlencoded"}
```

الـ JSON كله اتقرا كـ **اسم Field** في Form، وقيمته فاضية!

**الحل**: يا إما `-H 'Content-Type: application/json'` مع `-d`، يا إما الأحسن: `--json`.
:::

```sh title="Terminal"
$ curl -s --json '{"a":1}' -X PUT https://httpbin.org/put | jq -c '{json, ct: .headers["Content-Type"], accept: .headers.Accept}'
{"json":{"a":1},"ct":"application/json","accept":"application/json"}
```

**تشريح الأمر**

```sh
curl -s --json '{"a":1}' -X PUT https://httpbin.org/put
```

1. `--json '…'`: Flag جديد نسبياً (curl 7.82، سنة 2022) بيعمل 3 حاجات مرة واحدة: يبعت الـ Body، ويحط `Content-Type: application/json`، ويحط `Accept: application/json`. وزي `-d`، بيخلي الـ Method `POST` لوحده. وتأكد من نسختك بـ `curl --version`.
2. `-X PUT`: "Request method": غيّر الـ Method. هنا محتاجينها لأن `--json` بيختار `POST`. ومتستخدمش `-X GET` أو `-X POST` من غير داعي: curl بيختارهم لوحده، و`-X` بتغيّر **الكلمة** بس مش السلوك.
3. `httpbin.org/put`: httpbin سيرفر بيرجّعلك اللي بعته بالظبط، فأحسن مكان تتأكد إن الطلب طالع صح (فصل 9).

### باقي الـ Flags، مجمّعة حسب الشغلانة

**curl للـ APIs**

| الشغلانة | الـ Flag | التفاصيل |
|---|---|---|
| Header | `-H 'Name: value'` | تتكرر لكل Header. و`-H 'Name:'` (فاضي) يشيل Header curl بيحطه لوحده. |
| Body من ملف | `--json @body.json` / `-d @body.json` | الـ `@` = "اقرا من الملف ده". و`@-` = من الـ stdin (الـ Pipe). |
| Body زي ما هو | `--data-binary @file` | `-d` بتشيل الـ Newlines من الملفات. `--data-binary` بتبعت البايتات زي ما هي. |
| Query بأمان | `-G --data-urlencode 'q=…'` | `-G` = "حوّل كل `-d` لـ Query string في GET". و`--data-urlencode` بتعمل Percent-encoding صح للمسافات والعربي. |
| Basic auth | `-u user:pass` | بيبني `Authorization: Basic …` لوحده (فصل 12). |
| Bearer token | `-H "Authorization: Bearer $TOKEN"` | أو `--oauth2-bearer "$TOKEN"`. والـ Token من Variable مش مكتوب في الأمر. |
| شوف الـ Headers | `-i` / `-v` | `-i` بيطبع Headers الرد قبل الـ Body. و`-v` الطلب والرد. |
| افشل بصوت عالي | `-f` / `--fail-with-body` | لو الـ Status ≥ 400، الـ Exit code بيبقى **22**. `-f` بتخفي الـ Body، و`--fail-with-body` بتطبعه (أحسن للـ APIs لأن رسالة الغلط جواه). |
| Status بس | `-o /dev/null -w '%{http_code}\n'` | ارمي الـ Body واطبع الـ Status. و`-w` ليه متغيرات كتير (تحت). |
| الـ Redirects | `-L` | امشي ورا 301/302. من غيرها curl بيقف عند الـ Redirect. |
| الهدوء الذكي | `-sS` | اسكت (`-s`) بس اطبع الأخطاء (`-S`). أحسن من `-s` لوحدها في الاسكريبتات. |
| Retries | `--retry 3` | يعيد على أخطاء مؤقتة (منها 429 و 5xx) ويحترم `Retry-After`. |

```sh title="Terminal"
$ curl -s -G https://httpbin.org/get --data-urlencode "q=APIs و JSON" -d limit=2 | jq -c '{args, url}'
{"args":{"limit":"2","q":"APIs و JSON"},"url":"https://httpbin.org/get?q=APIs+و+JSON&limit=2"}
$ curl -s --fail-with-body https://api.github.com/repos/nope-xx/nope; echo " exit=$?"
{
  "message": "Not Found",
  "documentation_url": "https://docs.github.com/rest/repos/repos#get-a-repository",
  "status": "404"
}
 exit=22
$ curl -s -o /dev/null -w 'status=%{http_code} type=%{content_type} time=%{time_total}s size=%{size_download}\n' https://pokeapi.co/api/v2/pokemon/pikachu
status=200 type=application/json; charset=utf-8 time=0.100613s size=309106
```

| الأمر | بيعمل إيه |
|---|---|
| `-G … -d limit=2` | اتنين `-d` (واحد Encoded وواحد عادي) اتلمّوا في الـ Query بـ `&`، والـ Method فضلت GET. |
| `q=APIs+و+JSON` | المسافة بقت `+` (طريقة الـ Forms القديمة)، و httpbin عرضها لنا متفكوكة. والسيرفر هيفكها لـ "APIs و JSON". |
| `echo " exit=$?"` | الـ Exit code 22 = "HTTP error". ده اللي بيخلّي `curl -f … && echo ok` يقف لو الـ API رجّع غلط. |
| `%{http_code} %{content_type} %{time_total} %{size_download}` | متغيرات `-w`: الـ Status، والـ Content-Type، والوقت الكلي بالثواني، والحجم بالبايت. وفي كمان `%{time_namelookup}` و`%{time_connect}` و`%{time_appconnect}` (TLS) و`%{time_starttransfer}` (أول بايت) لو بتقيس السرعة. |

:::tip[Best Practice: الـ Token من Variable]
`export GITHUB_TOKEN=…` مرة في الجلسة، وبعدين `curl -H "Authorization: Bearer $GITHUB_TOKEN" …` بـ <strong>"</strong> مش <strong>'</strong> (علشان الـ `$` يتفك). كده الـ Token مش مكتوب في الأمر، وميظهرش لو عملت Copy للأمر لحد. وخلّي بالك إن `-v` بيطبع الـ `Authorization` header، فمتلزقش ناتج `-v` في Slack.
:::

## 8.2 HTTPie: curl بس معمول للـ APIs

curl عام لكل البروتوكولات، فكتابة JSON فيه متعبة. **HTTPie** اتعمل مخصوص للـ APIs: JSON افتراضي، والرد ملوّن ومنسّق، والصيغة قريبة من الكلام. تسطّبه بـ `brew install httpie` (3.2.4 في أكتوبر 2026)، والأمر اسمه `http` (و`https`).

```sh title="Terminal"
$ http --offline POST api.example.com/v1/articles title="Hello" views:=10 tags:='["api","json"]' status=draft Authorization:"Bearer abc123" lang==ar
POST /v1/articles?lang=ar HTTP/1.1
Accept-Encoding: gzip, deflate
Connection: keep-alive
Content-Length: 75
User-Agent: HTTPie/3.2.4
Accept: application/json, */*;q=0.5
Content-Type: application/json
Authorization: Bearer abc123
Host: api.example.com

{"title": "Hello", "views": 10, "tags": ["api", "json"], "status": "draft"}
```

**تشريح الأمر**

```sh
http --offline POST api.example.com/v1/articles title="Hello" views:=10 tags:='["api","json"]' Authorization:"Bearer abc123" lang==ar
```

1. `--offline`: "متبعتش، اطبعلي الطلب اللي كنت هتبعته". أحسن طريقة تتعلم بيها HTTPie وتتأكد من الطلب قبل ما يروح لـ API حقيقي.
2. `POST`: الـ Method في الأول. ولو مكتبتهاش: GET، أو POST لو فيه Body.
3. `api.example.com/…`: من غير `https://`: الأمر `http` بيفترض `http://`، و`https` بيفترض `https://`. فمع APIs حقيقية اكتب `https api.github.com/…` أو الـ URL كامل.
4. `title="Hello"`: الـ `=` = Field في الـ JSON قيمته **String**.
5. `views:=10`: الـ `:=` = Field قيمته **JSON خام**: رقم أو Boolean أو Array أو Object. فـ `10` طلعت رقم مش `"10"`.
6. `tags:='[…]'`: Array كاملة كـ JSON. وبين `'…'` علشان الـ Shell.
7. `Authorization:"Bearer …"`: الـ `:` لوحدها = **Header**.
8. `lang==ar`: الـ `==` = **Query parameter**. وطلع في سطر الطلب: `?lang=ar`.

**رموز HTTPie**

| الرمز | بيعمل | مثال |
|---|---|---|
| `:` | Header | `X-Trace:abc` |
| `==` | Query parameter | `limit==2` |
| `=` | JSON field (String) | `title=Hello` |
| `:=` | JSON field (خام) | `done:=true` |
| `@` | ملف (مع `--form`) | `file@photo.jpg` |
| `-a user:pass` | Basic auth | بيبني `Authorization: Basic dXNlcjpwYXNz` |
| `-A bearer -a TOKEN` | Bearer auth | بيبني `Authorization: Bearer TOKEN` |
| `--print=HhBb` | اطبع إيه | H/B = Headers/Body الطلب، h/b = بتوع الرد |
| `--form` | Form بدل JSON | `application/x-www-form-urlencoded` |

:::caution[خلي بالك: HTTPie في الاسكريبتات]
لو شغّلت `http` جوه اسكريبت أو Cron (مفيش Terminal)، ممكن يقع بـ <em>"Request body (from stdin…) and request data (key=value) cannot be mixed"</em>، لأنه بيفتكر إن في Body جاي من الـ stdin. الحل `--ignore-stdin`. (حصلت معانا بالظبط وإحنا بنجرّب للكتاب.)
:::

**المصادر الرسمية:** [HTTPie CLI docs](https://httpie.io/docs/cli) · [HTTPie · Request items](https://httpie.io/docs/cli/request-items) · [formulae.brew.sh · httpie](https://formulae.brew.sh/formula/httpie)

## 8.3 البرامج بالواجهة: Bruno و Postman و Insomnia

لما يبقى عندك 30 طلب لنفس الـ API، ومتغيرات زي `baseUrl` و `token`، وعايز تحفظهم وتشاركهم، الـ Terminal بيتعب. البرامج دي بتدّيك **Collections** (طلبات محفوظة في فولدرات)، و**Environments** (نفس الطلبات على local و production)، وتعرض الرد حلو، وتكتب Tests صغيرة.

**التلاتة جنب بعض (أكتوبر 2026)**

|   | Bruno | Postman | Insomnia |
|---|---|---|---|
| Homebrew | `brew install --cask bruno` (4.3.0) | `brew install --cask postman` (12.33) | `brew install --cask insomnia` (13.3) |
| فين بيتحفظ | **ملفات نص في فولدر عندك** (صيغة YAML / Bru)، تعملها Commit في Git مع الكود | في حسابك على السحابة أساساً | Local أو Cloud أو Git |
| محتاج حساب؟ | لأ | أيوه للمزايا الأساسية | اختياري |
| المجاني | Open source، والأساسي كله مجاني | خطة Free: **مستخدم واحد** | في خطة مجانية |
| OpenAPI | Import و Export | Import ومحرر Specs | Import ومحرر Specs |
| هتقابله فين | فرق صغيرة بتحب Git | **الأشهر** في الشركات والكورسات | ناس بتحبه أخف |

:::note[هتختار إيه؟]
كورس Maximilian (زي أغلب الكورسات) غالباً هيستخدم Postman، فاعرف شكله. بس لشغلك الشخصي جرّب **Bruno**: الـ Collection بيبقى فولدر جوه الـ Repo بتاع الـ API نفسه، فأي حد يعمل Clone يلاقي الطلبات جاهزة. والفكرة في التلاتة واحدة: Method و URL و Headers و Body و Auth، يعني اللي في الكتاب ده كله.
:::

## 8.4 تابة Network: تصطاد الطلب وتعيده

كل موقع حديث بيكلم API بـ `fetch`. يعني أي موقع بتستخدمه هو "دوكيومنتيشن حي" للـ API بتاعه. وتابة Network اتشرحت في كتاب الإنترنت (فصول 18 و 19)، فهنا الحاجات الخاصة بالـ APIs بس:

1. **فلتر Fetch/XHR**: من الشريط اللي فوق، علشان يختفي كل الـ CSS والصور ويفضل طلبات الـ API بس.
2. اضغط على أي طلب: **Headers** (الـ Method والـ Status والـ Headers)، و**Payload** (الـ Query string والـ Body اللي اتبعت)، و**Preview** (الـ JSON كشجرة تفتحها وتقفلها)، و**Response** (النص الخام).
3. كليك يمين على الطلب ← **Copy** ← **Copy as cURL**: الطلب كله بكل الـ Headers والـ Cookies جاهز تلزقه في الـ Terminal. ومنه تشيل الـ Headers اللي مش محتاجها لحد ما توصل لأقل طلب شغال.
4. أو **Copy as fetch** (أو <strong>Copy as fetch (Node.js)</strong>): نفس الطلب كـ كود JS تلزقه في الـ Console أو في ملف.
5. من نفس القايمة **Replay XHR**: يعيد الطلب زي ما هو، مفيد وانت بتعدّل في السيرفر.

:::caution[خلي بالك: Copy as cURL فيه أسرارك]
الطلب المنسوخ فيه الـ Cookies بتاعة الـ Session و الـ `Authorization` header. يعني أي حد معاه الأمر ده يقدر يتصرف كأنه انت لحد ما الـ Session تخلص. متلزقهوش في Issue ولا شات، وامسح الـ Headers الحساسة قبل ما تشاركه.
:::

:::note[Safari]
في Safari، تابة Network في Web Inspector، وكليك يمين على الطلب فيها **Copy as cURL** برضه (كتاب الإنترنت فصل 21). بس فلاتر Chrome وتابة Payload أوضح للشغل ده.
:::

**المصادر الرسمية:** [Chrome DevTools · Network features reference](https://developer.chrome.com/docs/devtools/network/reference)

## 8.5 تختار أنهي أداة؟

**الأداة حسب الموقف**

| الموقف | الأداة |
|---|---|
| طلب سريع، أو جوه اسكريبت Shell، أو في Docs رسمية | **curl** (موجود في كل حتة) |
| بتجرّب API بإيدك وعايز JSON سهل ورد ملوّن | **HTTPie** |
| Collection كاملة ومتغيرات وتشاركها مع فريق | **Bruno** / Postman / Insomnia |
| عايز تعرف الموقع ده بيكلم إيه | **تابة Network** + Copy as cURL |
| هتكرر الطلب ده كتير في كود | `fetch` (فصل 10) أو Python `requests` |

:::tip[ملخص الفصل]
- `-d` لوحدها = Form مش JSON. استخدم `--json` (Body + Content-Type + Accept + POST).
- `-X` للـ Method، و`-H` للـ Headers، و`@file` و`@-` للـ Body من ملف أو Pipe.
- `-G --data-urlencode` لـ Query آمن، و`--fail-with-body` Exit 22 مع رسالة الغلط، و`-w` للـ Status والوقت.
- HTTPie: `:` Header، و`==` Query، و`=` String، و`:=` JSON خام، و`--offline` تشوف قبل ما تبعت.
- Bruno ملفات في Git، و Postman الأشهر (Free لمستخدم واحد)، و Insomnia الأخف.
- Network: فلتر Fetch/XHR، و Copy as cURL / fetch، وخلي بالك من الأسرار.
:::

### صح ولا غلط؟

1. `curl -d '{"a":1}' URL` بيبعت `Content-Type: application/json`.
2. في HTTPie، `count=5` بيبعت `5` كرقم.
3. `-f` في curl بتخلي الـ Exit code 22 لو الـ Status 404.

### أسئلة مراجعة

1. اكتب نفس الطلب (POST بـ JSON فيه `title` و`userId` رقم) بـ curl وبـ HTTPie.
2. إيه الفرق بين `-f` و `--fail-with-body`؟ وليه التانية أحسن مع APIs؟
3. ليه `-G --data-urlencode` أحسن من إنك تكتب `?q=…` في الـ URL بإيدك؟
4. إيه الخطر في مشاركة ناتج Copy as cURL؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** سطّب HTTPie وابعت `https httpbin.org/post title=Hi done:=false` وقارن الرد بنفس الطلب بـ curl.
2. **[متوسط]** افتح أي موقع بتستخدمه (مثلاً GitHub وانت عامل Login)، وفلتر Fetch/XHR، واختار طلب، واعمله Copy as cURL، وشيل Headers لحد ما توصل لأقل طلب شغال.
3. **[صعب]** سطّب Bruno، واعمل Collection فيها 3 طلبات لـ JSONPlaceholder (GET و POST و DELETE) بمتغير `baseUrl`، وبص على الملفات اللي اتعملت في الفولدر.
