<small>المرحلة 3 · تتكلم مع API</small>

أحسن طريقة تفهم بيها الـ APIs إنك تكلّم كتير منها وتقارن. كل API في الفصل ده اتبعتله طلب حقيقي يوم 23 أكتوبر 2026 ورد. هنعرف كل واحد بيعلّمك إيه بالظبط: CRUD وهمي، أو Pagination، أو Auth، أو أخطاء، أو GraphQL، وهنشوف بعين المصمّم إيه اللي حلو فيهم وإيه اللي وحش.

:::note[بعد الفصل ده هتكون عارف]
- جدول بـ 15 API مجاني: محتاج Key ولا لأ، وحدوده، وبيعلّمك إيه
- APIs الـ Echo: httpbin و Postman Echo علشان تشوف طلبك
- JSONPlaceholder و DummyJSON: تجرّب POST و PUT و DELETE من غير ما تبوّظ حاجة
- PokeAPI و Rick and Morty: Pagination بطريقتين
- Open-Meteo و Frankfurter: Query parameters وأخطاء 400 مفيدة
- NASA: API key وإيه اللي بيحصل من غيره
- درس حقيقي: REST Countries قفلت نسخة قديمة
:::

<a id="s9-1"></a>

## 9.1 الجدول الكبير

كل اللي في الجدول اتجرّب بـ `curl` ورجّع رد صح يوم 23 أكتوبر 2026. والـ APIs العامة ممكن تتغير أو تقفل (زي ما هتشوف في آخر الفصل)، فلو حاجة وقفت، ارجع للـ Docs بتاعتها.

**APIs للتمرين**

| الـ API | Key؟ | بيعلّمك إيه | جرّب |
|---|---|---|---|
| httpbin | لأ | Echo: بيرجّعلك طلبك. Auth و Status codes على الطلب | `httpbin.org/anything` |
| Postman Echo | لأ | Echo تاني | `postman-echo.com/get?x=1` |
| JSONPlaceholder | لأ | CRUD وهمي: posts و users و todos و comments | `jsonplaceholder.typicode.com/posts/1` |
| DummyJSON | لأ | Login بـ JWT، وبحث، و `limit`/`skip`، و `select`، وترتيب | `dummyjson.com/products?limit=2` |
| GitHub REST | اختياري (60/ساعة من غيره) | API حقيقي بكل حاجة: Versioning و Link pagination و Rate limit headers | `api.github.com/users/octocat` |
| PokeAPI | لأ (GET بس) | بيانات متداخلة كبيرة، و Pagination بـ `offset`/`limit` | `pokeapi.co/api/v2/pokemon/pikachu` |
| Rick and Morty | لأ | Pagination بـ `page`، وفلترة، و 404 بـ JSON | `rickandmortyapi.com/api/character?page=2` |
| Open-Meteo | لأ (غير تجاري: أقل من 10,000 طلب في اليوم) | Query parameters كتير، ووحدات، وأخطاء 400 واضحة | `api.open-meteo.com/v1/forecast?…` |
| Frankfurter | لأ | أسعار العملات، و v1 جنب v2 | `api.frankfurter.dev/v2/rates?base=USD` |
| Countries (GraphQL) | لأ | GraphQL حقيقي (فصل 2) | `countries.trevorblades.com/graphql` |
| Open Library | لأ | بحث، و `fields` لاختيار الحقول | `openlibrary.org/search.json?q=dune` |
| NASA APOD | **أيوه** (`DEMO_KEY` للتجربة) | API key في الـ Query، وحد صغير | `api.nasa.gov/planetary/apod?api_key=DEMO_KEY` |
| Hacker News | لأ | API على Firebase: IDs وبعدين تجيب كل Item | `hacker-news.firebaseio.com/v0/item/8863.json` |
| Random User | لأ | بيانات وهمية لأشخاص (للـ UI) | `randomuser.me/api/` |
| Dog CEO | لأ | أبسط API ممكن: صورة عشوائية | `dog.ceo/api/breeds/image/random` |

:::note[الـ URLs في الجدول من غير https://]
علشان الجدول يبقى مقروء، شلنا `https://` من الأول. كلهم HTTPS، فاكتبه وانت بتجرّب.
:::

<a id="s9-2"></a>

## 9.2 الـ Echo: شوف طلبك بعين السيرفر

أول ما تتلخبط "أنا بعت إيه بالظبط؟"، ابعت نفس الطلب لـ httpbin. هو بيرجّعلك الـ Headers والـ Query والـ Body زي ما وصلوه:

```sh title="Terminal"
$ curl -s "https://httpbin.org/anything?lang=ar" --json '{"title":"Hi"}' | jq '{method, args, json, ct: .headers["Content-Type"]}'
{
  "method": "POST",
  "args": {
    "lang": "ar"
  },
  "json": {
    "title": "Hi"
  },
  "ct": "application/json"
}
```

| الأمر | بيعمل إيه |
|---|---|
| `/anything` | بيقبل أي Method وأي Path بعدها، ويرجّع كل حاجة. |
| `/status/429` | بيرد بالـ Status اللي تطلبه، علشان تجرّب كودك على الأخطاء من غير ما تستنى API حقيقي يقع. |
| `/basic-auth/user/pass` | بيطلب Basic auth باليوزر والباسورد اللي في المسار (فصل 12). |
| `/bearer` | بيتأكد إن في `Authorization: Bearer …`. |
| `/delay/3` | بيستنى 3 ثواني قبل ما يرد: تجرّب الـ Timeouts (فصل 10). |

**المصادر الرسمية:** [httpbin.org](https://httpbin.org/) · [Postman Echo](https://learning.postman.com/docs/developer/echo-api/)

## 9.3 CRUD وهمي: JSONPlaceholder و DummyJSON

عايز تجرّب `POST` و `PUT` و `DELETE` من غير ما تبوّظ بيانات حد؟ JSONPlaceholder بيرد كإنه نفّذ، بس مبيحفظش حاجة. والدوكيومنتيشن بتاعته بتقولها صراحة: <em>"The resource is not really created on the server, but the response is faked as if"</em>.

```sh title="Terminal"
$ curl -s -i --json '{"title":"Hello","userId":1}' https://jsonplaceholder.typicode.com/posts | grep -iE '^HTTP|^location'
HTTP/2 201
location: https://jsonplaceholder.typicode.com/posts/101
$ curl -s -X DELETE https://jsonplaceholder.typicode.com/posts/1 -w ' %{http_code}\n'
{} 200
$ curl -s https://jsonplaceholder.typicode.com/posts/999 -w ' %{http_code}\n'
{} 404
```

بعين المصمّم: **201** و `Location` بعد الإنشاء = ممتاز (فصل 16). بس الـ <strong>404 بـ Body فاضي `{}`</strong> مش مفيد: مفيش أي رسالة بتقولك إيه اللي مش موجود. قارنه بـ GitHub اللي بيرجّع `message` و `documentation_url`.

و**DummyJSON** أغنى: فيه Login حقيقي بيرجّع JWT (هنفصّصه في فصل 12)، وبحث، وتحكم في الحقول والترتيب:

```sh title="Terminal"
$ curl -s "https://dummyjson.com/products?limit=2&skip=10&select=title,price&sortBy=price&order=desc" | jq -c .
{"products":[{"id":192,"title":"Rolex Datejust Women","price":10999.99},{"id":95,"title":"Rolex Cellini Date Black Dial","price":8999.99}],"total":194,"skip":10,"limit":2}
```

| الأمر | بيعمل إيه |
|---|---|
| `limit=2&skip=10` | Offset pagination: عدّي أول 10 وهات 2 (فصل 18). |
| `select=title,price` | Field selection: هات الحقول دي بس، والـ `id` بييجي دايماً. حل بسيط لـ Over-fetching من غير GraphQL. |
| `sortBy=price&order=desc` | ترتيب. APIs تانية بتكتبها `sort=-price` (فصل 18). |
| `"total": 194` | العدد الكلي، علشان تعرف فاضل كام صفحة. |

**المصادر الرسمية:** [JSONPlaceholder · Guide](https://jsonplaceholder.typicode.com/guide/) · [DummyJSON · Docs](https://dummyjson.com/docs)

## 9.4 Pagination بطريقتين: PokeAPI و Rick and Morty

```sh title="Terminal"
$ curl -s "https://pokeapi.co/api/v2/pokemon?limit=3&offset=6" | jq '{count, next, previous}'
{
  "count": 1351,
  "next": "https://pokeapi.co/api/v2/pokemon?offset=9&limit=3",
  "previous": "https://pokeapi.co/api/v2/pokemon?offset=3&limit=3"
}
$ curl -s "https://rickandmortyapi.com/api/character?page=2" | jq .info
{
  "count": 826,
  "pages": 42,
  "next": "https://rickandmortyapi.com/api/character?page=3",
  "prev": "https://rickandmortyapi.com/api/character?page=1"
}
$ curl -s "https://rickandmortyapi.com/api/character?page=99" -w ' %{http_code}\n'
{"error":"There is nothing here"} 404
```

الاتنين بيدّوك **URL الصفحة الجاية جاهز** في `next`، فمش محتاج تحسب. ودي عادة ممتازة: الـ Client يمشي ورا `next` لحد ما يبقى `null`. والفرق: PokeAPI بالـ `offset` (بتعدّي كام عنصر) و Rick and Morty بالـ `page` (رقم الصفحة)، ووصلنا لـ 404 لما عدّينا آخر صفحة. وكلام كتير عن ده في فصل 18.

**المصادر الرسمية:** [PokeAPI · Docs v2](https://pokeapi.co/docs/v2) · [Rick and Morty API · Docs](https://rickandmortyapi.com/documentation)

## 9.5 Query parameters وأخطاء مفيدة: Open-Meteo

```sh title="Terminal"
$ curl -s "https://api.open-meteo.com/v1/forecast?latitude=30.04&longitude=31.24&current=temperature_2m,wind_speed_10m&timezone=Africa%2FCairo" | jq '{timezone, current_units, current}'
{
  "timezone": "Africa/Cairo",
  "current_units": {
    "time": "iso8601",
    "interval": "seconds",
    "temperature_2m": "°C",
    "wind_speed_10m": "km/h"
  },
  "current": {
    "time": "2026-10-23T14:30",
    "interval": 900,
    "temperature_2m": 29.9,
    "wind_speed_10m": 11.9
  }
}
$ curl -s "https://api.open-meteo.com/v1/forecast?latitude=300&longitude=31" -w ' %{http_code}\n'
{"error":true,"reason":"Latitude must be in range of -90 to 90°. Given: 300.0."} 400
```

| الأمر | بيعمل إيه |
|---|---|
| `latitude / longitude` | إحداثيات القاهرة. والـ API قرّب لأقرب نقطة عنده (`30.03`). |
| `current=a,b` | اختار المتغيرات اللي عايزها مفصولة بـ `,`. |
| `timezone=Africa%2FCairo` | الـ `/` في اسم المنطقة اتعملها Encode لـ `%2F` علشان متتلخبطش مع المسار. |
| `"current_units"` | الوحدات **جنب** الأرقام في Object منفصل: تصميم حلو، فمحدش يخمّن إن 29.9 سيلزيوس ولا فهرنهايت. |
| `"reason": "…Given: 300.0."` | رسالة الغلط بتقول القاعدة والقيمة اللي بعتها. ده المستوى اللي عايزه في الـ API بتاعك (فصل 17). |

**المصادر الرسمية:** [Open-Meteo · Docs](https://open-meteo.com/en/docs) · [Open-Meteo · Terms (حدود الاستخدام المجاني)](https://open-meteo.com/en/terms)

## 9.6 API key: NASA

```sh title="Terminal"
$ curl -s "https://api.nasa.gov/planetary/apod" -w ' %{http_code}\n'
{
  "error": {
    "code": "API_KEY_MISSING",
    "message": "No api_key was supplied. Get one at https://api.nasa.gov:443"
  }
} 403
$ curl -sI "https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY" | grep -i ratelimit
x-ratelimit-limit: 10
x-ratelimit-remaining: 9
```

حاجتين للمصمّم: الـ `code` ثابت (`API_KEY_MISSING`) تقدر تكتب عليه `if`، والـ `message` للبني آدم وفيه الحل. بس الـ Status **403**، والأدق حسب HTTP كان **401** ("مين انت؟") مش 403 ("عارفك بس ممنوع"). فصل 16 هيفصّل الفرق. و`DEMO_KEY` حدّه صغير جداً (الـ Header قال 10)، فسجّل Key مجاني لو هتستخدمه بجد.

**المصادر الرسمية:** [api.nasa.gov](https://api.nasa.gov/)

## 9.7 درس حقيقي: لما API يقفل نسخة

وإحنا بنجرّب للكتاب، بعتنا لـ REST Countries (API مشهور جداً في الكورسات، ومنها كورس Jonas!) على النسخة القديمة `v3.1`:

```sh title="Terminal"
$ curl -sL "https://restcountries.com/v3.1/name/egypt?fields=name,capital"
{
    "success": false,
    "data": null,
    "errors": [
        {
            "message": "This API version has been deprecated. Please visit https://restcountries.com/docs/countries/legacy-api-deprecation to migrate to our new version (v5)."
        }
    ]
}
```

يعني كل كود قديم بيستخدم `v3.1` وقف. ولو بتذاكر من فيديو قديم بيستخدم REST Countries، هتقابل ده. والدرس للمصمّم (فصل 19): لما تقفل نسخة، قول ده بوضوح، وحط لينك للـ Migration، والأحسن تبعت قبلها بفترة Headers زي `Deprecation` و `Sunset` علشان الناس تلحق.

:::tip[Best Practice: تمرين يومي 10 دقايق]
كل يوم اختار API من الجدول، واقرا صفحة الـ Docs بتاعته 5 دقايق، وابعت 3 طلبات: واحد صح، وواحد ناقص Parameter، وواحد بقيمة غلط. واكتب في ورقة: الـ Status كام؟ وشكل الغلط إيه؟ ده اللي هيبني إحساسك كمصمّم.
:::

:::tip[ملخص الفصل]
- httpbin و Postman Echo: شوف طلبك زي ما وصل، وجرّب Status codes و Auth و Delays.
- JSONPlaceholder: CRUD وهمي (201 + Location حلو، 404 فاضي وحش). DummyJSON: JWT و `select` و `limit/skip`.
- PokeAPI (`offset`) و Rick and Morty (`page`) بيدّوك `next` جاهز.
- Open-Meteo: الوحدات جنب الأرقام، وأخطاء 400 بتقول القاعدة والقيمة.
- NASA: API key في الـ Query، و `code` ثابت، بس 403 مكان 401.
- REST Countries قفلت v3.1: الـ Versioning مش رفاهية.
:::

### صح ولا غلط؟

1. JSONPlaceholder بيحفظ الـ Posts اللي بتعملها بـ POST.
2. PokeAPI و Rick and Morty بيستخدموا نفس طريقة الـ Pagination.
3. httpbin مفيد علشان تشوف الطلب بتاعك زي ما السيرفر استلمه.

### أسئلة مراجعة

1. إيه اللي حلو في رد الغلط بتاع Open-Meteo؟ وإيه اللي ناقص في 404 بتاع JSONPlaceholder؟
2. ليه `next` كـ URL كامل أحسن من إنك تحسب الـ offset بنفسك؟
3. NASA رجّعت 403 من غير Key. كنت هترجّع إيه انت؟ وليه؟
4. إيه اللي كان ممكن REST Countries تعمله علشان الناس متتفاجئش؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** هات درجة الحرارة الحالية في الإسكندرية من Open-Meteo بـ `timezone=Africa/Cairo`.
2. **[متوسط]** اكتب Loop في الـ Shell أو JS بيمشي ورا `next` في Rick and Morty لحد الآخر، ويعد كام شخصية `status` بتاعها `Dead`.
3. **[صعب]** اختار 3 APIs من الجدول، وابعت لكل واحد طلب غلط، وقارن شكل الأخطاء في جدول: الـ Status، والـ Fields، وفيه `code` ثابت ولا لأ.
