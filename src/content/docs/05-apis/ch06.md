<small>المرحلة 2 · JSON بالتفصيل</small>

PokeAPI رجّعلك 309 KB عن Pikachu، وانت عايز الاسم والنوع بس. ممكن تفتحه في المتصفح وتدوّر بعينك، أو تكتب اسكريبت JS. أو تكتب سطر jq واحد. في الفصل ده هنتعلم jq حتة حتة على بيانات حقيقية: من النقطة لوحدها لحد select و map و group\_by وتطليع CSV، وكل رمز متشرّح.

:::note[بعد الفصل ده هتكون عارف]
- jq موجود على الماك ولا تسطّبه، ونسخة مين
- الفلتر . والـ Paths: .a.b و .\[0\] و .\[\]
- الـ Pipe
- جوه jq (مش بتاع الـ Shell)
- تبني Objects و Arrays جديدة بـ { } و \[ \]
- map و select و length و keys و sort\_by و group\_by و unique
- -r و -c و -s و -n و -e و --arg و --argjson
- التعامل مع null و // و ?
- تطلّع CSV و TSV من JSON
:::

<a id="s6-1"></a>

## 6.1 ليه jq؟

JSON جاي من الـ API سطر واحد طويل، أو مئات السطور متداخلة. وانت عايز تجاوب أسئلة بسيطة: "كام عنصر؟"، "هات الأسماء بس"، "مين اللي حالته draft؟". و**jq** لغة صغيرة معمولة للحكاية دي بالظبط: بتاخد JSON، وتعدّيه على **فلتر**، وتطلّع JSON (أو نص). وأحلى حاجة فيه إنه بيتركب مع `curl` بـ Pipe، فتستكشف أي API من غير ما تكتب كود.

<a id="s6-2"></a>

## 6.2 التسطيب على الماك

```sh title="Terminal"
$ which -a jq
/opt/homebrew/bin/jq
/usr/bin/jq
$ /usr/bin/jq --version
jq-1.7.1-apple
$ brew install jq
$ jq --version
jq-1.8.2
```

- من **macOS 15 Sequoia** وطالع، أبل بقت حاطة jq جاهز في `/usr/bin/jq`، بس نسخة قديمة (1.7.1 في macOS 26). ومينفعش تمسحها ولا تحدّثها (System volume).
- `brew install jq` بيدّيك أحدث نسخة (**1.8.2** في أكتوبر 2026) في `/opt/homebrew/bin`، وده بيبقى أول في الـ `PATH` فبيكسب.
- `which -a`: الـ `-a` = "All": اطبع كل نسخة لقيتها في الـ `PATH` بالترتيب، مش أول واحدة بس.
- كل الأمثلة هنا اتجربت على 1.8.2. وأغلبها شغال زي ما هو على 1.7.1، بس Functions جديدة زي `trim` مش موجودة في القديمة.

**المصادر الرسمية:** [jqlang.org · Download](https://jqlang.org/download/) · [jq 1.8 Manual](https://jqlang.org/manual/) · [formulae.brew.sh · jq](https://formulae.brew.sh/formula/jq)

<a id="s6-3"></a>

## 6.3 النقطة: أبسط فلتر

نزّل بيانات حقيقية الأول علشان نلعب عليها:

```sh title="Terminal"
$ curl -s https://pokeapi.co/api/v2/pokemon/pikachu -o pika.json
$ curl -s https://jsonplaceholder.typicode.com/users -o users.json
$ jq . pika.json | head -5
```

**تشريح الأمر**

```sh
jq . pika.json
```

1. `jq`: البرنامج.
2. `.`: الفلتر: "**اللي داخل زي ما هو**" (Identity). بس jq بيطبعه منسّق وملوّن، فده أسرع Pretty printer. ومن غير اسم ملف بياخد من الـ Pipe: `curl -s URL | jq .`
3. `pika.json`: الملف اللي هيقرا منه.

:::caution[خلي بالك: حط الفلتر بين ' ']
الفلاتر فيها رموز الـ Shell بيحب يلعب فيها (`|` و `[ ]` و `$` و `*` و `>`). فاكتب الفلتر دايماً بين علامتين `'…'`: `jq '.types[].type.name'`. والـ zsh على الماك تحديداً بيعتبر `[ ]` من غير تنصيص Pattern للملفات، ويطلّع `zsh: no matches found`.
:::

## 6.4 الوصول للحقول: .key و .\[n\] و .\[\]

```sh title="Terminal"
$ jq '.name, .id, .height' pika.json
"pikachu"
25
4
$ jq '.[0].address.geo' users.json
{
  "lat": "-37.3159",
  "lng": "81.1496"
}
$ jq -r '.types[].type.name' pika.json
electric
```

| الأمر | بيعمل إيه |
|---|---|
| `.name` | قيمة الـ Key `name`. زي `obj.name` في JS. |
| `.a, .b` | الفاصلة = "طلّع الاتنين" ورا بعض كنتايج منفصلة. |
| `.[0]` | أول عنصر في Array. و`.[-1]` آخر عنصر، و`.[2:5]` Slice من 2 لحد قبل 5. |
| `.address.geo` | تدخل جوه Objects متداخلة. وخد بالك: `lat` جاي **String** مش رقم، وده قرار تصميم وحش من JSONPlaceholder هنتكلم عنه في فصل 16. |
| `.[]` | "**فك**" الـ Array: كل عنصر يطلع لوحده كنتيجة منفصلة. ده أهم رمز في jq. |
| `.types[].type.name` | لكل عنصر في `types`، ادخل في `type` وهات `name`. |
| `-r` | "Raw output": اطبع النص من غير `"`. لازم لو هتستخدم الناتج في أمر تاني. |

### لو الـ Key مش موجود

```sh title="Terminal"
$ jq '.nope' pika.json
null
$ jq '.nope.deeper' pika.json
null
$ jq '.name.x' pika.json
jq: error (at pika.json:0): Cannot index string with string ("x")
$ jq '.name.x?' pika.json
$ jq '.license.spdx_id // "none"' repo.json
"MIT"
$ echo '{"license": null}' | jq '.license.spdx_id // "none"'
"none"
```

| الأمر | بيعمل إيه |
|---|---|
| `.nope` | Key مش موجود = `null` من غير Error. و`null` نفسه لو دخلت جواه برضه `null`. |
| `Cannot index string` | لكن لو حاولت تدخل جوه String أو رقم، ده Error حقيقي، والـ Exit code بيبقى **5**. |
| `?` | "لو فيه Error، اسكت ومطلعش حاجة". زي `?.` في JS تقريباً. |
| `//` | الـ **Alternative operator**: "لو الشمال `null` أو `false` أو مطلعش حاجة، خد اليمين". زي `??` في JS. ومش تعليق! |

<a id="s6-5"></a>

## 6.5 الـ Pipe جوه jq، وتبني شكل جديد

الـ `|` جوه الفلتر بتاع jq زي الـ Pipe بتاع الـ Shell (كتاب الإنترنت فصل 3): ناتج اللي على الشمال بيدخل للي على اليمين. بس هي **جوه** jq، وده سبب التنصيص.

```sh title="Terminal"
$ jq '{name, weight, types: [.types[].type.name]}' pika.json
{
  "name": "pikachu",
  "weight": 60,
  "types": [
    "electric"
  ]
}
$ jq -c '.stats[] | {stat: .stat.name, base: .base_stat}' pika.json
{"stat":"hp","base":35}
{"stat":"attack","base":55}
{"stat":"defense","base":40}
{"stat":"special-attack","base":50}
{"stat":"special-defense","base":50}
{"stat":"speed","base":90}
$ jq '[.stats[] | .base_stat] | add' pika.json
320
```

```text title="حتة حتة"
{name, weight}
types: [.types[].type.name]
-c
.stats[] | {stat: .stat.name, base: .base_stat}
[ … ] | add
```

1. `{name, weight}`: بناء Object جديد. `{name}` اختصار لـ `{name: .name}` (زي الـ Shorthand في JS).
2. `types: [.types[].type.name]`: الـ `[ … ]` حوالين فلتر بيطلّع كذا نتيجة = "**لمّهم في Array**". عكس `.[]`.
3. `-c`: "Compact": كل نتيجة في سطر واحد. مفيد مع النتايج الكتير، وبيطلّع JSON Lines.
4. `.stats[] | {stat: .stat.name, base: .base_stat}`: فك الـ Array، وكل عنصر يدخل للـ Pipe لوحده، ويتبني منه Object صغير. وجوه الـ Pipe النقطة بقت معناها "العنصر الحالي".
5. `[ … ] | add`: لمّ الأرقام في Array، و`add` تجمعهم: 35+55+40+50+50+90 = 320.

## 6.6 map و select وأصحابهم

```sh title="Terminal"
$ jq 'length' users.json
10
$ jq -c 'keys[:6]' pika.json
["abilities","base_experience","cries","forms","game_indices","height"]
$ jq -c '.[] | select(.id == 3) | {id, name}' users.json
{"id":3,"name":"Clementine Bauch"}
$ jq -c 'map(select(.address.city | startswith("S"))) | map({name, city: .address.city})' users.json
[{"name":"Patricia Lebsack","city":"South Elvis"},{"name":"Mrs. Dennis Schulist","city":"South Christy"}]
$ jq 'map(select(.completed)) | length' todos.json
90
$ jq -c 'group_by(.userId) | map({user: .[0].userId, done: map(select(.completed)) | length}) | .[:3]' todos.json
[{"user":1,"done":11},{"user":2,"done":8},{"user":3,"done":7}]
$ jq -c '[.stats[] | {name: .stat.name, base: .base_stat}] | sort_by(-.base) | .[:2]' pika.json
[{"name":"speed","base":90},{"name":"attack","base":55}]
```

**أهم الـ Functions وما يقابلها في JS**

| jq | بتعمل | في JS |
|---|---|---|
| `length` | عدد عناصر Array أو Keys أو حروف String | `.length` |
| `keys` | الـ Keys مترتبة أبجدياً | `Object.keys()` (من غير ترتيب) |
| `map(f)` | طبّق `f` على كل عنصر = `[.[] \| f]` | `.map()` |
| `select(cond)` | عدّي العنصر لو الشرط صح، وامسحه لو لأ | `.filter()` (مع map) |
| `add` | اجمع أرقام / ادمج Strings أو Arrays | `.reduce((a, b) => a + b)` |
| `sort_by(f)` | رتّب حسب قيمة. و`-.base` = تنازلي | `.sort((a, b) => …)` |
| `group_by(f)` | Array of Arrays، كل مجموعة ليها نفس القيمة | `Object.groupBy()` |
| `unique` | شيل المتكرر (ورتّب) | `[...new Set(arr)]` |
| `startswith("S")` | String بيبدأ بـ | `.startsWith()` |
| `to_entries` / `from_entries` | Object ↔ Array of `{key, value}` | `Object.entries` / `fromEntries` |
| `type` | اسم النوع: `"object"` و`"array"`… | `typeof` (بس أدق) |

| الأمر | بيعمل إيه |
|---|---|
| `select(.id == 3)` | `==` مقارنة (مفيش `===` في jq). و`and` و `or` و `not` كلمات: `select(.ok \| not)`. |
| `.address.city \| startswith("S")` | جوه `select` تقدر تعمل Pipe عادي، والنتيجة لازم تبقى true/false. |
| `map({user: .[0].userId, …})` | بعد `group_by` كل عنصر بقى Array، فـ `.[0].userId` = الـ userId بتاع أول واحد في المجموعة. |

## 6.7 الـ Flags وبناء JSON صح

```sh title="Terminal"
$ jq -c 'select(.ok | not)' results.jsonl
{"file":"b.md","ok":false,"error":"timeout"}
$ jq -s -c 'map(.file)' results.jsonl
["a.md","b.md"]
$ jq -n --arg t 'He said "hi"' --argjson v 10 '{title: $t, views: $v}' -c
{"title":"He said \"hi\"","views":10}
$ jq -e '.missing' pika.json; echo "exit=$?"
null
exit=1
```

| الأمر | بيعمل إيه |
|---|---|
| `ملف .jsonl` | jq بيقرا أي عدد JSON ورا بعض، وبيطبّق الفلتر على كل واحد لوحده. فـ JSON Lines شغال لوحده. |
| `-s` | "Slurp": اقرا كل الـ JSONs ولمّهم في Array واحدة قبل الفلتر. فـ `-s 'length'` = عدد السطور. |
| `-n` | "Null input": متقراش أي حاجة، ابدأ من `null`. علشان **تبني** JSON من الصفر. |
| `--arg t '…'` | متغير `$t` قيمته **String**. وjq بيعمله Escape صح لوحده: الـ `"` اللي جوه بقت `\"`. وده الطريقة الصح تبني Body لـ curl. |
| `--argjson v 10` | نفس الحكاية بس القيمة بتتقري كـ **JSON**، فـ `10` رقم مش `"10"`. |
| `-e` | "Exit status": لو آخر نتيجة `null` أو `false`، الـ Exit code يبقى 1. مفيد في اسكريبتات Shell: `if curl … \| jq -e '.ok' >/dev/null; then …`. |
| `$?` | Exit code بتاع آخر أمر في الـ Shell (0 = نجح). |

```sh title="Terminal"
# تبني Body صح وتبعته
$ jq -n --arg title "APIs و JSON" '{title: $title, userId: 1}' \
    | curl -s --json @- https://jsonplaceholder.typicode.com/posts
{
  "title": "APIs و JSON",
  "userId": 1,
  "id": 101
}
```

الـ `@-` معناها "خد الـ Body من الـ stdin" (اللي جاي من الـ Pipe)، و`--json` هنشرحه في فصل 8.

## 6.8 تطلّع CSV و TSV ونصوص

```sh title="Terminal"
$ jq -r '.[] | [.id, .name, .email] | @csv' users.json | head -3
1,"Leanne Graham","Sincere@april.biz"
2,"Ervin Howell","Shanna@melissa.tv"
3,"Clementine Bauch","Nathan@yesenia.net"
$ curl -s "https://api.github.com/repos/expressjs/express/releases?per_page=3" \
    | jq -r '.[] | "\(.tag_name)  \(.published_at[:10])"'
v5.3.0  2026-10-09
v4.22.2  2026-05-11
v5.2.1  2025-12-01
$ jq -rn '"q=\("APIs و JSON" | @uri)"'
q=APIs%20%D9%88%20JSON
```

| الأمر | بيعمل إيه |
|---|---|
| `[.id, .name, .email] \| @csv` | ابني Array بالترتيب اللي عايزه، و`@csv` تحوّله لسطر CSV بتنصيص صح. وفي `@tsv` بـ Tab. ومحتاج `-r` وإلا السطر هيطلع جوه `"…"`. وتحفظه بـ `> users.csv` وتفتحه في Excel. |
| `"\(.tag_name)"` | **String interpolation**: زي `${…}` في الـ Template strings. |
| `.published_at[:10]` | الـ Slice شغال على الـ Strings كمان: أول 10 حروف = التاريخ من غير الوقت. |
| `@uri` | Percent-encoding للـ URL (كتاب الإنترنت فصل 6): المسافة `%20` و "و" بقت بايتاتها في UTF-8. |

:::note[مثال عملي: سؤال واحد، سطر واحد]
"إيه أكتر 3 Repos عليها Stars عند منظمة expressjs؟":<br>`curl -s "https://api.github.com/orgs/expressjs/repos?per_page=100" | jq -r 'sort_by(-.stargazers_count) | .[:3][] | "\(.stargazers_count)\t\(.name)"'`<br>رجّع وقت الكتابة: `69577 express` و`12087 multer` و`8200 morgan`. وفصّص كل حتة بالجداول اللي فوق: `sort_by(-…)` تنازلي، و`.[:3]` أول 3، و`[]` فكّهم.
:::

:::tip[حاجة مشتركة: نفس الفكرة في كل حتة]
الـ Path بالنقط (`.owner.login`) هتلاقيه في JSONPath (**RFC 9535**: `$.owner.login`)، وفي JSON Pointer (**RFC 6901**: `/owner/login`) اللي هيظهر في JSON Schema (فصل 7) وفي أخطاء الـ Validation (فصل 17) وفي JSON Patch (فصل 15). تلات صيغ لنفس الفكرة: "إزاي أشاور على حتة جوه JSON".
:::

**المصادر الرسمية:** [jq Manual · Basic filters](https://jqlang.org/manual/#basic-filters) · [jq Manual · Builtin functions](https://jqlang.org/manual/#builtin-operators-and-functions) · [jq Manual · @csv @uri](https://jqlang.org/manual/#format-strings-and-escaping) · [RFC 6901 · JSON Pointer](https://www.rfc-editor.org/rfc/rfc6901) · [RFC 9535 · JSONPath](https://www.rfc-editor.org/rfc/rfc9535)

:::tip[ملخص الفصل]
- macOS 15+ فيه jq قديم في `/usr/bin`، و`brew install jq` = 1.8.2.
- الفلتر دايماً بين `'…'`. و`.` = زي ما هو، و`.a.b` و`.[0]` و`.[]` للوصول.
- `|` جوه jq Pipe، و`{ }` تبني Object، و`[ ]` تلمّ نتايج.
- `map` و `select` و `length` و `keys` و `sort_by` و `group_by` و `add`.
- `//` قيمة بديلة، و`?` يسكّت الأخطاء.
- `-r` نص، و`-c` سطر، و`-s` لمّ، و`-n` بناء، و`--arg`/`--argjson` متغيرات آمنة، و`-e` Exit code.
:::

### صح ولا غلط؟

1. `//` في jq معناها تعليق.
2. `jq '.nope'` على Key مش موجود بيرجّع Error.
3. `--arg n 5` بيخلي `$n` رقم.

### أسئلة مراجعة

1. إيه الفرق بين `.[]` و `[ … ]`؟
2. اكتب فلتر بيطلّع أسماء الـ Users اللي الـ email بتاعهم بيخلص بـ `.biz`.
3. ليه `jq -n --arg` أحسن من إنك تكتب الـ JSON بإيدك في `curl -d`؟
4. إمتى تحتاج `-r`؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** من `pika.json` طلّع أسماء الـ abilities كنص، كل واحدة في سطر.
2. **[متوسط]** من `todos.json` طلّع لكل User نسبة المهام المخلّصة كـ `{user, percent}`.
3. **[صعب]** من `https://api.github.com/repos/expressjs/express/issues?per_page=30` طلّع CSV فيه رقم الـ Issue والعنوان واسم صاحبها والـ Labels مفصولة بـ `;` (تلميح: `[.labels[].name] | join(";")`).
