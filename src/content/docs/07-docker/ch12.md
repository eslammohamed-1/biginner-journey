بنينا Image على جهازنا، فاضل نرفعها على Registry علشان أي سيرفر يقدر يسحبها ويشغّلها. دي الخطوة اللي بتكمّل الدورة: build ثم push ثم pull ثم run.

<a id="s12-1"></a>

## 12.1 اسم الـ Image لازم يقول هي رايحة فين

فاكر تشريح اسم الـ Image في فصل الـ Images؟ `REGISTRY/REPOSITORY/image_name:TAG`. علشان ترفع Image على Docker Hub، لازم اسمها يبدأ بـ **اسم حسابك** (الـ namespace)، لأن `library/` محجوزة للـ Images الرسمية بس. فلو اسم حسابك `moaz`، الـ Image لازم تبقى بالشكل ده:

![اسم الـ Image اللي هتترفع على حسابك في Docker Hub.](./assets/ch12-fig1.png)

*اسم الـ Image اللي هتترفع على حسابك في Docker Hub.*

<a id="s12-2"></a>

## 12.2 الخطوات: tag ثم login ثم push

1. **اعمل حساب** على hub.docker.com (لو معندكش). ممكن تعمل Repository من الموقع، أو تسيب الـ push يعمله لوحده أول مرة.
2. <strong>اعمل tag للـ Image:</strong> الـ tag مش نسخة جديدة، هو مجرد اسم تاني لنفس الـ Image (نفس الـ IMAGE ID).

   ```sh title="Terminal"
   docker tag my-nginx-website moaz/my-nginx-website:1.0
   docker tag my-nginx-website moaz/my-nginx-website:latest
   ```
3. **سجّل دخول** من التيرمينال: هيطلب منك الـ username، وبدل الـ password الأحسن تستخدم **Personal Access Token** تعمله من إعدادات حسابك.

   ```sh title="Terminal"
   docker login
   ```
4. <strong>ارفع الـ Image:</strong> لاحظ إن Docker بيرفع الـ Layers اللي مش موجودة بس، والـ Layers بتاعة nginx الأصلية موجودة أصلاً على Docker Hub فمبتترفعش تاني (وده تاني فايدة لفكرة الـ Layers).

   ```sh title="Terminal"
   $ docker push moaz/my-nginx-website:1.0
   The push refers to repository [docker.io/moaz/my-nginx-website]
   5f70bf18a086: Pushed
   a2b9c1d3e4f5: Mounted from library/nginx
   1.0: digest: sha256:4c3f...9a1e size: 1570
   $ docker push moaz/my-nginx-website:latest
   ```
5. **شغّلها من أي سيرفر** عليه Docker:

   ```sh title="Terminal"
   docker pull moaz/my-nginx-website:1.0
   docker run -d -p 80:80 moaz/my-nginx-website:1.0
   ```

<a id="s12-3"></a>

## 12.3 Registries تانية غير Docker Hub

نفس الخطوات بالظبط، بس بتكتب عنوان الـ Registry في أول الاسم، وتعمل login عليه هو:

```sh title="Terminal"
docker login ghcr.io
docker tag my-app ghcr.io/moaz/my-app:1.0
docker push ghcr.io/moaz/my-app:1.0
```

ومن الأمثلة المشهورة: GitHub Container Registry (ghcr.io)، و Amazon ECR، و Google Artifact Registry، و Azure Container Registry. وتقدر تقفل الجلسة بـ `docker logout`.

:::tip[Best Practice: الـ Tags]
- استخدم أرقام versions واضحة (زي `1.0` و `1.1`) وارفع `latest` كمان لو حابب، بس **متعتمدش على `latest` في الـ Production**، لأنه بيتغير مع كل رفع، ومش هتعرف بالظبط أنهي نسخة شغالة.
- الـ Repository على Docker Hub ممكن يبقى **Public** (أي حد يسحبه) أو **Private**. اختار حسب المشروع.
:::

:::caution[خلي بالك]
أي حاجة جوه الـ Image بتترفع معاها. لو الـ Repository Public وفيه ملف `.env` أو Password في `ENV`، فكده انت نشرته للعالم. استخدم `.dockerignore` ومتحطش أسرار في الـ Dockerfile.
:::

:::tip[ملخص الفصل]
- اسم الـ Image لازم يبدأ باسم حسابك: `username/repo:tag`.
- `docker tag` بيدّي اسم جديد لنفس الـ Image، و `docker login` للدخول، و `docker push` للرفع.
- الـ Layers الموجودة على الـ Registry مبتترفعش تاني.
- نفس الخطوات لأي Registry تاني، بس بعنوانه في أول الاسم.
:::

### أسئلة مراجعة

1. عندك Image اسمها `api` وحسابك `sara`، اكتب الأوامر اللي ترفعها بـ version `2.0`.
2. هل `docker tag` بيعمل نسخة جديدة وبياخد مساحة؟
3. ليه مش كويس تعتمد على `latest` في السيرفرات؟
