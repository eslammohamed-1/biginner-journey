الـ Container شغال في الخلفية، طب أعرف منين هو بيعمل إيه؟ بيطبع إيه؟ واخد IP كام؟ وبياكل RAM قد إيه؟ التلات أوامر دول هما عينك على أي Container.

<a id="s5-1"></a>

## 5.1 docker logs: الـ Container بيقول إيه؟

لما بتشغّل Container بـ `-d` مش بتشوف أي حاجة بيطبعها. الـ Process الأساسية جوه الـ Container (اللي اتشغلت بالـ CMD أو الـ ENTRYPOINT) أي حاجة بتطبعها على الـ **stdout** أو الـ **stderr**، Docker بيحفظها، وتقدر تشوفها بـ:

| الأمر | بيعمل إيه |
|---|---|
| `docker logs web` | يعرض كل الـ logs بتاعة الـ Container اللي اسمه `web`. |
| `docker logs -f web` | يفضل متابع (follow) ويعرض أي log جديد أول بأول، زي `tail -f`. اخرج بـ `Ctrl+C`. |
| `docker logs --tail 50 web` | آخر 50 سطر بس. |
| `docker logs --since 10m -t web` | الـ logs بتاعة آخر 10 دقايق، ومعاها الوقت (timestamps). |

:::note[مثال]
شغّل nginx وافتح الصفحة من المتصفح كام مرة، وبعدين:

```sh title="Terminal"
$ docker run -d --name web -p 8080:80 nginx
$ docker logs --tail 2 web
172.17.0.1 - - [22/Oct/2026:11:02:13 +0000] "GET / HTTP/1.1" 200 615 "-" "Mozilla/5.0 ..."
172.17.0.1 - - [22/Oct/2026:11:02:14 +0000] "GET /favicon.ico HTTP/1.1" 404 153 "-" "Mozilla/5.0 ..."
```

كل request وصل لـ nginx ظهر في الـ logs.
:::

:::tip[Best Practice]
خلي التطبيق بتاعك يكتب الـ logs على الـ stdout والـ stderr بدل ملفات جوه الـ Container. كده `docker logs` يشوفها، وأي أداة مراقبة تقدر تجمعها، ومش هتضيع لما الـ Container يتمسح لو بعتّها برّه.
:::

<a id="s5-2"></a>

## 5.2 docker inspect: كل التفاصيل عن أي حاجة

`docker inspect` بيطلّعلك ملف **JSON** فيه كل حاجة Docker عارفها عن الـ Container (أو الـ Image أو الـ Volume أو الـ Network): حالته، والـ IP بتاعه، والـ Ports، والـ Volumes المتوصّلة بيه، والـ Environment variables، والأمر اللي شغّال بيه.

```sh title="Terminal"
docker inspect web
```

الناتج طويل جداً، فبنستخدم `--format` (أو `-f`) عشان نطلّع المعلومة اللي محتاجينها بس:

| الأمر | بيعمل إيه |
|---|---|
| `docker inspect -f '{{.State.Status}}' web` | حالة الـ Container (running أو exited ...). |
| `docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' web` | الـ IP بتاع الـ Container جوه شبكة Docker. |
| `docker inspect -f '{{json .Mounts}}' web` | الـ Volumes والـ Mounts المتوصّلة بيه. |
| `docker image inspect nginx` | تفاصيل الـ Image نفسها: الـ Layers والـ CMD والـ ENV والـ Ports. |

<a id="s5-3"></a>

## 5.3 docker stats: بياكل موارد قد إيه؟

فاكر الـ **cgroups** اللي اتكلمنا عنها في المقدمة؟ `docker stats` بيوريك استهلاك كل Container للموارد بشكل لحظي: الـ CPU، والـ RAM، والـ Network، والـ Disk I/O.

```sh title="Terminal"
$ docker stats --no-stream
CONTAINER ID   NAME   CPU %   MEM USAGE / LIMIT     MEM %   NET I/O         BLOCK I/O   PIDS
3f2a9c1d7e44   web    0.00%   12.4MiB / 512MiB      2.42%   4.1kB / 2.3kB   0B / 4.1kB  9
```

من غير `--no-stream` الأمر هيفضل يحدّث الأرقام كل ثانية لحد ما تدوس `Ctrl+C`. وتقدر تحدد حدود للموارد وانت بتشغّل الـ Container، وده بالظبط شغل الـ cgroups:

```sh title="Terminal"
docker run -d --name web --memory 512m --cpus 1 -p 8080:80 nginx
```

**التلات أوامر: كل واحد بيجاوب على سؤال**

| الأمر | بيجاوب على سؤال | مثال استخدام |
|---|---|---|
| `docker logs` | الـ app بيقول إيه؟ فيه Errors؟ | الـ Container بيقع على طول ومش عارف ليه |
| `docker inspect` | الـ Container متظبط إزاي؟ | عايز تعرف الـ IP أو الـ Volume متوصّل فين |
| `docker stats` | بياكل موارد قد إيه دلوقتي؟ | السيرفر تقيل وعايز تعرف مين السبب |

<a id="s5-4"></a>

## 5.4 أوامر مساعدة مفيدة

| الأمر | بيعمل إيه |
|---|---|
| `docker top web` | الـ Processes اللي شغالة جوه الـ Container. |
| `docker port web` | الـ Port Mapping بتاع الـ Container. |
| `docker system df` | المساحة اللي واخدينها الـ Images والـ Containers والـ Volumes. |
| `docker container prune` | يمسح كل الـ Containers الواقفة.اتأكد إنك مش محتاج حاجة منهم قبل ما توافق. |

:::caution[خلي بالك]
لو الـ Container بيقع على طول بعد ما يقوم (STATUS بتاعه `Exited (1)`)، أول حاجة تعملها `docker logs` عليه، حتى لو هو واقف. الـ logs بتفضل موجودة لحد ما الـ Container يتمسح.
:::

:::tip[ملخص الفصل]
- `docker logs` بيعرض الـ stdout والـ stderr بتوع الـ Process الأساسية، و `-f` للمتابعة.
- `docker inspect` بيعرض كل التفاصيل في JSON، و `-f` لاستخراج قيمة واحدة.
- `docker stats` بيعرض استهلاك الموارد لحظياً، و `--memory` و `--cpus` لتحديدها.
:::

### أسئلة مراجعة

1. Container بيقع بعد ما يقوم بثانية، إيه أول أمر هتكتبه؟
2. إزاي تعرف الـ IP بتاع Container من غير ما تقرا الـ JSON كله؟
3. اكتب أمر يشغّل Container ميعديش 256 ميجا RAM.
