<small>المرحلة 6 · DevTools والـ Debugging</small>

هنبني صفحة صغيرة على جهازك فيها 8 أخطاء متخبية عن قصد في 6 مهام، من أنواع مختلفة: ملف مش موجود، و JSON بايظ، وشكل رد مختلف، و CORS بيخبي 404، و Body اتبعت غلط، وسيرفر مش شغال. مهمتك تلاقيهم كلهم بالأدوات اللي اتعلمتها، وتحدد كل واحد في أنهي محطة، وتثبت السبب بـ curl، وتصلّحه، وتكتب تقرير. الحلول في ملحق الإجابات.

:::note[بعد الفصل ده هتكون عارف]
- تجهّز مشروع وتشغّله بـ python3 -m http.server
- تمشي على خريطة الفصل 22 خطوة خطوة
- تستخدم Console و Network (Headers و Payload و Response) و Application
- تثبت كل سبب من الـ Terminal: curl و nc و lsof و json.tool
- تصلّح وتتأكد بـ Disable cache و 304
- تكتب تقرير Debugging منظم
:::

<a id="s23-1"></a>

## 23.1 جهّز المعمل

اعمل فولدر للمشروع، وجواه 3 ملفات. اكتبهم بالظبط زي ما هم، **بالأخطاء**. متصلحش حاجة وانت بتكتب، حتى لو شفتها.

```sh title="Terminal"
$ mkdir -p ~/net-lab/data && cd ~/net-lab
$ code .
```

```html title="~/net-lab/index.html"
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="utf-8">
  <title>Net Lab</title>
  <script src="js/app.js" defer></script>
</head>
<body>
  <h1>المستخدمين</h1>
  <p id="status">جاري التحميل...</p>
  <ul id="users"></ul>
  <p id="quote"></p>
</body>
</html>
```

```js title="~/net-lab/app.js"
const list = document.querySelector('#users');
const statusEl = document.querySelector('#status');

async function loadUsers() {
  const res = await fetch('data/user.json');
  const data = await res.json();
  data.users.forEach((u) => {
    list.insertAdjacentHTML('beforeend', `<li>${u.name} — ${u.email}</li>`);
  });
  statusEl.textContent = `${data.users.length} users`;
}

async function loadQuote() {
  const res = await fetch('https://example.com/quote.json');
  const q = await res.json();
  document.querySelector('#quote').textContent = q.text;
}

async function saveVisit() {
  const res = await fetch('https://httpbin.org/post', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: { page: 'home', at: Date.now() },
  });
  const echo = await res.json();
  console.log('server got:', echo.json);
}

async function ping() {
  await fetch('http://localhost:3000/health');
}

loadUsers();
loadQuote();
saveVisit();
ping();
```

```json title="~/net-lab/data/users.json"
{
  "data": [
    {"id": 1, "name": "Sara", "email": "sara@example.com"},
    {"id": 2, "name": "Omar", "email": "omar@example.com"},
  ]
}
```

وشغّل سيرفر بسيط من نفس الفولدر (اتعرفنا عليه في الفصل 3):

**تشريح الأمر**

```sh
python3 -m http.server 8000
```

1. `python3`: Python 3. على الـ Mac جاي مع Command Line Tools، ولو مش موجود هيعرض عليك يسطبه.
2. `-m http.server`: شغّل الـ Module اللي اسمه `http.server`: سيرفر ملفات بسيط بيوزع الفولدر الحالي.
3. `8000`: الـ Port. افتح `http://localhost:8000`.

:::note[خلي الـ Terminal ده مفتوح]
السيرفر ده بيطبع سطر لكل طلب بيجيله، زي `"GET /js/app.js HTTP/1.1" 404 -`. ده Log السيرفر، وهو جزء من التحقيق: هيوريك اللي **وصل فعلاً** للسيرفر. افتح تابة Terminal تانية (<kbd>⌘</kbd><kbd>T</kbd>) للأوامر.
:::

## 23.2 قواعد التحقيق

افتح الصفحة في Chrome، و DevTools على Network، وفعّل **Disable cache** و**Preserve log**، واعمل Reload. وبعدين امشي على خريطة الفصل 22، ولكل خطأ تلاقيه املا الجدول ده في ملف `REPORT.md`:

**قالب التقرير لكل خطأ**

| الخانة | تكتب فيها |
|---|---|
| العَرَض | اللي شفته في الصفحة أو الـ Console بالنص |
| المحطة | DNS أو TCP أو TLS أو HTTP أو المتصفح (CORS) أو كودك |
| الدليل من DevTools | أنهي Panel وأنهي تابة، واللي لقيته |
| الدليل من الـ Terminal | أمر يثبت السبب من غير المتصفح، وناتجه |
| الإصلاح | التعديل بالظبط |
| التأكيد | إزاي اتأكدت إنه اتحل |

<a id="s23-3"></a>

## 23.3 المهام

مش هقولك الأخطاء فين، بس هديك تلميحات حسب المحطة. حاول من غير التلميح الأول.

### المهمة 1: الصفحة واقفة على "جاري التحميل..."

أول حاجة هتلاحظها إن مفيش أي حاجة بتحصل. ابدأ بالـ Console، وبعدين Network وفلتر `status-code:404`.

:::note[تلميح 1]
لو لقيت `net::ERR_ABORTED 404 (File not found)` على ملف JS، قارن المسار في الـ `<script>` بمكان الملف الحقيقي. وأكّد من الـ Terminal: `curl -I http://localhost:8000/js/app.js` مقابل `curl -I http://localhost:8000/app.js`، وبص على Log السيرفر.
:::

### المهمة 2: الـ users مش ظاهرين

بعد ما تصلح المهمة 1، هيظهر خطأ جديد. فيه هنا **3 أخطاء ورا بعض** في نفس الدالة، وكل ما تصلح واحد هيظهر اللي بعده. ده طبيعي جداً في الحياة الحقيقية.

:::note[تلميح 2]
الأول: `Unexpected token '<'` = جالك HTML بدل JSON (الفصل 19). بص على الـ Request URL واسم الملف. التاني: `SyntaxError` جوه JSON: افتح الملف في Response، أو من الـ Terminal: `python3 -m json.tool data/users.json` هيقولك السطر والعمود. التالت: `Cannot read properties of undefined (reading 'forEach')`: افتح Preview وقارن شكل الرد بالكود. أو حط Breakpoint على سطر `data.users.forEach` وبص على `data` في Scope.
:::

### المهمة 3: الـ quote مش ظاهرة

هتلاقي في الـ Console خطأ CORS. بس فاكر تحذير الفصل 14؟ الـ CORS error ساعات بيخبي حاجة تانية.

:::note[تلميح 3]
جرب الطلب من غير متصفح: `curl -si https://example.com/quote.json -H 'Origin: http://localhost:8000' | head -5`. بص على أول سطر، ودوّر على `access-control-allow-origin`. فيه مشكلتين هنا، مش واحدة. وإصلاحها مش في إيدك (السيرفر مش بتاعك)، فقرر: تعمل إيه في الكود عشان الصفحة متبوظش لو الطلب ده فشل؟
:::

### المهمة 4: السيرفر "مش فاهم" الـ Body

الـ Console بيطبع `server got: null`. يعني httpbin استلم الطلب ورد 200، بس الـ JSON اللي بعتناه ماوصلش.

:::note[تلميح 4]
افتح طلب `post` في Network ← **Payload** ← view source. وبص في الـ Response على `"data"` و`"json"`. وبعدين Copy as cURL، والزقه في الـ Terminal، وشوف الـ `--data-raw` فيه إيه.
:::

### المهمة 5: خطأ أحمر لطلب على localhost

آخر طلب بيفشل من غير Status رقم.

:::note[تلميح 5]
الـ Status بين أقواس، فالمشكلة قبل HTTP. اقرا اسم `net::ERR_*`، وأكّد بـ `nc -zv localhost 3000` و`lsof -nP -iTCP:3000 -sTCP:LISTEN`. القرار هنا: هل المفروض يبقى فيه سيرفر شغال، ولا الكود ده مالوش لازمة؟ وفي الحالتين، الدالة لازم تتعامل مع الفشل.
:::

### المهمة 6: الكاش

بعد ما كل حاجة تشتغل: **اقفل** Disable cache، واعمل Reload مرتين. بص على Status و Size لملف `users.json` و`app.js`. وبعدين ضيف مستخدم تالت في `users.json`، واعمل Reload عادي. التعديل ظهر؟ وإيه الـ Status المرة دي؟

:::note[تلميح 6]
`python3 -m http.server` بيبعت `Last-Modified`. جرب: `curl -sI http://localhost:8000/data/users.json` وخد التاريخ، وبعدين `curl -sI http://localhost:8000/data/users.json -H 'If-Modified-Since: التاريخ'`. إيه الرد؟ وإيه اللي هيحصل بعد ما تعدّل الملف؟
:::

## 23.4 مهام إضافية (اختياري)

1. **Throttling**: شغّل الصفحة بعد الإصلاح على Slow 4G. ضيف `statusEl.textContent = 'جاري التحميل...'` وتأكد إنها بتبان وقت كافي. وجرب Offline: الصفحة بتعرض رسالة مفهومة؟
2. **Block**: اعمل Block لـ `httpbin.org` من Request conditions. هل الـ users لسه بيظهروا؟ لازم يظهروا: كل دالة لازم تفشل لوحدها من غير ما توقع الباقي.
3. **Override**: اعمل Override content لـ `users.json` وخليه `{"data": []}`. الصفحة بتقول "0 users" ولا بتقع؟
4. **Timing**: قيس طلب `httpbin.org/post` في تابة Timing وبـ `curl -w @timing.txt`. فين أطول مرحلة؟
5. **HAR**: صدّر HAR sanitized للجلسة كلها، وطلّع منه بـ `jq` كل الطلبات اللي Status بتاعها مش 2xx أو 3xx (لاحظ إن الطلبات اللي فشلت من غير رد Status بتاعها 0).
6. **Safari**: افتح نفس الصفحة في Safari بـ Web Inspector. نفس الأخطاء ظاهرة؟ النصوص مختلفة إزاي؟

## 23.5 إمتى تعرف إنك خلصت؟

#### الصفحة

بتعرض 2 users (أو 3 بعد المهمة 6) وعدّهم، ومفيش خطأ أحمر في الـ Console غير لو قررت تسيب طلب بيفشل ومتعامل معاه بـ `catch` (وساعتها المتصفح نفسه هيفضل يطبع سطر الشبكة).

#### التقرير

8 أخطاء (أو أكتر لو لقيت حاجة مش في القايمة)، لكل واحد: العرض والمحطة والدليلين والإصلاح والتأكيد.

:::tip[ده شغلك الحقيقي بعد كده]
المشروع ده صغير، بس الطريقة هي نفسها في أي مشروع كبير: متخمنش، امشي على المحطات، خد دليل من مكانين (المتصفح والـ Terminal)، صلّح حاجة واحدة، واتأكد. ولما تخلص الكورس وتبني مشاريعك، كل مشكلة شبكة هتقابلك هتقع في واحدة من الخانات دي. وارجع لملحق الإجابات عشان تقارن تقريرك بالحل.
:::

:::tip[ملخص المشروع]
- ملف مش موجود (404 على الـ script)، ومسار JSON غلط، و JSON بايظ، وشكل رد مختلف عن الكود.
- CORS بيخبي 404 على سيرفر مش بتاعك، وعلاجه في الكود: تتعامل مع الفشل.
- Body اتبعت `[object Object]`، ويبان في Payload و Copy as cURL.
- سيرفر مش شغال: `ERR_CONNECTION_REFUSED`، ويتأكد بـ nc و lsof.
- الكاش: `Last-Modified` و`If-Modified-Since` و 304.
:::

### صح ولا غلط؟

1. `python3 -m http.server` بيرد على الملفات اللي مش موجودة بصفحة HTML فيها 404.
2. تقدر تصلّح CORS على `example.com` من الكود بتاعك.
3. لو `fetch` اتبعت بـ `body: {…}` من غير `JSON.stringify`، الـ Body هيبقى `[object Object]`.

### أسئلة مراجعة

1. ليه الخطأ في المهمة 2 الأول بيقول `Unexpected token '<'` مش 404؟
2. في المهمة 3، إيه المشكلتين اللي curl كشفهم؟
3. ليه كل دالة لازم يبقى فيها `try/catch` لوحدها؟
4. إزاي تعرف إن Log السيرفر و Network متفقين؟ وإمتى ممكن ميتفقوش؟
