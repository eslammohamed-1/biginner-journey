<small>المرحلة 6 · DevTools والـ Debugging</small>

كل اللي فات كان عن اللي بيحصل في السلك. من هنا ورايح هنشوفه بعينينا، من جوه المتصفح نفسه. Chrome DevTools عبارة عن مجموعة أدوات مدمجة في المتصفح بتوريك كل طلب، وكل خطأ، وكل كوكي، وكل عنصر في الصفحة. الفصل ده جولة: إزاي تفتحه، وكل Panel بيعمل إيه، والاختصارات اللي هتوفر عليك وقت كل يوم.

:::note[بعد الفصل ده هتكون عارف]
- ليه DevTools اتعمل، وإزاي كان الـ Debugging قبله
- تفتحه بـ ⌘⌥I و ⌘⌥J و ⌘⌥C
- خريطة الـ Panels: Elements و Console و Sources و Network و Application وغيرهم
- الـ Drawer بـ Esc، و Command Menu بـ ⌘⇧P
- مكانه في الشاشة، والإعدادات، واللغة
- حاجات تعملها في أول 5 دقايق
- أدوات الـ AI في DevTools وحدودها
:::

<a id="s17-1"></a>

## 17.1 قبل DevTools: alert وربنا يستر

في أول الألفينات، لو الـ JS بتاعك بايظ، المتصفح كان بيعمل… ولا حاجة. أيقونة صغيرة صفرا في الركن تحت في Internet Explorer لو كنت محظوظ. فالمطورين كانوا بيكتبوا `alert('وصلت هنا')` في كل حتة، ويقفلوا 30 نافذة عشان يعرفوا الكود وقف فين. ومفيش أي طريقة تشوف الطلبات اللي الصفحة بتعملها.

سنة 2006 جت Extension لـ Firefox اسمها **Firebug**، وغيرت كل حاجة: Console حقيقي، وتقدر تدوس على أي عنصر وتشوف الـ HTML والـ CSS بتوعه وتعدلهم مباشرة، وقايمة بكل الطلبات. المطورين حبوها لدرجة إن كل المتصفحات بنت نسخ مدمجة منها: Safari عمل Web Inspector، و Chrome من أول نسخة سنة 2008 كان فيه **Developer Tools**. والنهارده DevTools متطور لدرجة إنه بقى أهم أداة عند أي Frontend developer بعد المحرر نفسه.

<a id="s17-2"></a>

## 17.2 تفتحه إزاي

**فتح DevTools على الـ Mac**

| الاختصار | بيفتح فين | تستخدمه لما |
|---|---|---|
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>I</kbd> | آخر Panel كنت فاتحه | الطريقة العامة. **I** = Inspect |
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>J</kbd> | الـ Console مباشرة | عاوز تشوف الأخطاء أو تجرب سطر JS |
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>C</kbd> | Elements، ومعاه وضع اختيار العنصر | عاوز تعرف الحتة دي في الصفحة إيه |
| Right-click ← Inspect | Elements، على العنصر اللي دوست عليه | نفس اللي فوق بالماوس |
| View ← Developer ← Developer Tools | من القايمة | لو نسيت الاختصار |

:::tip[حاجة مشتركة: ⌥ هي Option]
على كيبورد الـ Mac، <kbd>⌘</kbd> = Command، و<kbd>⌥</kbd> = Option (مكتوب عليه alt كمان)، و<kbd>⇧</kbd> = Shift، و<kbd>⌃</kbd> = Control. ولما تقرا دوكيومنتيشن مكتوبة للـ Windows، بدّل `Ctrl` بـ <kbd>⌘</kbd>، و`Alt` بـ <kbd>⌥</kbd>، غالباً. يعني `Ctrl+Shift+I` = <kbd>⌘</kbd><kbd>⌥</kbd><kbd>I</kbd> (دي حالة خاصة) و`Ctrl+Shift+P` = <kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd>.
:::

<a id="s17-3"></a>

## 17.3 خريطة الـ Panels

فوق في DevTools فيه صف تابات، كل واحدة اسمها **Panel**. مش محتاج تعرفهم كلهم النهارده. دول اللي هتستخدمهم، ومرتبين حسب أهميتهم في الكتاب ده:

#### Network

كل طلب الصفحة بتعمله: الـ Status والـ Headers والـ Body والوقت. نجم الكتاب ده، وليه فصلين كاملين (18 و 19).

#### Console

الأخطاء والتحذيرات، والـ `console.log` بتاعك، ومكان تكتب فيه JS على الصفحة نفسها. الفصل 20.

#### Application

الكوكيز و localStorage و sessionStorage و IndexedDB و Service Workers. تشوفهم وتعدلهم وتمسحهم. الفصل 21.

#### Elements

الـ DOM الحقيقي (مش الـ HTML اللي جه من السيرفر، لكن بعد ما الـ JS غيّر فيه)، والـ CSS بتاع أي عنصر، وتعدّل وتشوف النتيجة فوراً.

#### Sources

ملفات الصفحة، والـ Debugger: توقف الكود عند سطر وتمشي سطر سطر. هنلمس منه الأساسيات في الفصل 22.

#### Performance و Lighthouse

ليه الصفحة بطيئة: تسجيل لكل حاجة المتصفح عملها، وتقرير بالدرجات والنصايح. خارج نطاق الكتاب، بس اعرف إنهم موجودين.

ولو مش لاقي Panel (زي Application أو Security)، هتلاقيه في زرار `»` آخر صف التابات. وتقدر تسحب التابات وترتبها زي ما تحب.

<a id="s17-4"></a>

## 17.4 الـ Drawer والـ Command Menu: اتنين هيغيروا حياتك

### الـ Drawer: Console تحت أي Panel

وانت في Network، عاوز تكتب حاجة في الـ Console. هتسيب Network؟ لأ. دوس <kbd>Esc</kbd>، هيطلعلك **Drawer** (درج) تحت فيه Console. يعني Network فوق و Console تحت في نفس الوقت. وفي الدرج ده كمان تابات تانية زي **Network conditions** و**Request conditions** و**Search**. و<kbd>Esc</kbd> تاني يقفله.

### Command Menu: أي حاجة بالكتابة

DevTools فيه مئات الأوامر. مش لازم تفتكر هي فين. دوس <kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd> واكتب اللي عاوزه، زي Spotlight في الـ Mac بالظبط:

| الأمر | بيعمل إيه |
|---|---|
| `⌘⇧P ← screenshot` | "Capture full size screenshot": صورة للصفحة كلها من فوق لتحت، حتى الجزء اللي مش ظاهر. |
| `⌘⇧P ← dark` | غيّر ثيم DevTools نفسه لـ Dark أو Light. |
| `⌘⇧P ← disable javascript` | شغّل الصفحة من غير JS خالص. مفيد تعرف الموقع بيعتمد على JS قد إيه. |
| `⌘⇧P ← show network conditions` | افتح تابة تغيير السرعة والـ User-Agent في الـ Drawer. |
| `⌘P (من غير ⇧)` | افتح أي ملف من ملفات الصفحة بالاسم (زي VS Code بالظبط). |
| `⌘⌥F` | دوّر على كلمة في **كل** ملفات الصفحة مرة واحدة (تابة Search في الـ Drawer). |

## 17.5 ظبّطه مرة واحدة

| الأمر | بيعمل إيه |
|---|---|
| `⋮ ← Dock side` | مكان DevTools: تحت، أو يمين، أو شمال، أو في نافذة لوحده. على شاشة Laptop، **يمين** غالباً أحسن عشان الصفحة تفضل عريضة كفاية. و<kbd>⌘</kbd><kbd>⇧</kbd><kbd>D</kbd> بيبدّل بين آخر مكانين. |
| `⚙ أو ? أو Fn+F1` | الإعدادات (الـ `?` وانت واقف جوه DevTools). فيها Preferences و Shortcuts و Experiments. |
| `Settings ← Language` | لغة DevTools. سيبها **English**: رسايل الأخطاء ومحركات البحث والدوكيومنتيشن وكل الكتاب ده بالإنجليزي، فهتلاقي الكلام بنفس الأسماء. |
| `⌘⇧M` | Device mode: شوف الصفحة كأنها على موبايل بمقاس معين. (والـ Network throttling اللي هنشوفه بعدين جزء منه.) |
| `⌘⇧+ / ⌘- / ⌘0` | كبّر أو صغّر **خط DevTools نفسه** (وانت واقف جواه). مفيد على شاشة صغيرة. |

:::tip[5 دقايق هتوفر عليك ساعات]
1) اعمل Dock على اليمين. 2) في Network، فعّل **Disable cache** (هيشتغل بس وDevTools مفتوح، الفصل 15). 3) في Network، فعّل **Preserve log** لو بتطور صفحة فيها Redirect أو Login (الفصل 18). 4) في Console، فعّل **Preserve log** برضه. 5) اعمل Profile منفصل في Chrome للتطوير من غير Extensions، لأن الـ Extensions بتحقن كود وبتعمل طلبات وبتطلع أخطاء مش بتاعتك.
:::

:::caution[خلي بالك: الـ Extensions بتلخبط]
هتلاقي في الـ Console أخطاء زي `chrome-extension://abc.../content.js` أو في Network طلبات مش فاكر إنك عملتها. دي غالباً من Extensions زي Ad blockers أو Password managers أو Grammarly. قبل ما تقلق، جرب الصفحة في **Incognito** (<kbd>⌘</kbd><kbd>⇧</kbd><kbd>N</kbd>)، لأن الـ Extensions مقفولة فيه بشكل افتراضي. ولو الخطأ اختفى، مش بتاعك.
:::

## 17.6 أدوات الـ AI جوه DevTools

من 2024، Chrome بقى فيه حاجات بتستخدم Gemini جوه DevTools: زرار **Understand this error** جنب الأخطاء في الـ Console (اسمها Console insights)، و Panel اسمه **AI assistance** تسأله عن طلب في Network أو عنصر في Elements. ممكن تكون مفيدة جداً وانت بتتعلم، بس اعرف حدودها:

- محتاجة تكون عامل Sign in في Chrome، وسنك 18+، وفي دولة متاحة فيها الخدمة، ولغة DevTools **إنجليزي**، وتفعّلها من Settings ← AI Innovations. فممكن متلاقيهاش خالص عندك.
- لما تستخدمها، بيانات من الصفحة (الخطأ، والكود اللي حواليه، والطلب) **بتتبعت لجوجل**. متستخدمهاش على حاجة فيها بيانات حساسة أو كود شغل سري.
- زي أي AI: ممكن تغلط بثقة. اعتبرها زميل بيقترح، مش حكم نهائي. والكتاب ده هدفه إنك تفهم الرسالة بنفسك الأول.

:::tip[ملخص الفصل]
- DevTools اتولد من Firebug، والنهارده مدمج في كل متصفح.
- <kbd>⌘</kbd><kbd>⌥</kbd><kbd>I</kbd> للفتح، و<kbd>J</kbd> للـ Console، و<kbd>C</kbd> لاختيار عنصر.
- أهم Panels في الكتاب: Network و Console و Application، ومعاهم Elements و Sources.
- <kbd>Esc</kbd> = Drawer فيه Console تحت أي Panel، و<kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd> = أي أمر بالكتابة.
- سيب DevTools بالإنجليزي، وفعّل Disable cache و Preserve log، وجرّب في Incognito لو شاكك في Extension.
- أدوات الـ AI ليها شروط، وبتبعت بيانات لجوجل، وممكن تغلط.
:::

### صح ولا غلط؟

1. <kbd>⌘</kbd><kbd>⌥</kbd><kbd>J</kbd> بيفتح الـ Console مباشرة.
2. تابة Elements بتوريك الـ HTML زي ما جه من السيرفر بالظبط، من غير أي تعديلات من الـ JS.
3. Disable cache بيفضل شغال حتى بعد ما تقفل DevTools.

### أسئلة مراجعة

1. إيه المشكلة اللي Firebug حلها للمطورين؟
2. عاوز تشوف Network و Console في نفس الوقت. تعمل إيه؟
3. ليه يفضّل تسيب DevTools بالإنجليزي؟
4. لقيت خطأ غريب في الـ Console من ملف `chrome-extension://`. تعمل إيه؟

### تحديات الفصل

<small>جرّبها بإيدك، والحلول في ملحق الإجابات.</small>

1. **[سهل]** افتح DevTools بالـ 3 اختصارات، واعمل Dock على اليمين، وفعّل Disable cache.
2. **[متوسط]** استخدم Command Menu تعمل Screenshot كامل لصفحة طويلة، وبعدين شغّل الصفحة من غير JS. إيه اللي اختفى؟
3. **[صعب]** افتح موقع في Profile عادي وفي Incognito، وقارن عدد الطلبات في Network وعدد الرسايل في Console. الفرق جاي منين؟
